## 1. Копирование уроков в другой курс — [PR #2747](https://github.com/gasyoun/Systema-Sanscriticum/pull/2747), в `main`

**Повод.** Урок вебинара «Грамматика санскрита (2026)» пометили как «Эфир клуба», но в фильтре «Курс = Клуб» его нет. Метка не переносит урок в клуб: он остался в курсе вебинара.
- Подписчик клуба такой урок не найдёт.
- При включённой проверке доступа к записям метка отняла бы запись у купивших вебинар без клуба.

**Сделано.**
- В `/admin/lessons` появилось действие «Копировать в курс…». Оно работает для одного урока и для выделенных.
- В окне выбираются курс, группа, блок и класс записи копии.
- Оригинал не меняется.
- Копия не запускает нарезку клипов и автооткрытие домашних заданий.
- Памятка по тегированию эфиров клуба дополнена.

**Куратору осталось:**
1. На уроке вебинара вернуть «Класс записи» = «Урок курса (покупка курса)».
2. Скопировать урок в «Клуб · #444» с классом «Эфир клуба (синоним)».

## 3. Локальный стек обработки видео и контента

**Окружение.** Python 3.12, torch 2.14 на CUDA 13, RTX 3090, ffmpeg с NVENC, ComfyUI 0.36 и 10 custom nodes.

**Модели.** 69 записей в каталоге, три этапа загрузки, 319 ГБ на диске. Все 8 категорий собраны и проверены прогоном:

| Категория | Что проверено |
|---|---|
| Whisper-транскрипция | 24× реального времени |
| Апскейл и интерполяция | Real-ESRGAN; RIFE 25→50 fps со звуком |
| Маттинг | BiRefNet на видео (альфа), GroundingDINO+SAM2 (IoU 0.996) |
| Генерация видео | Wan 2.2 T2V/I2V, LTX-Video |
| Картинки и правка | FLUX schnell/dev, Qwen-Image (кириллица), Kontext, Qwen-Edit |
| Реставрация лиц | CodeFormer, GFPGAN, InsightFace |
| TTS и клон голоса | XTTS, F5-TTS, Kokoro |
| Детекция и трекинг | YOLO11+ByteTrack, авто-рефрейм 9:16, CLIP-поиск |

**Инструменты.**
- 15 CLI и 11 шаблонов воркфлоу.
- Единый диспетчер `media.cmd`: окружение активировать не нужно.
- Машиночитаемый манифест `media list --json`.
- `AGENTS.md` для агентов.

## 4. Транскрибация по ссылке → ChatGPT

**Сервис.** Локальный HTTP-сервис: ссылка на YouTube → yt-dlp → ffmpeg → Whisper large-v3 на GPU → сегменты с таймкодами. Задачи асинхронные, есть кэш по `video_id` и ключ доступа.

**Публикация.** Сервис опубликован через обратный SSH-туннель на VPS + nginx + Let's Encrypt. Расшифрованы 4 реальных видео, в том числе лекция «Ведийская литература»: 199 сегментов, 14 401 символ.

**MCP-сервер.** Создавать новые Custom GPT на личных аккаунтах OpenAI больше нельзя, а developer mode с remote MCP доступен на Plus. Поэтому сделан MCP-сервер. Оба транспорта (streamable HTTP и SSE) проверены через публичный HTTPS.

## 5. Починено по дороге

Одиннадцать реальных багов, все пойманы прогонами:
- `matte.py` терял последний батч кадров.
- VP9 молча терял альфу.
- `detect.py --reframe` возвращал исходный размер вместо вертикального кропа.
- `models.py` считал неполный снапшот готовым.
- `run_comfyui.cmd` не работал вовсе из-за опечатки в переменной.
- nginx после `scp` терял TLS-блок и отдавал чужой сертификат.
- httpx уходил в прокси даже для 127.0.0.1 и давал фантомные 503.
- MCP-инструмент блокировал сам себя: делал синхронный вызов в свой же uvicorn.
- Ответ 421 от защиты SDK от DNS-rebinding.
- fastmcp на PyPI несовместим сам с собой. Перешёл на официальный SDK.
- Среда:
  - песочница ломает schannel-TLS;
  - `tempfile.mkdtemp` ломал pip;
  - torch cu130 конфликтовал с CUDA 12 для ctranslate2;
  - onnxruntime перекрывал GPU-сборку.
