## Что реализовано (квотная машина Q7)

Per-role лимиты подписочной квоты поверх принятой схемы из
[стратегии 04-10-2026](https://github.com/gasyoun/Uprava/blob/main/docs/SCHOOL_AGENTS_90_DAY_STRATEGY_2026-10-04.md)
(§4 «Правило бюджета») и порогов H6174. Killgate-слой H5867 остаётся отдельным
общим слоём и здесь не дублируется; механика вердиктов намеренно следует его
контракту (status/code/reason, авто-стоп с причиной).

| Требование миссии | Где закреплено | Поведение |
|---|---|---|
| 60/20/20 | `config/school_role_quota.php` `lane_share_pct` (60/20/20) + `QuotaLane::cap()` | Жёсткие потолки полос «штатная работа / проверки / резерв» от квоты роли; переполнение полосы → `lane_exhausted` |
| 79/80/99/100 | там же `warn_pct/experiments_stop_pct/critical_pct/hard_stop_pct` + `QuotaStatus` | Целочисленные пороги (used×100 ≥ pct×allowance, без float-дрейфа): 79/99 — предупреждения, на 80 — стоп экспериментов, на 100 — ноль LLM-вызовов |
| Concurrent reservation / release | `QuotaReservationStore::holdAndCreate/commitReservation/releaseReservation` | Атомарное удержание (условный UPDATE в транзакции, MySQL/SQLite); удержанные токены занимают ёмкость до release/commit; commit списывает факт, излишек возврата не горит |
| Максимум два повтора | `TransientRetryLimiter` (из конфига `max_retries=2`) | 1 попытка + ≤2 повторов, только на `TransientCallException`, итеративно — без рекурсивных агентных циклов |
| На 80 стоп экспериментов | `SchoolRoleQuotaService::reserve()` | Эксперимент (is_experiment) отклоняется, если его расход достиг/перешагнул 80%; штатная работа продолжается |
| На 100 ноль LLM-вызовов | там же | При расходе ≥100% (или перешагивании квоты) — отказ `hard_stop`, замыкающая функция не вызывается вообще |
| Платного fallback нет | `QuotaVerdict::FALLBACK_NONE` | Любой отказ: `fallback: none`, `queued_for_human: true` — очередь человеку; платных маршрутов у машины нет |
| Без новых canonical role ID | `QuotaConfig::excludedRoleIds()` + паттерн слага | Только ссылки на ростер ([FLEET_SCHOOL_AGENTS_92_ROSTER_GRILL_04-10-2026](https://github.com/gasyoun/Uprava/blob/main/docs/FLEET_SCHOOL_AGENTS_92_ROSTER_GRILL_04-10-2026.md)); ID 8/39/42 (`lead-scorer`, `pronunciation-coach`, `plagiarism-sniffer`, ИСКЛ) блокируются при любой попытке |

Повторное использование входов (без параллельного механизма): снимок бюджета
`App\Services\Support\StudentAgent\AgentBudget` (H3231) — мост

## Границы и риски

- Нулевой прод-след: машина не вызывается из прод-кода — ни роутов, ни джобов,
  ни команд, ни планировщиков; флаг `enabled` дефолт OFF; изменений в
  существующих сервисах отправки/поддержки нет.
- Числа квот по ролям (TBD) — единственное, что нужно дозаполнить перед
  фактическим ограничением: вносятся в `config/school_role_quota.php`
  `allowances` только по результатам замера (стратегия §4: сначала измерить).
- Пороговое сравнение — целочисленное, границы 79/80/99/100 отработаны
  литералами; при неделимых квотах потолки полос округляются вниз
  (консервативно, ≤100%).
- Overspend сверх резерва (факт > оценки) честно списывается в committed и
  может увести режим на ≥100% — это ожидаемая учётная семантика (токены уже
  потрачены), следующий вызов блокируется `hard_stop`.
- Окно учёта — месяц (`window_key`); перенос квоты между окнами не
  производится (новое окно — новые счётчики).
