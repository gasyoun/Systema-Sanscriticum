**Предлагаемые фазы:**

## 🧠 Dev Notes & Hypotheses

- **ЛОКАЛЬНЫЕ ТЕСТЫ РАБОТАЮТ:** XAMPP php CLI с включёнными `intl/zip/gd` в `C:\xampp\php\php.ini`. Запуск: `/c/xampp/php/php.exe artisan test [--filter=...]` (в bash `php` не на PATH — звать полным путём или через PowerShell). `.env` из `.env.example` + `key:generate` (gitignored). `openssl_pkey_new` на Windows падает без openssl.cnf — тестовые RSA-ключи фиксируем константой, не генерим в рантайме.
- **ВАЖНО — фронт нужно собрать перед тестами:** layout'ы (`layouts/promo.blade.php`, `layouts/articles.blade.php`) используют `@vite`. Без `public/build/manifest.json` директива бросает исключение → **500** на homepage/лендингах. Это и есть причина «фейлов» `ExampleTest` / `LandingListingVisibilityTest` / `CourseStreamsBlockTest` — НЕ seed-данные и НЕ регрессия (раньше в .ai_state была ошибочная гипотеза про seed). Лечится один раз: `npm install && npm run build` (оба artifact'а gitignored, не коммитим). CI собирает ассеты сам. После сборки полный прогон зелёный.
- **Cast-ловушка `User`:** datetime/integer-атрибуты (`last_activity_at`, `last_login_at`, `*_connected_at` и т.п.) приходят **строками** — метод `User::casts()` в этой версии Laravel не применяется (касты надо было бы в свойстве `$casts`). Поэтому весь код (UserResource, новый `StuckStudentsReport`) оборачивает их в `Carbon::parse()` / `(int)` вручную. Не полагаться на то, что `$user->last_activity_at` — это Carbon.
- **«Оплачено» = `['paid','success']`**, не только `'paid'`. Канон `Payment::PAID_STATUSES`/`scopePaid()` (#104). #108 свёл константы; остались инлайн-литералы (см. очередь).
- **CodeQL не умеет PHP.** `Analyze (php)` падал на КАЖДОМ PR («Did not recognize languages: php»). Исправлено в #107 (php→только javascript). Свип сиблингов: владелец уже починил большинство upstream 2026-06-02; реально остались RuWritingStyles (PR #14) + csl-websanlexicon (PR #62). **Урок:** мой grep по локальным рабочим деревьям ≠ origin/<default> (многие клоны устарели / трекают не ту ветку — нужен `git pull`).
