# H4452: Канва фаза 3 — методология vs эталон Гасунца, transfer view взаимозаменяемости (OxAlpha z-ai/glm-5.3-flash, 09-09-2026)

Решения MG 09-09 (чат): группы взаимозаменяемы; у каждого преподавателя ответвления — нормальны, но отслеживаются и сравниваются; эталон — Гасунц в грамматике; перенос группы — в полном составе по ближайшей позиции канвы.

- **Методология (Uprava):** [`kanva_manifest_calibration.py`](https://github.com/gasyoun/Uprava/blob/main/tools/kanva_manifest_calibration.py) дополнен агрегатами по преподавателям (правило атрибуции MG: по умолчанию Гасунс, исключения — TEACHER_EXCEPTIONS). Отчёт [KANVA_PHASE3_2026-09-09](https://github.com/gasyoun/Uprava/blob/main/docs/KANVA_PHASE3_2026-09-09.md): эталон Гасунца — 14 потоков, медиана 6.0 сессий/урок, Эмено 11 за все потоки (бюджет 5 на поток соблюдён), 16 прыжков. Таймкод-пайплайн задокументирован: n8n «таймкоды» (supadata YouTube-транскрипт → OpenRouter → нарезка → Rutube/Drive) + «нарезка видео» (ответ в TG-чат-инициатора + Drive-папка); ингестия — при спросе, не построена.
- **Transfer view (Systema):** секция «Канва: взаимозаменяемость» в [AttendanceDashboard](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Filament/Pages/AttendanceDashboard.php) — живые грамматики по убыванию курсора: урок/блок, ответвлений (занятия, не двигающие и не подкрепляющие канву: Эмено-only, свободные источники), финал-прогноз, «вливается в» = соседи семейства |Δкурсор| ≤ 2. На проде: 11 групп; гр.55 (урок 18, +5 к медиане) лидер, гр.60 (урок 4, -9) отстающая.
- Тесты: `KanvaTransferTest` 2 (курсорная совместимость ±2, исключение не-канва курсов) + регрессия 47/47 локально. Uprava: тесты калибровки 7/7 + test manifest регистрация.
