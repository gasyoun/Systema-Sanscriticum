# H3930 (OxAlpha z-ai/glm-5.3-flash, 02-09-2026): очередь story_posts + издатель канала @rusamskrtam (Phase 1, flag OFF)

Плашка под автоматизацию ежедневных постов/сториз @rusamskrtam (MG rulings 02-09-2026: text posts first, stories later; студенческие медиа — авто с анонимизацией; курирование — Filament).

- **Таблица `story_posts`** (additive migration `2026_09_02_090000`): kind (`text|photo|video`), payload, media_path, source (`queue|harvest|dm|homework|manual`), source_key (уникальный индекс (source, source_key) — дедуп), status (`draft|approved|published|skipped`), publish_at, repeat_rule (JSON, движок повтора — Phase 2), posted_at, repeat_count, telegram_message_id, journal. Модель [StoryPost](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Models/StoryPost.php) со скоупами `approved`/`due`.
- **`stories:import-queue --path=`** ([StoriesImportQueueCommand](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/StoriesImportQueueCommand.php)): парсит файлы очереди Uprava `content/queue/YYYY-MM-DD-<код>.md` (разделитель «- - - текст поста - - -» / «— — —», построчный разбор — preg-offset байтовые, mb_substr по ним режет мимо на кириллице); слот «утро»→09:00, «вечер»→19:00; дедуп по имени файла, существующие строки не перезаписываются.
- **`stories:publish-due`** ([StoriesPublishDueCommand](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/StoriesPublishDueCommand.php)): флаг `features.telegram_story_publisher` (default OFF, прод-инертен, ноль HTTP); шлёт approved+due текстовые строки магнит-ботом (`MarketingSetting.tg_bot_token`, НЕ кабинетный/zapisi-бот — FINDINGS §651) после дешёвой getChat-пробы пары «токен × chat_id» — «chat not found» на предположенном креденшале это сигнал, а не ретрай; photo/video скипаются с журналом до Phase 2 (MTProto stories).
- **Filament [StoryPostResource](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Filament/Resources/StoryPostResource.php)** (группа «Контент», только ADMIN): таблица с бейджами статусов, approve/skip-экшены, форма с kind/source/status/publish_at; создание вручную доступно.
- **Kernel**: ежечасный `stories:publish-due` (`withoutOverlapping(10)`, `onOneServer`) рядом с content:publish-due.
- Конфиг: `services.telegram_story` (`TELEGRAM_STORY_CHANNEL_CHAT_ID`, `TELEGRAM_STORY_QUEUE_PATH`, `TELEGRAM_STORY_DEFAULT_PUBLISH_HOUR`).
- Тесты: [StoriesImportQueueTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/StoriesImportQueueTest.php) (4) + [StoriesPublishDueTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/StoriesPublishDueTest.php) (4) — 8/8; Pint clean. Гоча: повторный `Http::fake()` в тесте АППЕНДИТ стаб (numeric-key merge), не перекрывает — поведение управляется флагом стаба.
- До включения на проде: магнит-бот должен быть админом @rusamskrtam с правом постинга; `TELEGRAM_STORY_CHANNEL_CHAT_ID=@rusamskrtam` в .env; Phase 2 (сториз через MadelineProto session, анонимизация студенческих медиа, repeat-движок) — отдельный handoff.
