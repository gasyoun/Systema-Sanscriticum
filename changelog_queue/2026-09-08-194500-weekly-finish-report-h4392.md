# H4392: еженедельный пост «Кто на чём закончил» в «Институт» (OxAlpha z-ai/glm-5.3-flash, 08-09-2026)

Решения MG 08-09-2026 в чате: по каждой **идущей группе** (группы активных видимых курсов с ≥1 прошедшим и ≥1 будущим занятием) — **весь ростер** с последним **реально посещённым** занятием каждого студента + подсветка **пропустивших 2+ подряд**; **автопост в понедельник** в чат «Институт», chat-id в env. Команда [`care:weekly-finish`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/WeeklyFinishReportCommand.php) (`--dry-run` печатает, не отправляет), сервис [`WeeklyFinishReport`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/WeeklyFinishReport.php), планировщик Kernel — понедельник 10:30 МСК (после приглашений 10:00), `withoutOverlapping`+`onOneServer`.

- **Семантика фактов:** последнее посещение = `WebinarAttendance` (present); клик по ссылке (`ScheduleJoinClick`) — weaker-факт: для студента без единого посещения помечается «не был ни разу (кликал: N-е занятие, …)», но посещением НЕ считается (ClassAttendanceService различает present/clicked). «Пропустил» = занятие без attendance И без клика (полная неявка); серия считается от новейшего прошедшего занятия назад; 2+ → «⚠️ пропустил N подряд». Семантика «прошло» — эффективный конец занятия (`end ?? start+2ч`, H4387); нумерация зеркалит FullSchedulePost (обзорное не в счёт), даты — тот же формат (`FullSchedulePost::formatDate` сделан публичным, переиспользуется).
- **Формат:** Telegram HTML, шапка «Кто на чём закончил — неделя дд.мм.гггг», по группе — жирный заголовок «{курс} — {группа} (прошло N · впереди M)» и строки студентов; чанки по ≤3500 символов (лимит 4096 с запасом), упаковка посегментно — гигантская группа не ломает лимит.
- **Гейты/получатель:** флаг `WEEKLY_FINISH_REPORT_ENABLED` (config `features.weekly_finish_report`, OFF по умолчанию — единая точка включения); получатель `TELEGRAM_INSTITUTE_CHAT_ID` (`services.telegram.institute_chat_id`) — пусто → команда отказывает явно (exit 1), не молчит; отправка через `SendTelegramChatMessageJob` (идемпотентный TelegramSendGuard).
- Тесты: `WeeklyFinishReportTest` 11/11 (идущая группа + весь ростер; последнее посещение vs не был ни разу; клик = не посещение, но снимает серию неявок; ⚠️ 2 подряд; законченная/нестартовавшая группы исключены; обзорное не нумеруется; чанкирование длинного отчёта ≤4096; dry-run без отправки; гейт флагом; явный отказ без chat-id; формат дат совпадает с H4328).
