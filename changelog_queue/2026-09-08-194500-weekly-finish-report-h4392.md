# H4392: еженедельный пост «Кто на чём закончил» в «Институт» (OxAlpha z-ai/glm-5.3-flash, 08-09-2026)

Решения MG 08-09-2026 в чате: по каждой **идущей группе** (группы активных видимых курсов с ≥1 прошедшим и ≥1 будущим занятием) — **весь ростер** с последним **реально посещённым** занятием каждого студента + подсветка **пропустивших 2+ подряд**; **автопост в понедельник** в чат «Институт», chat-id в env. Команда [`care:weekly-finish`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/WeeklyFinishReportCommand.php) (`--dry-run` печатает, не отправляет), сервис [`WeeklyFinishReport`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/WeeklyFinishReport.php), планировщик Kernel — понедельник 10:30 МСК (после приглашений 10:00), `withoutOverlapping`+`onOneServer`.

- **Семантика фактов (поправлена по живым данным — dry-run на проде):** из 1924 строк `WebinarAttendance` только 74 привязаны к user_id (гости пишутся по имени), а `ScheduleJoinClick` — «надёжная привязка студентов к занятию» (кодбейс) — 80/80 с user_id. Основной сигнал = КЛИК; attendance-with-user_id на том же занятии — усиление (строка без пометки), клик без attendance помечается «(по клику)». Ростер — канонический `ClassRoster` (activeGroups, `left_at IS NULL` — вышедшие/выпускники и служебные аккаунты отсечены). «Пропустил» = занятие без факта; серия от новейшего прошедшего назад; 2+ после хотя бы одного факта → «⚠️ пропустил N подряд»; ноль фактов → «не был ни разу (за N занятий)» (русская плюрализация), без ложного ⚠️. Семантика «прошло» — эффективный конец занятия (`end ?? start+2ч`, H4387); нумерация зеркалит FullSchedulePost (обзорное не в счёт), даты — тот же формат (`FullSchedulePost::formatDate` сделан публичным).
- **Формат:** Telegram HTML, шапка «Кто на чём закончил — неделя дд.мм.гггг», по группе — жирный заголовок «{курс} — {группа} (прошло N · впереди M)» (дубль-заголовок схлопнут, когда имя группы равно названию курса) и строки студентов; чанки по ≤3500 символов (лимит 4096 с запасом), упаковка посегментно — гигантская группа не ломает лимит.
- **Гейты/получатель:** флаг `WEEKLY_FINISH_REPORT_ENABLED` (config `features.weekly_finish_report`, OFF по умолчанию — единая точка включения); получатель `TELEGRAM_INSTITUTE_CHAT_ID` (`services.telegram.institute_chat_id`) — пусто → команда отказывает явно (exit 1), не молчит; отправка через `SendTelegramChatMessageJob` (идемпотентный TelegramSendGuard).
- Тесты: `WeeklyFinishReportTest` 13/13 (идущая группа + весь ростер; последнее посещение vs не был ни разу; клик = факт «по клику» и снимает серию неявок; «не был ни разу (за N занятий)» без ⚠️; вышедшие исключены из ростера; ⚠️ 2 подряд; законченная/нестартовавшая группы исключены; обзорное не нумеруется; чанкирование длинного отчёта ≤4096; dry-run без отправки; гейт флагом; явный отказ без chat-id; формат дат совпадает с H4328).
