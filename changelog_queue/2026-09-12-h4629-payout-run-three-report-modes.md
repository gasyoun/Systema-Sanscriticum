# H4629: payout:run — три режима отчёта: marina (чат-формулы 1-в-1), detailed (поимённые перерасчёты + должники), payments (лента платежей) (OxAlpha z-ai/glm-5.3-flash, 12-09-2026)

Исполнение [H4629](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4629-OxAlpha_Systema-Sanscriticum_payout-run-three-report-modes_12.09.26.md). [PayoutRunCommand.php](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/PayoutRunCommand.php) + [PayoutRunTest.php](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/PayoutRunTest.php); сервисы расчёта не тронуты, `json` без изменений.

- **`--format=marina` 1-в-1 стиль чат-формул Марины** (эталоны 16.02–23.07.2026 — Uprava `data/h4597_finansy_leitan_kostina_extract.json`): «{N}-й блок: платных X: (база × 92%) × ставка = срез × ставка = сумма р.» с промежуточным шагом, перерасчёты отдельными строками («перерасчёт за M-й блок: платных Y: …»), «итого …» на курс, «Всего: a + b = c евро» для мульти-курса, «Итого начислено: X руб. или N €», «К оплате: N € / X руб.» (EUR-линия по `lane`; Костина в конфиге — тоже EUR, как в эталонах «К оплате: 325 € / 29256 руб.»). Формулы — целые/2-знака без разделителей тысяч (как в чате), суммы-итоги — «14 904,00». Починен rtrim-баг процентов (30→«3»): новый `pctTxt()` для ставки/среза/курса/НПД.
- **`--format=detailed`** (бывший `report`, оставлен алиасом): + секция «Перерасчёты старых блоков (поимённо)» — ученик, курс, блок, доля, дата платежа, payment_id; должники по завершённым блокам через `debtorsFor` наружу **с чисткой от исторического состава групп**: вступивший в группу позже завершения блока не считается должником (pivot `group_user.created_at` против `completed_on`), чистимые перечисляются отдельной строкой.
- **`--format=payments`**: лента всех платежей расчёта по датам — дата (first_paid_at, fallback created_at), ученик, курс, блок, доля в базе, метод (Карта/СБП/Долями/Наличные), плюс прямые (вычет), посреднические (не вычет) и возвраты; футер «Доли расчёта / прямые / посреднические».
- Тесты: 15/15 (11 старых + 4 новых: формула 1-в-1 с перерасчётом, EUR-линия с «Всего», поимённые перерасчёты + чистка должников, лента с методами). Pint green. Нюанс тест-инфры: PendingCommand `expectsOutputToContain` при >1 ожидании ломается (Mockery-ожидание `atLeast()->times(0)` перехватывает все doWrite) — новые тесты на `Artisan::call` + `assertStringContainsString`.
