# H5398 — русские глоссы в обеих SRS-колодах приведены к словарной форме, правка сделана в источниках (Opus 5 `claude-opus-5`, 24-09-2026)

Остаток [H5285](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/roots_gloss_lint.tsv): линт NKRYa нашёл в карточках глоссы, которые стоят не в словарной форме, а в какой-то падежной/личной («сделал» вместо «сделать» у `kṛ`, «сближении» вместо «сближение» у `abhigamana`). В колоде это самостоятельный ответ карточки, поэтому косвенная форма там просто неверна. Правка механическая и обратимая (гриль 23-09-2026, Q2 — без голосования), и она сделана **в апстриме, а не в сгенерированных сидах**: сиды пересобраны из исправленных источников.

- **Корни — 385 глосс** ([WhitneyRoots#91](https://github.com/gasyoun/WhitneyRoots/pull/91), `crosswalk/ru_root_glosses.tsv`, колонка `gloss_ru_1`): 382 строки с флагом `inflected` заменены на лемму, которую сам линт предложил в колонке `gloss_lemma`, плюс 3 строки `inflected_ambiguous`, решённые вручную по санскритской части речи (все три — глагольные корни, значит инфинитив): `svap` «спит» → «спать», `mi` «сошлись» → «сойтись», `śvit` «белых» → «белеть». В файле переписано 436 строк (один корень с несколькими номерами Уитни несёт глоссу в каждой своей строке). После этого [`database/seeders/data/build_roots_frequency_ru.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/seeders/data/build_roots_frequency_ru.py) пересобрал [`roots_frequency_ru.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/seeders/data/roots_frequency_ru.tsv) — 385 изменённых `gloss_ru`, 570 совпавших и 59 несовпавших строк без изменений.
- **Леммы — 107 глосс** ([kosha#639](https://github.com/gasyoun/kosha/pull/639), `reading/data/hitopadesa-0.json`, слот `tokens[].gloss_ru.lemma`): 96 строк `inflected` по предложению линта и 11 строк `inflected_ambiguous` по санскритской части речи (глагольный корень → инфинитив, имя → именительный): `han`/`nihan` «убит» → «убить», `nidhā` «сложенные» → «сложить», `svap` «спит» → «спать», `stha` «стоит» → «стоять», `mṛga` «зверей» → «зверь», `sumanas` «цветами» → «цветок», `toya` «воду» → «вода», `tīra` «берегу» → «берег», `vivekin` «отличен» → «отличный», `vādin` «говорящие» → «говорящий». Переписано 174 токена. Заморозка «Старт чтения» перепинена в kosha **только по двум затронутым файлам** (сам пак и производный `lemmas_for_srs.tsv`) — полный перезапуск сборщика заодно перепинил бы и сандхи-активы с источников, ушедших вперёд с 01-08-2026, а это отдельное решение. Здесь пак перевендорен обычным путём: [`scripts/vendor_cohort_start_chteniya_packs.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/vendor_cohort_start_chteniya_packs.py), который сам сверяет sha256 каждого пина против `origin/main` kosha перед записью.
- **Проверка — офлайн-прогон линта после пересборки:** `python scripts/nkrya_gloss_lint.py lemmas roots --offline`. Ни один сид этим проходом не правился руками: оба пересобраны своими штатными сборщиками из исправленных апстримов.
