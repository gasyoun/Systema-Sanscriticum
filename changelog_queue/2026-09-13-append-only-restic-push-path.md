# Append-only restic push path: компрометация .92 больше не стирает историю бэкапов (ox-alpha, opencode `deepseek/deepseek-v4-flash`, 13-09-2026)

Рулинг MG 13-09 (вопрос «как сделать так, чтобы при атаке потерять максимум час данных?»): **append-only — сейчас; Yandex Object Storage с Object Lock остаётся на согласованном ≈24-09-2026.**

- **Дыра, которую закрыли:** пароль репо (`/root/.restic-pass`) и SFTP-ключ push лежат на pusher'е `.92`; root на `.92` мог выполнить `restic forget --prune` через SFTP-аккаунт и стереть всю историю снапшотов на `.91` — «часовой бэкап» при атаке стоил бы только суточной Drive-копии. Теперь `Match User restic-push` → `ForceCommand internal-sftp -P remove,rmdir` (управляемый источник [`scripts/server_guards/sshd/60-restic-append-only.conf`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/server_guards/sshd/60-restic-append-only.conf), severity critical в `manifest.psv`): создавать и переименовывать можно, удалять — нельзя.
- **Retention переехал на `.91`** ([`systema-restic-forget.sh`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/ops/backup/systema-restic-forget.sh), таймер daily 06:40 UTC) и выполняется **от имени `restic-push`** — иначе root-овый prune перезаписывает index-файлы как `root:root 0400` и читатель-uid 999 падает на `Open /systema/index/…: permission denied` (§537 root-poisoning; найдено и исправлено в этом же проходе). Таймер на `.92` погашен.
- **Все restic-вызовы с `.92` — с `--no-lock`** (`backup` в [`systema-restic-run.sh`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/ops/backup/systema-restic-run.sh) + `snapshots`/`ls` в `size_sanity_check.py`): lockless-писатель не может создать лок, который ему же запрещено удалить. Второй дефект этого же класса: stale-локи от sanity-скрипта заставляли `forget` ждать 30 минут (`repo already locked`); в .91-скрипт добавлен `restic unlock --remove-all`.
- **Верификация (живая):** `sftp put` OK / `sftp rm` → `Permission denied` (канарейка `/srv/restic/systema/PROBE_APPEND_ONLY_13-09-2026.txt`); обёртка → `overall_rc=0 systema=OK samudra=OK`; цикл «бэкап → forget от restic-push (0 root-файлов, 0 локов) → бэкап снова зелёный»; root-pivot `.92`→`.91` проверен и закрыт (`Permission denied (publickey)`).
- **Разбор + откат:** [`RUN_LOG_APPEND_ONLY_SFTP_13-09-2026.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/ops/backup/RUN_LOG_APPEND_ONLY_SFTP_13-09-2026.md); ранбук нового бокса дополнен (retention на `.91`, append-only drop-in, проба канарейки).
- **Остаток:** S3-нога с Object Lock — единственная, переживающая компрометацию **обоих** серверов; дата ≈24-09-2026 по рулингу 24-08.
