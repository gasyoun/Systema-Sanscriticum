# H6393 — Лигатуры: FSRS-колода по частотности + lila v2 «Близнецы» + по-лигатурная трудность в воронке

**Лигатуры: колода FSRS + режим различения одним пакетом (H6393, OxAlpha `GLM-5.3, ZCode`).** Два рулинга MG 10-10 в одном PR. (a) *Колода*: [`SrsLigatureFrequencyDeckSeeder`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/seeders/SrsLigatureFrequencyDeckSeeder.php) — content-only по паттерну H1280 (корневая колода), движок СРС не тронут. Фикстура [`ligatures_frequency.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/seeders/data/ligatures_frequency.tsv) — топ-200 лигатур DCS из зафиксированной lila-полосы H1281 (`public/lila/ligatures/data.js`), собранная детерминированным скриптом [`build_ligatures_frequency_tsv.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/seeders/data/build_ligatures_frequency_tsv.py): разложение на компоненты + интерим-близнецы (правило: равная длина IAST, ровно один различающийся слот из визуально-путаемых семейств — придыхание / n-ṇ / s-ṣ; 40 пар) — когда gold-сет Киселёвой ляжет (H6392), фикстура перегенерируется, сеятель идемпотентно обновит карточки. Карточка: лицо = деванагари, ответ = чтение в поле `meaning` (ANSWER_KEYS → работает MC c дестракторами из колоды и typing); отдельного поля `iast` НЕТ — рендер лица показывает devanagari+iast подряд и выдал бы ответ (тест-канарейка). Порядок вставки = ранг DCS → `orderBy('id')` в `queueFor()` подаёт сперва самые частотные. (b) *lila v2*: режим «Близнецы» [`/lila/ligatures/twins/`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/public/lila/ligatures/twins/index.html) — `match/engine.js` переиспользован байт-в-байт; 10 самых частых пар-близнецов всегда целиком на доске (без `perRound` — движок сэмплирует пары независимо и мог бы выкинуть одного из близнецов; «Заново» перемешивает позиции). Гейт/телеметрия/locale прежние (`data-drill="ligatures" data-band="twins"`). Каталожная карточка на `/lila/ligatures/`. *Статистика*: на Filament-странице «Воронка тренажёров» — блок «Лигатуры: трудные чтения» (топ-15 по `GameEvent::difficulty()`, drill=ligatures, включая band=twins: раунды, медиана мс, доля ошибок). Тесты: `SrsLigatureDeckTest` 5 (порядок=частотность, ответ=чтение, нет `iast`-поля, близнецы резолвятся в реальные карточки, идемпотентность, целостность фикстуры) + `LigatureTwinsPackTest` 6 (файлы, проводка gate/telemetry/locale, гарантированная совместная выкладка близнецов, пары из топ-200, линк в каталоге, строки трудности в воронке); регрессии SrsReviewTest/SrsAuthoringTest/GamesFunnelTelemetryTest/P1PackPagesTest зелёные; Pint чист. Деплой: [DEPLOY_QUEUE №82](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/DEPLOY_QUEUE.md) — разовая команда `php artisan db:seed --class="Database\\Seeders\\SrsLigatureFrequencyDeckSeeder"` после выката, миграций/флагов нет; live-пробы (`/koloda`, twins-раунд) — после деплоя.
