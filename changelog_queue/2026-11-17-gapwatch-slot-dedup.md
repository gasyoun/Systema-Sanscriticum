# recordings:gap-watch — пер-slot дедуп + stale только no-recording (шторм алертов записей) — H8410 (2026-11-17)

_Created: 17-11-2026 · Last updated: 17-11-2026_

- **Устранена причина «частых повторов» алертов «Записи не в кабинете / ТГ» (прод 17-11-2026: 13:41, 14:41, 15:41 — серия почти одинаковых TG; пример MG: 11:30 гр.149 no-lesson).**
  Две причины в [`WatchRecordingGaps`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/WatchRecordingGaps.php): (1) дедуп-ключ был sha256 ОТ НАБОРА пробелов окна — каждый новый «протухший» слот (start + `stale_hours` 4 ч, hourly-тик :41) перезапускал весь алерт заново; теперь ключ — sha256 одного слота (`schedule_id:lesson_date`), повторно уезжают только новые слоты, уже отправленные помечаются строкой «⏸ ещё N пробел(ов) этого окна уже уезжали за последние 36 ч»; `--force` по-прежнему шлёт всё. (2) `--stale` ловил и `no-lesson` (слот есть, урока нет — «не отметили» или отмена), у которого нет SLA конвейера записи: теперь дневной тик — только `no-recording` (урок есть, публикации/записи нет), `no-lesson` накрывается утренним 08:00 проходом (окно «вчера»), по-прежнему пер-slot дедуплицированный (36 ч). Прод-факты диагноза: `recording_gap_alerts` 76–83 (по 1–3 отправки каждый день 14–17-11), все наборы — разные отпечатки, 36-часовой дедуп фактически не срабатывал; сегодняшний `--stale --dry` до фикса = {11:30 г.149 no-lesson}, после = пусто. Тесты: семейство `RecordingsGap*` 38/38 (новые: `test_set_growth_alerts_only_new_slots`, `test_stale_tick_leaves_no_lesson_slots_to_morning_pass`; `test_stale_slot_today_is_flagged_same_day` и `test_hourly_tick_dedupes_within_the_day` переведены на no-recording-сид), Pint чист. Хендофф: H8410. Прод-включение — автодеплой после merge; контроль — первый вечерний тик без новых `no-lesson`-сообщений и утренний 08:00 полного охвата 18-11.
