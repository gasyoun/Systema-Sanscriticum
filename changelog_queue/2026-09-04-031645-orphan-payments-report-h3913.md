# H3913 (этап 3 джей-дика Насти): Filament-отчёт «Сиротские платежи» с подсказкой кандидата (OxAlpha z-ai/glm-5.3-flash, 04-09-2026)

Автоматизация из [джей-дика Насти §3](https://github.com/gasyoun/Uprava/blob/main/docs/CURATOR_NASTYA_GORBACHENKO_JD_AND_AUTOMATION_02-09-2026.md): «платежи без привязки к студенту» — сейчас она выясняет «чьи 3 счёта по 8 000» вручную через сопоставление с TG-перепиской. Реальный кейс: 3 счёта по 8000 ₽ за блок 1 Летнего интенсива от SuperAdmin (06-08 и 13-08).

- **Определение сироты:** реально оплаченный (paid) настоящий (не conditional) платёж, у которого user_id указывает на аккаунт супер-админа (платёж создали руками «под собой»). Ветка user_id IS NULL осталась в SQL про запас, но в текущей схеме `payments.user_id` NOT NULL — «без user_id» физически не бывает (обнаружено тестом, задокументировано в коде). Сервис: [`OrphanPaymentsReport`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/OrphanPaymentsReport.php).
- **Страница:** [`OrphanPayments`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Filament/Pages/OrphanPayments.php) — «Пользователи → Сиротские платежи», read-only (actions/bulkActions пустые), группировка по сумме (дефолт)/дате/курсу, фильтры «курс» и «тип сироты», поиск по квитанции. Базовый запрос — чистый Eloquent по payments (не UNION), поэтому группировки/сортировки Filament работают нативно.
- **Подсказка кандидата** (best-effort, НЕ привязка): ученики этого же курса, платившие ту же сумму; сначала «близкой даты» (окно 30 дней, Δ в днях), затем та же сумма вне окна; максимум 3, кэш на запрос, супер-админы кандидатами не считаются. Колонка «Кандидат (подсказка)» + тултип с честной оговоркой «зацепка для сверки, привязку делает человек».
- **Гейт:** `RoleGate::adminOnly()` как у «Должников» (super_admin проходит через any()). Fence соблюдён: ни payments, ни users не пишутся — закреплено тестом.
- Тесты: `OrphanPaymentsReportTest` 7/7 (29 assertions: только-сироты, ранжирование кандидатов по Δ-дням с отсечением чужих курсов/сумм, человекочитаемый лейбл, курс-независимые сироты без зацепок, рендер для админа, гейт по ролям, read-only-инвариант). Pint clean.
