# Глобальный поиск в шапке samskrte.ru: клиентский индекс + /poisk (H7590, GLM 5.3 `account:zai-individual-coding-plan/GLM-5.3`, ZCode, 01-11-2026)

_Created: 01-11-2026 · Last updated: 01-11-2026_

Во всех публичных шапках (компонент public-header — главная, блог, словарь,
промо; и инлайн-шапка shop-лейаута — каталог /online, преподаватели, /k/курсы)
появляется бокс поиска `data-testid="global-search"`: живой дропдаун топ-5 по
мере ввода и полноэкранный оверлей на мобиле (поле свёрнуто в иконку-лупу).
Клавиатурный набор как на GitHub (вердикт MG 01-11-2026): Cmd/Ctrl+K и «/»
фокусируют поле, ↑↓ ходят по результатам, Enter переходит (выбранный результат
или полная страница), Esc закрывает.

Клиентский индекс: `php artisan search:index` (регенерится при деплое и
наблюдателем SearchIndexObserver после правок корпуса) пишет
`public/search/index-{hash12}.json` — контент-хэш в имени, браузер кэширует
бессрочно и перекачивает только при смене корпуса — плюс manifest.json, по
которому шапка узнаёт актуальный файл; прошлые версии подчищаются. Корпус:
витринные лендинги (is_active+is_listed), курсы /k/{slug} (is_visible, записи-
дубли H3807 не продвигаются), преподаватели с публичной страницей,
опубликованные статьи. Поиск — Fuse.js в Alpine; движок (9,6 КБ gzip) и индекс
грузятся лениво при первом фокусе/вводе, начальная страница за поиск не
платит (лоадер 0,85 КБ gzip). Alpine-компонент — inline x-data в
partials/global-search: шапка живёт на страницах с Livewire-Alpine и с
alpine-standalone, регистрация Alpine.data до старта в обоих путях не
гарантируется. No-JS/словарь (там Alpine нет): GET-форма /poisk?q=…
деградирует корректно.

Полная страница результатов — path-style /poisk/{q} БЕЗ ?q= (SEO-вердикт MG:
query-string плох для SEO), маршрут в 02-auth-and-public-pages до catch-all
/{slug}; GET /poisk?q=… редиректится 301-м на канонический путь. Страница
фильтрует тот же корпус, что и клиентский индекс (паритет выдачи,
mb_stripos — регистронезависимо для кириллицы на любом драйвере БД), сама
страница noindex,follow. Каталог /online не тронут (фильтр H7589 остался как
был). Тесты: `GlobalSearchTest` (12) — корпус, хэш-именование и подчистка
старых файлов, команда, 200 на /poisk/йога и на пустой выдаче, 301 с ?q=,
testid в шапке на /, /online, /s, /prepodavately, /k/{slug}. Pint чист,
`npm run build` exit 0 (fuse.js ^7.1.0 в dependencies).
