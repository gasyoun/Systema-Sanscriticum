# H4253: teacher-level отпуск + date-aware «Отмена ДД.ММ» в чате группы, ACL-резолвер (OxAlpha z-ai/glm-5.3-flash, 06-09-2026)

MG 06-09 ruling (doubt-everything pass): teacher vacation toggle settable in panel AND Telegram; что может препод, могут и менеджер/админ; отдельная date-aware команда отмены — препод не обязан ловить just-in-time reply на дальние даты. Отдельно от H4251 (op-cancel двух конкретных дат) — это сам feature-build.

- **[`TelegramGroupAcl`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Support/TelegramGroupAcl.php)** — `SocialAccount(provider=telegram) -> User -> role`: super_admin/admin/manager управляют любой группой, teacher — только своими (`User.teacher_id -> Course -> Group::ledBy`). Неизвестный аккаунт/роль без доступа — отказ, только в лог. Whitelist `zapisi_cancel_admin_ids` (H4199) этим резолвером НЕ гейтится — старая reply-команда не тронута.
- **`teachers.on_vacation_from/until`** (миграция `2026_09_06_120000`, nullable date) — teacher-level окно отпуска, отдельно от group-level `Group.is_on_vacation` (H3790). Форма [TeacherResource](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Filament/Resources/TeacherResource.php) (секция «Отпуск / каникулы», admin/super_admin — ресурс остался `AdminOnly`).
- **Wired effects**: [`PublicScheduleResource`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Resources/PublicScheduleResource.php) несёт `group.is_teacher_on_vacation` (bool, без PII); [`RemindZapisiClasses`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/RemindZapisiClasses.php) теперь пропускает занятия каникульной группы ИЛИ занятия, чей ведущий/со-препод в личном отпуске на дату старта — раньше команда `is_on_vacation` вообще не читала (закрытый гэп).
- **[`TeacherVacationCommandService`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/TeacherVacationCommandService.php)** — «Каникулы с ДД.ММ по ДД.ММ» / «отпуск …» ставит окно всем преподавателям курсов чата группы; «занятия возобновляются» / «вышел(-ла) из отпуска» снимает. ACL-гейт, подтверждение в чат, клейм `TelegramSendGuard` на (chat, окно).
- **[`DatedCancelCommandService`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/DatedCancelCommandService.php)** — «Отмена ДД.ММ[ и ДД.ММ …]» отменяет занятия НА УКАЗАННЫЕ ДАТЫ БЕЗ каскадного сдвига +7 дней (в отличие от reply-команды H4199) — soft-delete только названных дат. ACL-гейт, клейм на (chat, дата), не reply-команда (адресация по тексту, а не по посту-напоминанию).
- Обе команды подключены в [`ProcessTelegramZapisiUpdate`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Jobs/ProcessTelegramZapisiUpdate.php) рядом с существующей reply-командой, не заменяя её.
- **Отложено (скоуп-срез в рамках одного прохода на hard/2h+ handoff):** сидинг `social_accounts`/`User(role=teacher, teacher_id)` для 19 живых whitelisted teacher telegram id (H4199 wave 2) — маппинга id↔препод в репозитории не нашлось, нужен человеческий список; teacher self-service через Filament (сейчас только через TG-команду, ресурс остаётся AdminOnly); Uprava-сторонний `tg_schedule` renderer (вне этого репо).
- Тесты: TeacherVacationCommandTest (5), DatedCancelCommandTest (4), RemindZapisiClassesTest +2 (group-level и teacher-level пропуск) — все green вместе с существующими ZapisiCancelClassCommandTest/PublicScheduleFeedTest. Pint clean (PHP 8.3).
