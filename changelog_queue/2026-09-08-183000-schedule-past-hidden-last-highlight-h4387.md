# H4387: расписание — прошедшие скрыты по умолчанию (кнопка-раскрытие) + жёлтая подсветка последнего прошедшего (OxAlpha z-ai/glm-5.3-flash, 08-09-2026)

Решение MG 08-09-2026 в чате: на поверхностях рендера [`FullSchedulePost::html()`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/FullSchedulePost.php) (/raspisanie, /widgets/schedule «Полные расписания курсов», карточка курса) прошедшие занятия больше не показываются в общем потоке — по умолчанию видны только будущие, над списком строка «Прошло занятий: N · последнее: {дата}» и кнопка «Показать прошедшие занятия» (режим «везде одинаково»). Последнее прошедшее занятие подсвечено жёлтой заливкой (`fs-last`, инлайн-стиль `#FDE047`/тёмный текст — читается на тёмной странице и светлом виджете). Нумерация занятий абсолютная («10-е» остаётся 10-м). Telegram (`telegramHtml()`) и Filament-превью (`->text()`) не тронуты; `html(['past' => 'visible'])` возвращает прежнюю разметку (с подсветкой).

- **Семантика «прошло»:** эффективный конец занятия (`end ?? start + 2ч`, `Schedule::DEFAULT_DURATION_HOURS`) уже позади — идущее сейчас занятие ещё НЕ «последнее прошедшее», та же семантика, что у `upcomingSchedules()`. Обзорное считается тоже (если оно последнее прошедшее — подсвечивается его строка, статус «Последнее прошедшее: …»).
- **Разметка:** в режиме скрытия каждая строка — `<span class="fs-line">` со СВОИМ `<br>` внутри (скрытая строка уносит разрыв с собой, пустые разделители приклеены к следующей строке — после раскрытия разметка совпадает с классической); прошедшие — `<span class="fs-line fs-past" hidden>`, последнее прошедшее — дополнительно `fs-last` (жёлтый). Статус `<p class="fs-status">` + `<button class="fs-toggle">` внутри `.fs-body[data-fs-past]`. Тумблер — делегированный JS-партиал [`partials/schedule-past-toggle`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/partials/schedule-past-toggle.blade.php), включён на всех трёх поверхностях; стили кнопки/приглушения прошедших — per-surface (тёмная тема страницы и карточки, светлая виджета).
- Тесты: `FullSchedulePostTest` +4 (скрытие+статус+кнопка+жёлтая подсветка; идущее сейчас не прошедшее; прошедшее обзорное подсвечено, статус «Последнее прошедшее»; `past:visible` — классика с подсветкой), `PublicSchedulePageTest` +1 (идущий курс: статус, кнопка, скрытые span'ы). Pint clean.
