# H4463: welcome-тур кабинета студента — Teachbase-подобный обзор в модалке (OxAlpha z-ai/glm-5.3-flash, 09-09-2026)

Аналог онбординг-тура Teachbase (скрин MG): центрированная модалка со слайдами «N / M», «Пропустить» / «Назад» / «Далее»→«Готово». Показ один раз на браузер (localStorage `cabinet_tour_v1` — прецедент `cabinet_notice_v1`), повтор — кнопка «Обзор кабинета» в шапке дашборда и в гибридном «Сегодня» (событие `open-cabinet-tour`, паттерн `open-change-password`). План прогнан через «doubt everything, widen, deepen» — 4 дефекта первой версии пойманы до кода.

- **Состав слайдов флаг-осознанный** ([cabinet-tour.blade.php](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/student/partials/cabinet-tour.blade.php)): приветствие, меню слева, «Продолжить»+прогресс, расписание, оплата и доступ, TG/VK-боты (если включены в MarketingSetting), карточки SRS (если `srs.enabled`, + «Тренажёры» при `games_skill_drills`), помощь, полезные материалы с CTA в существующий quiz «Проверить кабинет» (`student.cabinet-mastery`). Слайд обещает только то, что студент реально видит в меню; счётчик динамический. Формулировки ветрятся по `cabinet_hybrid` (прод: ON — «Сегодня/Календарь/Записи»). Копирайт сверен с docs/onboarding-student.md и UX-аудитом (Ticket 2 First-5-minutes).
- **Молчание в «войти как»** ([Impersonation](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Support/Impersonation.php)): партиал не рендерится при `Impersonation::isActive()` — принцип H1947 «превью не подделывает активность целевого пользователя» (иначе админ-превью записало бы себе localStorage-ключ студента).
- **Телеметрия только кликами** (`cabinet_tour.skip.click` / `next.click` / `finish.click` c `:data-track-step`): impression-атрибут сознательно НЕ ставлен — существующий контракт [telemetry](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/student/partials/telemetry.blade.php) шлёт импрешены по `querySelectorAll` на window.load, скрытые x-show узлы засчитались бы как показ у всех.
- **Ловушка npm-skip в деплое обойдена**: [app.css](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/css/app.css) дополнен строкой-комментарием — `need_npm_build()` в deploy.sh (H2104) видит только изменения `resources/{js,css}` и НЕ пересобрал бы Tailwind по изменениям одного blade-партиала (новые утилиты остались бы вне бандла на проде).
- **Kill-switch по конвенции репо**: `features.cabinet_tour` = `env('CABINET_TOUR', true)` — default ON (рулинг MG «деплой сразу»), гашение строкой .env без релиза (после правки — config:cache); флаг OFF → кабинет байт-стабилен.
- **Тесты**: [CabinetTourTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/CabinetTourTest.php) — разметка тура + кнопка повтора на `student.dashboard` (один роут отдаёт и классику, и гибрид при `cabinet_hybrid`), флаг OFF → разметки нет, режим «войти как» → разметки нет, слайд SRS появляется/исчезает вместе с `srs.enabled`. Pint clean.
