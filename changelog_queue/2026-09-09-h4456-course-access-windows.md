# H4456: окна доступа course_access_windows — срок доступа для реальных платежей (OxAlpha z-ai/glm-5.3-flash, 09-09-2026)

Рулинг MG 09-09-2026 (вербатим): «сказать 18 дней и отрезать на 19й день, не надо к курсам Парибка вечный доступ, если не оговорено конкретно у кого такой исключение и вечный доступ». Повод: студентка (users id 6476, платёжные ключи block_1..4 на курсах 327 «Йога-сутры 1 поток в записи» и 336 «2 поток») просила доступ на 9 дней; реальный платёж открывает уроки навсегда, а резать строки платежей (деньги) нельзя. PR — course-access-windows.

- **Таблица `course_access_windows`** (миграция 2026_09_09_110000): уникальная пара (user_id, course_id), `ends_at` nullable, reason, created_by. Строка с `ends_at` в прошлом закрывает доступ, открываемый РЕАЛЬНЫМИ платежами этого курса; `ends_at = NULL` — «вечный доступ по именному исключению» (документированное строкой разрешение); нет строки — прежнее поведение. Модель [CourseAccessWindow](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Models/CourseAccessWindow.php): `setUntil`/`clearFor`/`hasExpiredFor`.
- **Предикат внутри H4396-точки**: [Payment::scopeWithoutExpiredAccessWindow](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Models/Payment.php) (флаг `features.course_access_windows`, дефолт OFF, прод-флип отдельным ops-шагом) вызывается из `scopeWithAccessExpiry` — единый доступ-лист наследует окно во ВСЕХ гейтах: веб-плеер/курс, LessonGate, ДЗ, API-кабинет (`getUserUnlockedTariffs`). Дата решает сама — демона не нужно.
- **Гейт-смежные читатели подключены**: [RecordingAccessPolicy::hasPurchasedLesson](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Membership/RecordingAccessPolicy.php), [CourseCatalog](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Livewire/Shop/CourseCatalog.php) и [ShopController](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/ShopController.php) («уже куплено» снимается — курс с истёкшим окном можно купить заново), [AccessDiagnosticsService::ownedKeys](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/AccessDiagnosticsService.php) (диагностика = правда гейта). Отчётные читатели ключей (сертификаты, хелпдеск, free-tier, BlockAccessMaterializer) не тронуты — деньги и отчётность не меняются.
- **Команда управления**: [access:set-window](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/SetCourseAccessWindow.php) — `--until="Y-m-d H:i"` / `--forever` / `--revoke`, с reason/by для аудита. Фильзамет-экшен не заводился (v1 — artisan).
- **Не тронуто**: строки/статусы/суммы платежей, conditional-механика H4396 (её флаг независим), долги/обещания.
- **Тесты**: [CourseAccessWindowTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/Access/CourseAccessWindowTest.php) 11/11 (нет строки = прежнее; флаг OFF = прежнее; истекшее окно режет ключи и плеер платит стеной; живое окно открывает; NULL = вечное исключение спустя годы; окно точечно по курсу; отсечка date-driven; магазин возвращает курс в «покупаемое»; API-кабинет под тем же предикатом; upsert/clear; artisan-команда). Регрессия: ConditionalAccessGateExpiry+RecordingGate+Kochergina 48/48, RecordingAccessPolicy+каталог 51/51. Pint clean.
