# H4978: `app/Http/Controllers/StudentController.php` Phase 1 split into 2 `App\Http\Controllers\Concerns` traits, no behavior change (Sonnet 5 `claude-sonnet-5`, 16-09-2026)

`StudentController.php` was 1511 lines. A read-only method inventory found it riskier than the `Kernel.php` (H4952) and `routes/web.php` (H4941) precedents: two `public static` methods (`getUserUnlockedTariffs`, `parseVideoId`) are called externally by literal class name, `dashboard()`/`showLesson()` are god methods needing internal decomposition first, and 4 routes had zero direct test coverage. This handoff scopes to **Phase 1 only** — the two lowest-coupling, zero-cross-call domain groups — leaving the god methods and externally-called statics for follow-up handoffs.

- **New traits** (`app/Http/Controllers/Concerns/`): `ManagesCourseResources` (`downloadCourseMaterials`, `courseLibrary`, `downloadCertificate`, `downloadCertificateImage`) and `ManagesStudentMiscPages` (`calendar`, `disconnectMessenger`, `openLessons`, `skillDrills`, `messages`) — 9 methods total, `StudentController.php` shrunk 1511 → 1236 lines.
- **Pure move, byte-identical:** every moved method's docblock+signature+body verified byte-identical to its pre-move slice via a scripted extraction/diff pass (9/9 pass); `route:list` fingerprint identical before/after — Phase 1 uses traits, not sibling controllers, so route bindings are untouched (zero diff, not just a normalized match).
- **New test coverage:** 3 of the 4 previously-uncovered Phase-1 routes (`downloadCourseMaterials`, `downloadCertificate`, `downloadCertificateImage`) get feature smoke tests (`tests/Feature/StudentControllerPhase1SmokeTest.php`, 4 tests) proving the moved trait methods still resolve and respond correctly (happy path + locked-student path for materials; PDF/JPEG download assertions for certificates).
- **External-call sweep:** `grep -rn "StudentController::"` across `app/` confirms none of the 9 moved methods are called externally by literal class name — only `getUserUnlockedTariffs`/`parseVideoId` are (both explicitly out of Phase 1 scope, unaffected).
- **Verification:** `php -l` clean on all 4 touched/new files; Pint clean (1 auto-fix: `class_attributes_separation`, unary/not-operator spacing — cosmetic, same precedent as H4952); full `phpunit` suite: 5708 tests, 28623 assertions, 1 error + 3 failures — reconciled against an unmodified `origin/main` baseline run of the same 4 tests (identical result: 3 failures, 0 errors) confirming `GrammarLabImportSearchTest::test_entitled_search_json_and_compare_and_bookmark` (malformed-UTF-8 JSON encoding), `Shop\CatalogPrettyUrlsTest::test_teacher_facet_resolves_by_name_and_filters_courses` (404), and `VitrinaWaitlistPageTest::test_teacher_links_use_natural_name_and_short_facet_resolves` (404) are the same pre-existing baseline as H4952/H4941, unrelated to StudentController.php; the 1 error (`AdminDocumentLibraryTest`, a Symfony Finder `Interrupted system call` scanning `app/Filament/Resources/TariffResource`) did not reproduce on the clean baseline run and is a transient macOS filesystem flake, not a regression. All 4 new `StudentControllerPhase1SmokeTest` tests pass green.
- **Fence:** no behavior change — a pure file-split plus new test coverage, same shape as the routes/web.php (H4941) and Kernel.php (H4952) precedents. Money-adjacent logic untouched.
