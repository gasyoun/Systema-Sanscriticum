# H5062: риск-скоупед независимый review-гейт для исполняемого кода активирован в shadow-режиме (OxAlpha `opencode/z-ai/glm-5.3-flash`, 17-09-2026)

Реализация неактивного дизайна [H3546](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/OXALPHA_STATUS_GATE_DESIGN_2026.md): bounded independent review gate для PR с исполняемым кодом.

- **Новый workflow [`oxalpha-review-gate`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/.github/workflows/oxalpha-review-gate.yml)** (тот же job id, что предписывал дизайн; standalone-файл по прецеденту H4074, чтобы месячный schedule не дёргал цепочку деплоя ci.yml). Ровно один вывод `pass`/`fail`/`skip`: skip — diff не матчит ни один паттерн исполняемого кода (дизайн §1, doc-only PR никогда не блокируются); pass — отдельные Standards- и Spec-вердикты с evidence-ссылками от независимой сессии; fail — вердикта нет в пределах bounded-ожидания (timeout), вердикт malformed/stale (INCONCLUSIVE никогда не PASS), P0/P1 без регрессионного теста, либо затронуты чувствительные пути (дизайн §3: деньги/безопасность/прод) без строки `Gate human approval: @login` от человека, отличного от автора PR, в теле PR.
- **Независимость механически:** независимая сессия постит чек-ран `oxalpha-independent-verdict`, привязанный к тестируемому head SHA, скриптом [`tools/oxalpha_gate_verdict.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tools/oxalpha_gate_verdict.py); валидатор отвергает `reviewer.independent=false` (само-ревью автора не удовлетворяет гейт) и любой вердикт с чужим head SHA.
- **Kill switch и откат:** репо-переменная `OXALPHA_REVIEW_GATE_DISABLED=true` даёт нейтральный skip без ослабления прочих защит; полное отключение — удалить один файл workflow (секция Rollback дизайна). Гейт — shadow (не required), человеческий флип в branch protection — отдельный аудируемый шаг (дизайн §4 шаг 4).
- **Таксономия путей без расширений:** матчер [`tools/oxalpha_gate_match.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tools/oxalpha_gate_match.py) переносит паттерны §1/§3 один-в-один; единственная документированная интерпретация — `database/migrations/*money-or-access*` прочитан как intent-глобы `*money*`/`*access*` (записано в ARMED-блоке дизайн-дока). Blade считается исполняемым только при изменениях логики (`@if/@php/auth`…).
- Тесты: hermetic fixture battery 68 проверок — [`test_oxalpha_gate_match.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tools/test_oxalpha_gate_match.py) (40: паттерны, исключения decision-5, logic-blade на временном git-репо, sensitive-детекция), [`test_oxalpha_gate_verdict.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tools/test_oxalpha_gate_verdict.py) (16: malformed, missing repro, P0/P1 без регрессионного теста, stale head, BOM), [`test_oxalpha_gate_conclude.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tools/test_oxalpha_gate_conclude.py) (12: kill switch, timeout, sensitive approval, pass/fail лестница). Батарея выполняется самим workflow на каждом прогоне.
