# H4832: поверхность тира Top «Преподавательский глоссарий» — 5 000 ₽/мес членская страница над зарегистрированным агрегатом (ox-alpha, opencode `z-ai/glm-5.3-flash`, 15-09-2026)

Рулинг MG 14-09 («делаем, в следующий раз смелее»): членская поверхность тира Top (5 000 ₽/мес), потребляющая ТОЛЬКО зарегистрированный в kosha агрегат `stenogrammy-teaching-glossary` (1 513 строк: кириллическая форма → SLP1 лемма, частота ≥ 20, 42-курсовой профиль). ФЕНС: `stenogrammy/`-пути не открываются никогда (152-ФЗ) — агрегат по построению не содержит строк приватного корпуса, дисциплина оговорена в миссии, не в отказе.

- **Данные** ([`teaching-glossary:import`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/ImportTeachingGlossary.php)): читает агрегатный TSV с диска (путь аргументом; на проде — `storage/app/teaching-glossary/`), шапку проверяет fail-loud, пишет в [`teaching_glossary_terms`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/migrations/2026_09_15_090000_create_teaching_glossary_tables.php) + `teaching_glossary_courses` полным рефрешем в транзакции (идемпотентен), `--dry-run` ничего не пишет. Сам TSV в репозиторий НЕ коммитится — датасет restricted-тира.
- **Гейт двухключевой, по дому:** [`/dvaram/teaching-glossary`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/routes/web.php) → [`TeachingGlossaryController`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/TeachingGlossaryController.php): `features.teaching_glossary` (`TEACHING_GLOSSARY`, default OFF → 404, dark до включения MG) + `ClubEntitlement::allows(user, 'teaching_glossary')` — новая capability в [`config/membership.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/config/membership.php) стоит на тире `top`; не-член, Basic и Club получают тот же 404. Истёкший грейс закрывает страницу немедленно (активность по датам, как во всём членстве).
- **Страница**: поиск по форме/глоссе/SLP1-лемме, сортировка по частоте, сворачиваемый профиль по 42 курсам, `noindex, nofollow`.
- **Тесты**: [`TeachingGlossarySurfaceTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/Membership/TeachingGlossarySurfaceTest.php) (8: гость → логин; OFF → 404 даже для Top; без членства/Basic/Club/истёкший → 404; Top → 200 с данными; поиск) + [`TeachingGlossaryImportTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/TeachingGlossaryImportTest.php) (5: импорт+профиль, dry-run, идемпотентный рефреш, fail-loud шапка, отсутствие файла). Пакет `tests/Feature/Membership/` — 132/132 зелёные, Pint чист.
- **Остаток (человек):** импорт агрегата на проде (`php artisan teaching-glossary:import storage/app/teaching-glossary/headwords.tsv --courses-path=storage/app/teaching-glossary/by_course.tsv`) и флип `TEACHING_GLOSSARY=true` — оба шага MG-гейт.
