# H4514: автогенератор обложек уроков — рендер датированных плашек по расписанию .92 и авто-загрузка в Drive-папки курсов (OxAlpha z-ai/glm-5.3-flash, 10-09-2026)

Иван (вёл папки обложек вручную) выпал; «Обложка найдена?» в ZOOM 1.4 больше не зависит от людей: новый ежедневный таймер на .91 сам рендерит и загружает `YYYY-MM-DD.jpg` в Drive-папку каждого курса на неделю вперёд. Компаньон к [H4513](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4513-OxAlpha_Systema-Sanscriticum_n8n-zoom-cover-bypass-and-infra-verdict_10.09.26.md) (тот чинит граф и вердикты — этот даёт источнику обложек данные).

- **Генератор** ([ops/covers/generate_covers.py](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/ops/covers/generate_covers.py)): уроки — mysql `laravel` на .92 через SSH с .91 (`root@192.168.200.92`, ключ; пароль БД читается из удалённого `.env` внутри .92 и не покидает её); маппинг `meeting_id -> drive_folder_id` — вкладка Settings листа Automation_DB как CSV через Drive `files.export`; join по `COALESCE(s.zoom_meeting_id, c.zoom_meeting_id)` — колонка расписания почти всегда NULL, рабочая — курсовая.
- **Рендер** — Pillow, 1920×1080 в палитре курса (бордо/золото/крем/красный): название курса, день недели, дата (чипы + медальон), ORS-вордмарк, samskrtam.ru; шрифты DejaVu (кириллица). Образец: [h4514-cover-sample-2026-09-17.jpg](https://gasyoun.github.io/h4514-cover-sample-2026-09-17.jpg) — на аппрув MG.
- **Идемпотентность**: точный запрос ZOOM 1.4 (`name = 'YYYY-MM-DD.jpg' and trashed = false and '<folder>' in parents`) — существующий файл НИКОГДА не перезаписывается; повторный прогон: 13/13 EXISTS, missing 0. Обложки уроков Ивана не тронуты (в папке «Хинди с Костиной» лежат дубликаты одного и того же jpg со старой датой внутри — генератор их не трогает).
- **Таймер на .91**: `uprava-covers.timer` — daily 04:00 UTC = 07:00 МСК (до дневных занятий), `Persistent=true`; юниты в [ops/covers/deploy/systemd/](https://github.com/Systema-Sanscriticum/blob/main/ops/covers/deploy/systemd/), состояние на .91 — `/opt/covers/` (venv+Pillow, `creds/gdrive.json` 0600 — экспорт n8n-креда «Google Drive account», полный `drive` scope, staging-копия из `/opt/n8n/storage/` удалена после установки).
- **Первый прогон**: 12/12 загружено, 0 отказов, 0 unmapped — папки всех курсов на 8 дней вперёд закрыты (включая «Созвон отдела Заботы» → его Settings-папку). df .91 до/после идентичен (37G/11G, 78%).
- **Инфра-факт (найден пробой, не спекой)**: прямой public-IP путь .91→.92 закрыт (22 и 443 — TCP blocked), но LAN 192.168.200.0/24 между боксами жив (samskrtte.ru с .91 резолвится в 192.168.200.92); ssh-ключ .91→.92 авторизован в `authorized_keys` .92 (10-09-2026, строка `h4514-covers-91to92` — root@samskrtam50) — handoff-предположение «ключ уже настроен» было ложным, починено минимально.
