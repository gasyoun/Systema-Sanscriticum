# H5163: report:first-time-buyers — первые покупатели пилота новичков, возвраты и продолжения раздельно (Sonnet 5 `claude-sonnet-5`, 20-09-2026)

_Created: 20-09-2026 · Last updated: 20-09-2026_

**Репортинг-нога пилота привлечения новичков (H5163): [`report:first-time-buyers`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/ReportFirstTimeBuyers.php) — read-only когортный отчёт «первые в жизни покупатели» по каналам.** Когорта = юзеры, чья ПЕРВАЯ доходная покупка (по `first_paid_at`, фолбэк `created_at`) попала в окно `--days` (дефолт — всё время); семантика выручки зеркалит `report:channel-roi` (H3332): `real()`, тариф вне `Расход`/`salary_payout`/`deposit`/`trial` — трипваер ₽500 (марафон + гидированное вводное) считается выручкой. Возвраты — отдельной колонкой (`status='refunded'`, оригинальная положительная сумма; нетто = гросс − возвраты), продолжение — отдельной колонкой (вторая и далее покупки после первой, колонка «позже, ₽» = гросс − первая покупка); покупатель с единственным возвращённым платёжом всё равно считается первым покупателем с нетто 0. Атрибуция — `Lead::effectiveSource()` (ручной source > inferred_source > utm_source) + `utm_campaign`, `--by-source` схлопывает кампании; неатрибуированные покупатели попадают в канал «—», а не выбрасываются — строка ИТОГО сходится с финансами, дыры атрибуции видны. Колонка «первый ₽500» — доля входа через трипваер. Деньги/доступ/флаги не тронуты (read-only, проверяется тестом на неизменность строк). Тесты: [`ReportFirstTimeBuyersTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/ReportFirstTimeBuyersTest.php) — 3 случая: когорта+возвраты+продолжение+«—»-канал+deposit-исключение+read-only, окно `--days` по дате первой покупки, `--by-source`. Хоумпейдж-нога пилота (маршрут «бесплатный предпросмотр → вводное ₽500», правдивость нагрузки, истории учеников) — отдельно, гейты на человеке.
