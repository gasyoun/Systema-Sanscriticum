# Чат поддержки: черновик студента не теряется при сбое сохранения; повтор очереди без дубликата; доступная отправка (H6300, GLM 5.3 `zai-coding-plan/glm-5.3`, [PR #3119](https://github.com/gasyoun/Systema-Sanscriticum/pull/3119), merged 24-10-2026)

_Created: 20-11-2026 · Last updated: 20-11-2026_

Ремонт Livewire-пути отправки в веб-чате поддержки. Раньше [`StudentChat::send()`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Livewire/StudentChat.php) чистил поле до записи входящего: сбой БД съедал черновик студента, а сбой диспетчеризации ответа молчал — без состояния повтора. Теперь черновик чистится только после успешного сохранения; при сбое сохранения текст остаётся в поле, а ошибка объявляется скринридеру (`aria-live="polite"`). При сбое очереди появилось состояние повтора: `retryReply()` диспетчеризирует только job ответа из последнего сохранённого сообщения текущего пользователя — входящее не пишется заново, дубликата не возникает; чужому пользователю повтор недоступен, а если бот/куратор уже ответил после сообщения — скип. Приватный текст не попадает ни в логи (`report()` несёт только класс ошибки, без SQL-биндингов), ни в персистентность браузера (textarea без `name`/`id`, `autocomplete="off"`); кнопка-иконка отправки получила `aria-label`, поле ввода — доступное имя. Тесты: [`CabinetWebChatTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/CabinetWebChatTest.php) 8/8 (4 новых поведенческих: сбой сохранения сохраняет черновик без записи, повтор без дубликата входящего, скоуп повтора на своего пользователя, a11y-разметка), потребительские наборы 14/14, Pint чист.
