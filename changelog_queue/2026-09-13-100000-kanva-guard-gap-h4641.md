# H4641: канва-гвардия — рендер-тест /dvaram, канва-факстура cabinet:probe, Semgrep-правило на unqualified inline FQCN (OxAlpha z-ai/glm-5.3-flash via opencode, 13-09-2026)

Три системных затвора на класс инцидента 10–13.09.2026 (Sev-1: `/dvaram` 500 — неквалифицированный inline `App\Models\Schedule::where(...)` в namespaced-файле резолвился в `App\Http\Controllers\App\Models\Schedule`; 43 ошибки / 9 студентов / ~3 дня до детекта; SOS-фикс — [PR #2516](https://github.com/gasyoun/Systema-Sanscriticum/pull/2516)). До этого класса не видел **никто**: ни feature-тесты (студент без курса-учебника проходил мимо ветки), ни `cabinet:probe` (smoke-студент не был в курсе канвы), ни SAST (правила не было).

- **Feature-тест** [`StudentDashboardKanvaBranchTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/StudentDashboardKanvaBranchTest.php): курс с заголовком семейства канвы (`TextbookScale::courseFamilyPublic` → kochergina) + группа + урок канвы + факт посещения → `GET /dvaram` = 200, `canvasByCourseId[course]` несёт family/курсор; второй тест — студент без канвы тоже 200. Рендер-инъекция проверена: с возвращённым багом тест падает ровно инцидентным фаталом `Class "App\Http\Controllers\App\Models\Schedule" not found`.
- **Канва-факстура пробы** ([`ProbeCabinetHealth::ensureKanvaFixture()`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/ProbeCabinetHealth.php) + `cabinet_probe.kanva_fixture_course_id`): перед student_surfaces smoke-студент идемпотентно дозаводится в группу пиннутого курса и получает один факт посещения (курс человек заводит один раз, ID — в env, как homework-факстура H37xx); пропуски — soft, не critical. Прогон на живом конфиге: со возвращённым багом `cabinet:probe` в один прогон даёт `[critical] student /dvaram: HTTP 500 на /dvaram` («Кабинет болен»), на здоровом main — «Кабинет жив». Тесты факстуры — 5 новых + 33 существующих probe-тестов зелёные.
- **SAST-правило** [`.semgrep.yml`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/.semgrep.yml) `unqualified-inline-app-fqcn` (ERROR, в блокирующем `semgrep.yml` через `--config .semgrep.yml`): `App\Seg\Name` без ведущего backslash в namespaced-деревьях (`app/`, `database/`, `tests/`) — вне комментариев и `use`/`namespace`. Репо-свип: 0 инстансов (26 упоминаний в докблоках исключены правилом); посаженный в `app/` пример — 1 находка. Глобально-неймспейсные `routes/`, `config/`, blade — вне правила (там inline `App\...` резолвится верно и легитимен).
- Остаток для прода (GTD): завести пиннутый курс-факстуру («Кочергина…», is_active) + группу на проде и прописать `CABINET_PROBE_KANVA_COURSE_ID` в prod `.env` — без этого канва-ветка пробы тихо пропускается.
