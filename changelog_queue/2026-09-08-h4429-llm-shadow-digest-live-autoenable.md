# H4429: теневая неделя LLM-ветки видна ежедневно + живое включение без переспрашивания (OxAlpha z-ai/glm-5.3-flash, 08-09-2026)

Рулинг MG 08-09-2026 по закрытию [H4404](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4429-OxAlpha_Systema-Sanscriticum_llm-drafts-shadow-digest-daily-tg_08.09.26.md): «live after 1 week without re-asking, the data in shadow week in telegram to Marcis daily» — данные тени приходят Марцису в Telegram ежедневно, живой режим включается сам после недели тени, переспрашивать не нужно. Исполнитель — [H4429](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4429-OxAlpha_Systema-Sanscriticum_llm-drafts-shadow-digest-daily-tg_08.09.26.md).

- **Блок «LLM-тень» в утренней сводке** ([SupportDailyDigest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Support/SupportDailyDigest.php)): сообщение H3242 (08:10 MSK, ADMIN_TELEGRAM_ID) дополняется разделом за вчера — «Сформулировано (тень): N», «Отказы R3: money 2, spam 1», пример черновика до 200 символов с моделью, оценка расхода дня по прайсам OpenRouter (неизвестная модель — строка опускается, не ноль), прогресс «Дней тени подряд: K из 7». Секция появляется только при включённой ветке и только в дни с событиями; после включения живого режима показывает отправки и штамп включения.
- **Авто-рубильник** [support:llm-live-enable](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/EnableSupportLlmLive.php) (расписание 09:00 MSK, сразу после сводки): считает, сколько последних дней подряд (включая вчера) ветка формулировала ответы в тени; **7 продуктивных дней подряд → живой режим включается сам**. Пустой день обнуляет серию — кратковременная тишина трафика не переключает ветку вслепую. `SUPPORT_DM_LLM_DRAFTS=false` запрещает включение (лог-отказ) — рубильник не может оживить мёртвую ветку.
- **Механика включения**: штамп `support_llm_live_enabled_at` в `marketing_settings` (миграция 2026_09_08_120000; авто-инвалидация кэша через штатный `saved`-listener) читается [SupportDailyDigest::llmLive()](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Support/SupportDailyDigest.php) — та же точка, которую теперь проверяет конвейер H4404 вместо голого env-флага. ENV-флаг `SUPPORT_DM_LLM_DRAFTS_LIVE=true` продолжает работать как прямой включатель (мгновенный откат = `false` + `config:cache`); отключение рубильником = `SUPPORT_DM_LLM_DRAFTS=false`, штамп не удаляется.
- **Аудит**: включение пишется событием `dm_llm_live_enabled` (стёкл with streak_days, required_days, правило-рулинг); идемпотентно — второй прогон no-op.
- **Не тронуто**: R3-отказы (деньги/доступы/спам), cooldown «один ответ на серию», BM25-порог 8.0 — всё в коде, как в H4404; рубильник не умеет обходить ни один из них.
