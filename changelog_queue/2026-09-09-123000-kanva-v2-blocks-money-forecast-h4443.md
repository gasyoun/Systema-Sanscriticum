# H4443: Канва v2 — блоки (маркеры/тарифы), деньги неоплаченных блоков (админка), прогноз финала с каникулами (OxAlpha z-ai/glm-5.3-flash, 09-09-2026)

Решения MG 09-09 (чат): к канве добавлены (1) блоки, (2) деньги, (3) прогноз месяца-года завершения — с учётом темпа преподавателя, двухнедельных новогодних каникул и летнего перерыва (середина июня → середина сентября, максимально поздно — середина октября).

- **Блоки:** номер блока — маркер *X.Y* из заголовка записи-курсора (эмпирика: «Кочергина 4 (читка)» = блок 3, арифметика дала бы 1); итого блоков — `Tariff.block_number` курса (коммерческая истина: у гр.53 — 20 продающихся блоков, не 40/4) → fallback записи уроков → fallback ceil(total/4). В посте: «урок 14/40 · блок 4/20 (осталось 16)».
- **Деньги (ТОЛЬКО админка, в публичный пост нельзя — тест на отсутствие ₽):** [`CanvasMoney`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/CanvasMoney.php) — неоплаченные блоки по факт-платежам: покрытие через `Payment::coversBlockHalf` (PAID_STATUSES, 'full', диапазоны start/end_block, пол-блока = половина цены, refunds не покрывают); цена — базовый `Tariff` блока (диапазонные тарифы понимаются), фолбэк курсовая цена/блоки с пометкой «оценка». Персонально — в ViewUser-вкладке («неоплачено X ₽ (блоки 5-20)»); групповой свод + СУММАРНО по всем грамматикам — в [AttendanceDashboard](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Filament/Pages/AttendanceDashboard.php) (новая секция «Канва: неоплаченные блоки грамматик»).
- **Прогноз финала:** remaining наших занятий × собственный rolling-темп группы (занятий/неделю, окно 8 нед из Schedule) по календарю вперёд с пропусками: НГ 29.12-11.01, лето 15.06-15.09 (норма) / 15.06-15.10 (макс. поздно, темп ×0.75). Выход: «финал: март 2028 (макс. поздно — март 2029)». Конфиг: `edutech.holidays`, `lessons_per_block`, `cadence_window_weeks`.
- Тесты: `KanvaBlocksMoneyForecastTest` 9 (маркеры→блок, тарифы→итого, покрытие диапазонами, full=0₽, refund не покрывает, пол-блока=половина, НГ-переход, лето-норма/поздно, отсутствие ₽ в TG) + регрессия 46/46 зелёная локально; CI-флейк SurveyStudentEmailInvite (вне диффа, локально 12/12) — admin-merge с фиксацией.
