# H4384: подтверждение отмены с причиной, «N-е из M», последним занятием; слотовые уведомления «сегодня занятия нет» и об оплате блока (правила MG 08-09, OxAlpha z-ai/glm-5.3-flash)

Правила MG 08-09 (чат, сессия отмены «Рецитация сутр Патанджали вт 15:00»): каскад +7д — семантика отмены по умолчанию, датированная single-отмена (H4253) — запасная; подтверждение бота в чате обязано озвучивать причину отмены (ровно одна главная), дату/время следующего занятия и его номер «какое оно по счету, например 15/16 — 15-е из всего 16», плюс строку о последнем занятии потока; в обычный слот группы без занятия бот напоминает «сегодня занятия нет» с датой следующего; после каждого 4-го занятия блока — напоминание об оплате (до какого числа и что неоплатившим и не предупредившим закрывается личный кабинет — остаются игры, бесплатные вебинары и оплата). Преподаватели грамматику команд не знают — при неузнанной попытке «отмен…» бот раз в сутки шлёт подсказку формата распознанному sender'у.

- **Серия/номера:** [LessonSeriesInfo](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/LessonSeriesInfo.php) — номер занятия парсится из тега титула «(#13, 08.09.26)» (плейсхолдер {N} генератора), общее число потока = максимум тега по всем строкам группы ВКЛЮЧАЯ мягко удалённые (single-отмена не занижает M). Номер хранится только в титуле — отдельной колонки нет.
- **Подтверждение:** [CancelNoticeRenderer](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/CancelNoticeRenderer.php) — `build()` (reply-каскад H4199 + artisan) и `buildDated()` (датированная H4253): заголовок «❗ Занятие отменено (причина)», строка «Следующее занятие: 15.09.2026 в 15:00 (МСК) — 13-е из 16», «Последнее, 16-е занятие пройдет 06.10.2026» (если последнее ещё в будущем), «Запланированных занятий больше нет» при отмене последнего.
- **Причина — ровно одна главная:** [CancelReasonResolver](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/CancelReasonResolver.php) — названная в команде («Отмена занятия: нет кворума», «Отмена 08.09 — гос. каникулы») → авто «отпуск преподавателя» (окно H4253 покрывает дату) → авто «каникулы» (флаг группы H3790) → без причины. Санитайзер режет разметку/длину (HTML parse_mode).
- **Грамматика:** reply-команда H4199 расширена опциональной причиной («Отмена занятия: …»); датированная H4253 принимает двоеточие-префикс («Отмена: 08.09») и причину после «—»/«:»; хвост, начинающийся с даты, никогда не считается причиной reply-команды (негативный lookahead) — «Отмена: 08.09» всегда уходит в датированную ветку.
- **Подсказка формата:** [CancelUsageHint](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/CancelUsageHint.php) в [ProcessTelegramZapisiUpdate](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Jobs/ProcessTelegramZapisiUpdate.php) — текст начинается с «отмен…», но команда не адресована (не reply/не матчится) → whitelist H4199 или панельный пользователь H4253 получает шпаргалку раз в сутки на чат (клейм TelegramSendGuard); студенты и незнакомцы — молча.
- **Слотовые уведомления:** [SlotNoticeService](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/SlotNoticeService.php) + `zapisi:slot-notices` (каждые 5 мин рядом с `zapisi:remind-classes`, no-op без флага бота). «Сегодня занятия нет»: обычный слот выведен по последнему прошедшему занятию группы (день недели + время), окно T-lead…T-lead+10 мин, на дату нет ни одной строки, будущее занятие существует, отпуск группы/преподавателя гасит — дедуп клеймом на (чат, дата). Оплата блока: строка с {N} % 4 == 0 закончилась в последние 48 ч и есть следующий блок — напоминание с дедлайном = дата ближайшего занятия; дедуп клеймом на строку расписания на неделю.
- **Artisan:** `schedule:cancel {id} {--reason=}` теперь тоже шлёт в чат группы то же подтверждение (агентский канал = одинаковый UX).
- **Гид:** в [CURATOR_ADMIN_GUIDE_RU.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/CURATOR_ADMIN_GUIDE_RU.md) добавлен раздел «Отмена занятия через @zapisi_ORSbot» — обе команды, разница каскад/single (ранее разница была видна только в handoff'ах H4199/H4253 и код-докблоках), формат подтверждения.
- **Тесты:** +12 (ZapisiCancelClassCommandTest 14, DateAwareCancelCommandTest 10, ZapisiCancelUsageHintTest 5, ZapisiSlotNoticesTest 6): причина в заголовке (названная/авто), «13-е из 14», строка о последнем, «больше нет», двоеточие-префикс, подсказка (whitelist/ACL/молчание студенту/раз в сутки), слот «сегодня занятия нет» (есть/нет занятия сегодня), оплата 4-го блока (дедуп, отказ на не-блочном номере).
- **Прод-контекст 08-09:** занятие #639 «Рецитация вт 15:00» отменено каскадом (`schedule:cancel 639`, 4 строки +7д → следующее 15.09 15:00 «13-е из 16»); reply «Отмена занятия» на пост-напоминание пришёл в 15:02 МСК — уже после старта, бот корректно отказал («lesson already started», лог-онли) — первый реальный заход команды, все гейты до отказа пройдены.
