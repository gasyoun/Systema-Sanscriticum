# H4840: видимый секундомер во всех играх + пер-вопросная телеметрия sort/cloze/table (ox-alpha, opencode `z-ai/glm-5.3-flash`, 14-09-2026)

Рулинг MG 14-09 («оба пункта — да»): (а) добрать крючки трудности в движки sort/cloze/table; (б) показать игроку секундомер.

- **Секундомер (`public/lila/{match,sort,cloze,table}/engine.js` + `.timer` в каждом `engine.css`):** тикает с нового раунда (mm:ss, `role="timer"`, tabular-nums), замирает на решённом раунде, сбрасывается «Заново». Живёт в тулбаре рядом со счётом; тёмная тема наследуется через `--ink-soft`.
- **Крючки (тот же контракт `item_result`, что H4692, сервер не менялся):**
  - `sort` — ms до первой раскладки карточки в ведро, wrong при неверном ведре; l = карточка, r = правильная группа (18 вопросов в раунде `genders`).
  - `cloze` — ms до первого выбора в пропуске (событие `change`), wrong при неверном ответе; l = глосс (или сам ответ), r = верное слово (11 пропусков в `verb-fill`).
  - `table` — ms до первой укладки карточки в ячейку, wrong при неверной ячейке; l = «заголовок строки · заголовок столбца», r = верная форма (20 ячеек в `verb-conjugation-grid`).
- **Верификация — Playwright E2E по каждому семейству на локальном сервере над `public/`:** секундомер тикает → замирает на решении → сбрасывается «Заново»; ровно 1 `item_result` на раунд (sort: 3 POST = start + complete + item_result), у всех вопросов ms > 0, wrong-счётчик растёт на ошибочных проверках; match — регресс-проверка (10 вопросов, ms > 0). `node --check` 4/4.
- **Сервер/PHP не тронуты** — контракт H4692 (whitelist, капы 40 items / ms ≤ 1 ч / wrong ≤ 50) принял все три семейства как есть.
