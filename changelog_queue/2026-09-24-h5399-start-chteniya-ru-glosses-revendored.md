# H5399 — 410 русских глосс в SRS-колоде «Старт чтения» вернулись из неизменившегося пина; остаток в 465 слов измерен и упёрся в тупик (Opus 5 `claude-opus-5`, 24-09-2026)

Хэндофф [H5399](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5399-Opus_Systema-Sanscriticum_start-chteniya-empty-russian-glosses_24.09.26.md) читал 841 строку `status: empty` в [`resources/data/nkrya_lint/lemmas_gloss_lint.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/lemmas_gloss_lint.tsv) как 841 недостающую русскую глоссу. Апстрим-половина того же хэндоффа в kosha нашла другую причину: **838 из 841 пустых строк — это ровно все строки пака `subhashita-beginner`**, то есть форма ошибки читателя, а не отсутствие лингвистики. Сборщик заморозки звал скалярный `as_str()` на `gloss_ru`, который в схеме субхашит лежит **списком словарей `{surface, lemma}` параллельно `lemma_slp1`**, и получал пустую строку. Глоссы всё это время были в пине: MANIFEST заморозки сам показывал 85.3 % покрытия по лемма-слою того самого файла, который производный TSV звал пустым.

- **Перевендорена заморозка** — `python scripts/vendor_cohort_start_chteniya_packs.py`, который перед записью сверяет sha256 и число байт каждого файла против MANIFEST. [`resources/data/cohort_start_chteniya/lemmas_for_srs.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/cohort_start_chteniya/lemmas_for_srs.tsv): 92 460 → 98 261 байт (`sha256 e0052c7c88f4…`), строка MANIFEST перепинена. `hitopadesa-0.json` побайтно прежний — его уже привёз H5398.
- **Линт перепрогнан офлайн** — `python scripts/nkrya_gloss_lint.py lemmas --offline`. `status: empty` 841 → **431**, `ok` 121 → 185, `not_russian` 34 без изменений. 410 русских глосс вернулись из неизменившегося пина: ни одной правки руками, ни одного перевода, ни одного голосования.
- **Приёмка H5399 не взята, и взять её нашими данными нельзя.** Планка — минус 80 % по `empty + not_russian`; получилось 875 → 465, это 46.9 %. Оставшиеся 465 лемм (428 субхашит + 37 «Хитопадеши») **не имеют русской глоссы ни в одном источнике, которым мы владеем** — измерено новым [`scripts/h5399_residual_gloss_census.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/h5399_residual_gloss_census.py) по четырём источникам сразу: `sa_ru_glossary.json` (45 289 ключей) покрывает 2, слоты пака субхашит — 1, слоты пака «Хитопадеши» — 1, русские колоды Memrise/Anki из `database/seeders/data/` (1 767 ключей) — 3; объединение **5 из 465 (1.1 %)**. Это ровно те редкие слова, которые корпусный глоссарий с частотным полом 2 и обязан терять (`autkārṣya`, `ajāgalastana`, `anargha`, `jāragarbha`, `kathāmukha`, `nagnakṣapaṇaka`). Лицензированный запасной путь из задания на этой машине тоже отсутствует: единственный достижимый артефакт Кочергиной, который мог бы нести глоссы, — `CORRECTIONS/Kochergina-1987_29007.txt` — это **список заголовочных слов в разреженном SLP1 без единой русской буквы**, а конкорданс H4748 в kosha (`data/concordance/kochergina_corpus_concordance.tsv`) — джойн «лемма → локус» без колонки глоссы.
- **Тупик записан** (правило 11 политики приёмки) вместе с очередью на человека: [`resources/data/nkrya_lint/lemmas_gloss_residual.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/lemmas_gloss_residual.tsv) — 465 строк с локусом, английской глоссой и колонками `candidate`/`candidate_source` для тех пяти, что закрываются апстримом. Из этого файла режутся листы голосования по ≤10 карточек (~47 листов); правка самого `lemmas_for_srs.tsv` в этом репозитории запрещена — это пин заморозки, чинить надо в kosha и перевендоривать. Полные числа и способ воспроизведения: [`docs/EVIDENCE_H5399_START_CHTENIYA_RU_GLOSS_RESIDUAL_24-09-2026.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/EVIDENCE_H5399_START_CHTENIYA_RU_GLOSS_RESIDUAL_24-09-2026.md).
