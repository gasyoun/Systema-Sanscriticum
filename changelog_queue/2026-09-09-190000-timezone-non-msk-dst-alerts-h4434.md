# H4434: таймзоны для нон-МСК учеников — dual-display, DST-будильник, временное пребывание (OxAlpha z-ai/glm-5.3-flash, 09-09-2026)

Рулинги MG 09-09-2026 (плановое интервью): гости — JS-детект+cookie; нон-МСК — dual-display («11:00 МСК · 16:00 ваше»); census сразу; Google-верификацию стартовать. Доктрина «doubt everything, deepen and widen» дала развилки: ICS-фид не будильник (Google опрашивает подписки 12–24 ч, T−1ч через подписку не доходит); Blade-рендер не работает для гостей/виджета — там клиентская конверсия; VPN-фактор (большинство РФ-учеников за NL/DE VPN) сделал device-TZ главным сигналом, IP-гео отравлено и для авторизованных не используется.

- **Census на проде** ([Uprava tools/timezone_census_slice.py](https://github.com/gasyoun/Uprava/blob/main/tools/timezone_census_slice.py), read-only guard; отчёт [TIMEZONE_CENSUS_H4434_09-09-2026.md](https://github.com/gasyoun/Uprava/blob/main/reports/TIMEZONE_CENSUS_H4434_09-09-2026.md)): 1037 юзеров; `users.country` заполнен на **0 строк** (поле H3909 пусто — не сигнал); телефон 236 RU / ~50 нон-RU (~12 активных 30д); email 99.6%, TG только 32; 200 юзеров затронуты расписанием (85 активных). Вердикт: нон-МСК — десятки, но dual-display + DST-джоб строим (ущерб = сорванное занятие с кворумом-4); tzdb на проде Debian 13 / PHP 8.3 — переходы читаются.
- **Хранение** (миграции 2026_09_09_100000/100100): `users.timezone` + `tz_override` + `tz_override_until` (временное пребывание: уехал на 1.5 мес в Индию — действует до даты, ленивый авто-возврат без крона) + `tz_source` (manual/device/admin); дедуп-леджер `tz_alerts_sent` (уникальный индекс user+transition+stage). Ядро — [User::effectiveTimezone()](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Models/User.php): оверрайд активен до даты, потом постоянная зона; `isNonMskTimezone()` гейтит dual.
- **Захват таймзоны** ([TimezoneController](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/TimezoneController.php)): device-TZ из `Intl.DateTimeFormat().resolvedOptions().timeZone` — VPN-иммунный сигнал (VPN меняет IP, не часы устройства); silent POST с кабинета + чип-подтверждение «сохранили, если ошибка — Изменить» (не модалка); manual-источник старше device (не затирается); селектор «страна→зона» + форма временного пребывания с датой возврата.
- **Dual-display** ([Support\Timezone::render](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Support/Timezone.php)): кабинет — серверно; заголовки дней («Сегодня/дата») в календаре студента считаются в TZ юзера, иначе у калифорнийца «суббота» = пятница по-московски. Публичные поверхности (`/raspisanie`, страница курса, embed-виджет) — клиентская конверсия по `<time data-msk-timestamp>` ([client-tz-convert](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/partials/client-tz-convert.blade.php)): vanilla JS, iframe-safe, без cookie; TG-посты остаются МСК + CTA.
- **DST-будильник** ([DstShiftAdvisor](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/DstShiftAdvisor.php) + `tz:remind-dst-shifts` ежедневно 10:00 МСК): смысл алерта — «локальное время ВАШЕГО следующего занятия изменилось», правила — IANA самой зоны юзера (Мадрид EU-воскресенья, ЛА US-second-Sunday, Дели/Москва — никогда, алертов нет); каденция T−7д / T−1д вечером **по локальным часам юзера** (20:00 его времени) / T−1ч — допстрокой в существующее 60-мин напоминание (отдельного пинга нет); переход, не задевающий занятие, молчит. VPN-гвардия: алерты только по manual/device/admin источникам, никогда по IP.
