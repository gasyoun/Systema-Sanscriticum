# H4001 (Wave 3 leverage-плана): knowledge_chunks dense-нога — bge-m3, HybridRetriever (weighted RRF, BM25-пол), knowledge:index, live-вердикт (OxAlpha z-ai/glm-5.3-flash, 03-09-2026)

Wave 3 плана Telegram support leverage ([PR #2351](https://github.com/gasyoun/Systema-Sanscriticum/pull/2351) + live-прогон [PR #2355](https://github.com/gasyoun/Systema-Sanscriticum/pull/2355)): dense-нога FAQ-ретривала без внешнего vector store — 22 МБ float32 в MySQL, пол BM25 по контракту. Студент-видимые поверхности не тронуты: флаг `FAQ_HYBRID_RETRIEVAL` default OFF, при OFF dense-нога даже не зовётся (туннель не в request-path).

- **`config/knowledge.php`**: driver (`''` → Null, `'ollama'` → Ollama), base_url туннеля, модель `bge-m3:latest` (короткое имя даёт 404), dims 1024, таймаут 5 с без ретраев в request-path (рулинг D2), batch 16, weighted-RRF k=60/depth 20/**веса ног sparse 1.0 / dense 0.5**. Env-инвентарь перегенерирован тем же проходом (+12 ключей, все optional).
- **`knowledge_chunks`** (миграция `2026_09_03_110000`): одна строка на `FaqChunk` — float32 LE BLOB, dims, `content_hash` = sha256(model|dims|searchText) охраняет ре-эмбеддинг; повторный запуск без сдвига хэшей не пишет ничего.
- **Провайдеры** ([`Faq/`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Support/Faq)): `EmbeddingProvider` (пустой вектор = «dense-нога недоступна», НИКОГДА «нет результатов»), `OllamaEmbeddingProvider` (одна попытка, 5 с, malformed/размерность падают громко), `NullEmbeddingProvider` (пусто + один warning). Bind, не singleton — config читается на момент резолва.
- **`knowledge:index`** → [KnowledgeEmbedChunksJob](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Jobs/KnowledgeEmbedChunksJob.php) на очередь `imports`, ретраи внутри джобы (tries=3, backoff 30/120 — обрыв туннеля штатен). Расписание **10:00 МСК — внутри окна GPU-узла Ивана 9–21** (ночной слот гарантированно умирал бы в спящий туннель), двойной гейт: флаг гибрида И настроенный driver.
- **`HybridRetriever`** — дроп-ин уровня `Bm25FaqRetriever` (тот же шейп + аддитивный `bm25_score`), weighted RRF `Σ w/(k+rank)`; равные веса роняли MRR свежего набора ниже BM25-пола (0.852 < 0.899) — вес dense 0.5 возвращает пол. Денежный порог (категория D) остался в домене BM25: `passesThreshold()` читает `bm25_score`, не RRF-скор.
- **Fresh eval-набор** ([`tests/fixtures/faq_rag_eval_fresh.json`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/fixtures/faq_rag_eval_fresh.json)): 1175 входящих строк за 30-дневное окно → 95 кандидатов → 20 размечено поштучно (R6: неоднозначные выброшены), пересечение с 80Q исключено новой опцией `--exclude-fixture`. ПДн анонимизированы ДО выхода с прода; маскирование доказано тестом над самим фикстуром (`FaqRagFreshSetMaskingTest`). «100Q из сентября» на 03-09 неисполнима (окно 2 дня, FAQ-образных ~8 % — стена FINDINGS §635); отклонение зафиксировано.
- **Live-вердикт** (bge-m3 через туннель, раздел в [`docs/FAQ_RAG_EVAL_H2448.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/FAQ_RAG_EVAL_H2448.md)): гибрид ≥ BM25 на ОБОИХ наборах — **80Q: recall@5 83 → 90 %, MRR 0.713 → 0.762; fresh: MRR 0.900 → 0.917; p95 560 мс** (бюджет 2 с). Храповик-гейт `test_live_hybrid_matches_or_beats_bm25_on_both_sets` (skip в CI, запуск `KNOWLEDGE_LIVE_EVAL=1`) валит любую регрессию fusion.
