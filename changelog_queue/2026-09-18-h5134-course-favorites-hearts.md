Сердечко ♥ «направление интересно» — лёгкий сигнал без записи в очередь и без покупки (рулинги MG 17-09-2026: хранение — только кабинет (auth), сигнал — счётчики + витрина направлений, поверхности — «везде: ждун + /k/ + каталог», отдельно от голоса ждуна). Таблица [`course_favorites`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/migrations/2026_09_18_100000_create_course_favorites_table.php) (`user_id`, nullable `course_id`, nullable `waitlist_slug` — для карточек ждуна без карточки курса, напр. kosmografiya; unique на тройку) + модель [`CourseFavorite`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Models/CourseFavorite.php) (ключ `c:{id}`/`w:{slug}`, viewer-хелперы). API тот же контур, что голос ждуна: web-группа, `POST /favorites/toggle` + `GET /favorites`, auth-гейт (гость 401), флаг в контроллере (OFF → 404), throttle 10,1, идемпотентный toggle, «ровно одна цель» (422 при course_id+waitlist_slug вместе или ни того ни другого). Сердечко на трёх поверхностях ([ждун](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/shop/zhdun.blade.php) — рядом с кнопкой голоса, страница курса, каталог-Livewire), гость кликом ведётся на `/login`, залогиненный — toggle в месте без перезагрузки; голоса ждуна (`WaitlistVote`) не трогаются. Кабинет — секция «[Избранное](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/student/partials/favorites-card.blade.php)» (курс/анонс, ссылка, дата, удаление по событию `favorite-toggled`).
