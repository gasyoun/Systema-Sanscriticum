# Плашки занятий делаются сами — из PSD курса и расписания (Opus 5 `claude-opus-5`, 22-09-2026)

- Новый контур [«Плашки занятий»](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/LESSON_BANNERS.md): фон из PSD курса + дата и номер занятия из расписания, JPEG на 7 дней вперёд. Повод: плашки рисовали руками в Photoshop, а ZOOM 1.4 ставит обложкой записи файл `ГГГГ-ММ-ДД.jpg` из папки группы на Google Диске — нет файла, нет обложки.
- PSD разбирается один раз на курс скриптом [`banner_template_from_psd.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/banner_template_from_psd.py) (psd-tools): фон без слоёв даты/номера + `template.json` (рамка, шрифт, кегль, цвет, выравнивание; формат номера выводится из слоя, «(1)» → «({N})»). Рамка не заходит на соседние слои — «(12)» не ложится на «из 16». Шаблон заводится в `/admin/lesson-banners` с превью; шрифты грузятся туда же и хранятся вне git (коммерческие, репозиторий публичный).
- Рендер — GD/FreeType ([`LessonBannerRenderer`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Banners/LessonBannerRenderer.php)), команда `lesson-banners:render` в 04:40. Номер — только из тега титула `(#N, …)` (`LessonSeriesInfo`); имя файла — UTC-дата старта, как ищет ZOOM 1.4; перерисовка по `render_hash` (перенос занятия, новая версия шаблона).
- На Диск кладёт n8n: API `GET /api/lesson-banners/due` + `POST …/{id}/delivered` под `X-Webhook-Secret`, черновик воркфлоу — [`docs/n8n/exports/lesson-banners.json`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/n8n/exports/lesson-banners.json) (папка группы — из Automation_DB/Settings по `meeting_id`, креденшлы ZOOM 1.4). В n8n не залит.
- Флаг `LESSON_BANNERS` **выключен**: команда no-op, API 404. Включение и импорт воркфлоу — отдельным шагом по runbook.
