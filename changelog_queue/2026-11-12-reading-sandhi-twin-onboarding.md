# Ридер: сандхи-двойник «Пословно ↔ В тексте» + онбординг «как пользоваться» — PR #4112 (2026-11-12)

_Created: 12-11-2026 · Last updated: 12-11-2026_

- **Рулинг MG 12-11-2026 по конкурентному ридеру Малиновского (t.me/samskrita2025/356–357): берём два паттерна, офлайн-экспорт — нет (MiMo V2.6 Flash `xiaomi-token-plan-sgp/mimo-v2.6-flash`).** В общем partial ридера [`resources/views/reading/partials/pack.blade.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/reading/partials/pack.blade.php) (публичная демо + кабинетный + курсовой ридер): (1) переключатель режима чтения **«Пословно ↔ В тексте (сандхи)»** — обе формы предложения остаются в DOM, меняются только заметность/размер/порядок (`flex-col-reverse`), тап по слову и H2107-телеметрия работают в обоих режимах; строка-двойник рендерится только там, где `trim(text) ≠ join(form)` (40/65 nala-1, 82/125 hitopadesa-0 — сравнение с вендорным фидом закреплено тестом, не хардкод); режим и состояние онбординга — в localStorage, без JS страница остаётся серверно-в состоянии «Пословно». (2) Онбординг **«? Как пользоваться ридером»** — открыт на первом визите, «Понятно» скрывает, ссылка открывает повторно; вариант про колоду только при `$srsAdd` (публичка остаётся без упоминаний колоды — инвариант `CabinetReadingPackSrsTest` сохранён). **Готча, зафиксированная в коммите:** многострочный `@php … @endphp` в этом partial ломает всю страницу — `storePhpBlocks` Blade (Laravel 13) парит **первый** `@php` в файле (инлайн `@php($srsAdd = …)` в шапке) с **первым** `@endphp` и уводит весь хедер в raw-блок → `ParseError: unexpected endforeach` на рендере; лечение — инлайн-`@php(...)` в том стиле, что уже был в файле (в partial теперь нет ни одного `@endphp`). Тесты: `php artisan test --filter='(ReadingPack|StartChteniya)'` → **63 passed / 6 250 assertions** (+4 новых `ReadingPackTest`), `pint --dirty` чист, `npm run build` — все новые Tailwind-варианты (`data-[sandhi-mode=text]:…`, `aria-pressed:…`) в собранном CSS. Лимит честно указан в PR: «без сандхи» = пословная склейка DCS-форм, не полная досандхи-форма Малиновского (для неё нужен обратный сандхи в фиде kosha).
