# Сшивка контактов поддержки по ФИО: команда с сухим прогоном

Студент писал в аккаунт школы, диалог в поддержке есть, а в кабинете он не привязан: `telegram_id` и `telegram_username` пусты. Канал «от имени аккаунта» в напоминаниях об оплате такого человека не видит — отправлять некуда, хотя чат существует. Так из 204 должников канал достаёт 20, а бот — 32.

Автоматическая сшивка при синхронизации трогать ФИО по-прежнему не имеет права: это политика, закреплённая тестом `test_auto_linker_does_not_match_by_full_name_without_telegram_identity` — в синхронизации нет человека, который увидит ошибку, а «Романов Павел» в базе может быть не один.

Поэтому появился отдельный ручной инструмент — `SupportContactNameLinker` и команда:

```
php artisan telegram-support:link-contacts            # сухой прогон: пары и счётчик, ничего не пишется
php artisan telegram-support:link-contacts --apply     # записать
```

Правило узкое и проверяемое: все слова контакта входят в ФИО пользователя (контакт «Юлия Перевалова, Москва» → «Перевалова Юлия Игоревна» — город, порядок слов и отчество не мешают), слов не меньше двух, и такой пользователь ровно один. Если кандидатов двое — не сшиваем. Если у пользователя уже есть привязанный диалог с другим Telegram-аккаунтом — не перешиваем.

Сшивка контакта подтягивает приватный чат (это делает `saved()` на модели), после чего канал «от имени аккаунта» начинает видеть человека.

Проверки: `SupportContactNameLinkerTest` — однозначное ФИО с городом, два однофамильца, одно слово в имени, уже привязанный другой аккаунт, сухой прогон без записи, команда с `--apply`. Плюс остаётся зелёным `TelegramSupportAnalyticsTest` про запрет автосшивки по ФИО.
