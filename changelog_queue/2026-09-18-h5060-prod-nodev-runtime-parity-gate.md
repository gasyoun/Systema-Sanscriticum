### Added

- **Production no-dev runtime parity gate в CI: `production-profile` job + `scripts/prod_runtime_parity_check.php` (OxAlpha `zai-coding-plan/glm-5.3-flash`, 18-09-2026, H5060).** Класс прод-поломок из PR #2577/#2646/#2648 (dev-only `symfony/yaml` через laravel/sail читался в рантайме → «Class Symfony\Component\Yaml\Yaml not found» на каждом входящем; анонс-манифесты откатили на JSON) больше не воспроизводится основным CI — он ставит vendor С dev-пакетами. Новый job в [`ci.yml`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/.github/workflows/ci.yml) ставит закрытый lock С `--no-dev`, кэширует конфиг (`artisan config:cache`), грузит Laravel и прогоняет реальные JSON-швы: MIC (`MicShadowClassifier`) с флагом OFF (ноль работы, вендоренный лоадер не грузится) и ON (классификация по JSON-близнецам `rules/v1/*.json`, 7 плоскостей) и anons `PublicationManifest::fromFile` на представительном JSON-манифесте (валидация fail-closed + хэш) плюс YAML-без-пакета → отказ с actionable-диагностикой («convert the manifest to .json», контракт H4880-revert). Скрипт — чистый PHP без PHPUnit (в no-dev профиле phpunit нет): exit 0/1 (чек)/2 (boot-зависимость), диагноз называет отсутствующий класс или неподдерживаемый формат с composer-причиной; `PARITY_REQUIRE_NODEV=1` роняет job, если dev-профиль протёк в require. Приёмка: локальный green 10/10 на неизменном дереве под настоящим no-dev профилем; RED-мутации — спрятанный `vendor/barryvdh` (эквивалент require→require-dev при `--no-dev`) → exit 2 с диагнозом `[Barryvdh\DomPDF]`, и YAML-запрос без пакета → actionable-отказ; после отката мутаций дерево снова 10/10. Без БД, секретов, сети; JSON-at-runtime контракт и прод-креденшалы не тронуты.
