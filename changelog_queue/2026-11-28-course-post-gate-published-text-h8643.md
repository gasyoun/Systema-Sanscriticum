# Гейт постов серий теперь видит посты календаря: судит текст, который уходит на площадки, и узнаёт серию по одному маркеру (H8643, GLM-5.4 via ZCode, 28-11-2026)

Гейт полноты поста с курсом (27-11-2026) на проде не узнал ни одного запланированного поста серий: ему передавалось голое тело слота, а календарь хранит тело серии без хэштегов — строку тегов дописывает рубрика при отправке (`ContentCalendarSlot::publishBody()`). Замер на проде 28-11: из 107 запланированных слотов распознан 0; по факту серий там 75 — «Неделя в группах» (17), «Ловушка» (21), «Вопрос из класса» (17), «Слово с историей» (20).

- **Судит опубликованный текст.** [`CalendarPublishService::passesChecklist()`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Content/CalendarPublishService.php) передаёт гейту `publishBody()` — тело плюс строка хэштегов рубрики, то есть то, что уйдёт на площадки.
- **Маркер один.** [`CoursePostCompletenessCheck`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Content/CoursePostCompletenessCheck.php) узнаёт пост серии по маркеру (ВОПРОС ИЗ КЛАССА · ЛОВУШКА · СЛОВО С ИСТОРИЕЙ · НЕДЕЛЯ В ГРУППАХ) уже без условия «есть строка хэштегов»: строка рубрики не канонична, а пост серии, забывший теги, не должен проходить молча — её отсутствие теперь дефект C4. Замер на живой сетке: маркер один выбирает ровно те 75 слотов четырёх рубрик серий и ничего больше.
- **Что это значит.** С момента деплоя удерживаются все 75 запланированных постов серий (C1 титул, C3 ссылка, C4 тэги, C5 доступ, C7 якорь; для «Слова с историей» ещё C6 словарь) — пока их не приведут к канону. Строка хэштегов рубрики дописывается последней, а гейт судит последнюю хэштег-строку: у рубрик серий её нужно убрать (теги — пять слотов в самом посте), иначе не пройдёт даже каноничный пост. Аварийный откат — `CONTENT_CAL_COURSE_POST_GATE=false`.
- **Тесты.** Unit 14/14, feature 10/10: тело слота без хэштегов и строка рубрики — удержан; серия без тегов вовсе — удержан по C4; каноничный пост и строка рубрики из двух тегов — удержан; каноничный пост и рубрика без строки — уходит.
