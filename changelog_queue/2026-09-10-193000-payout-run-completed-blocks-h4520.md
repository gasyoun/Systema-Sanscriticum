# H4520: payout:run — read-only месячный прогон выплат по завершённым блокам (OxAlpha z-ai/glm-5.3-flash, 10-09-2026)

До сих пор каждый прогон собирали вручную поверх tinker-замеров, и документ 30-08 давал 33 561,60 ₽ там, где сверка 26-08 — 29 145,60 ₽ на том же Лейтане. Новая artisan-команда `payout:run` (`--teacher=id[,id]|--all`, `--on`, `--since`, `--format=json,marina,report`) считает окно (since, on] по ЗАВЕРШЁННЫМ блокам — read-only, ни одной записи в `payments`/`teacher_payouts`/`users`/`finance_snapshots` (отпечатки до/после в выводе, расхождение роняет exit-код).

- **Ядро — переиспользование, не дублирование** ([PayoutRunService](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/PayoutRunService.php)): завершение блока — `CourseBlock.ends_at`, пустой → фолбэк на даты занятий (max lesson_date ≤ on) со строкой ⚠, без дат вовсе — видимый ⚠ «неопределимо», не молчаливый ноль; база блока — `TeacherSalaryService::blockGroupRevenueDetail` (платежи ЛЮБЫМИ датами прихода, возвраты вычтены, уже выплаченные доли отсечены paidShareKeys); «на руки» — `PayrollRateCalculator::netFor` по таймлайну `config/teacher_rates.php`.
- **Перерасчёт прошлых блоков**: доли блоков, завершённых до отсечки, не вошедшие ни в одну выплату («64-й блок: 1 платный (перерасчёт)»), добираются в базу автоматически.
- **Ловушка pass-through (MG 10-09)**: платежи `received_by_teacher_id = T` по ЧУЖИМ курсам — НЕ вычет; отдельный список «посреднические — ручная сверка» (прецедент «763 € = 200 ученики + 563 наш PayPal»). Прямые оплаты СВОИХ курсов — вычет по номиналу в валюте выплаты (`directReceiptsForTeacher`), EUR-вычет гасит €-сторону, ₽-сторону не трогает.
- **Предоплата задним числом (#14142 Соловьева, 144 000 за блоки 1–36)**: платёж ≥2 блоков, все завершённые ДО прихода денег, НЕ попадает в «к выплате» — помесячная рента (доля блока × срез × ставка = 2 208 ₽/мес, всего 79 488 ₽) по рулингу MG 26-08; старт признания (задним числом/вперёд) — открытый @DECIDE.
- **Удержание 8 % (вопрос MG 10-09)**: для percent-схем (X×0,92)×r = (X×r)×0,92 — «то же или второе удержание?» на цифру не влияет; в JSON поле `withholding_reading` фиксирует чтение «один срез». Фикс-регистр (Новикова и т.п.) показывается, но НЕ вычитается — в прогонах 25-08/26-08 не вычитался; подтвердить перед первым боевым прогоном (он и так за бэктест-гейтом).
- **Форматы**: json — машиночитаемые строки (блок, платежи, база, ×92 %, ставка, начислено, вычеты, к выплате, €); marina — текст §3б [сверки 26-08](https://github.com/gasyoun/Uprava/blob/main/docs/PAYROLL_LEITAN_MONTHLY_RECON_26-08-2026.md) для чата/письма; report — markdown-ведомость «начислено/выплачено/остаток + должники по курсам» (участники групп без оплаты блока, «5 платных из 7»).
- **Тесты**: [PayoutRunTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/PayoutRunTest.php) 11/11 — якоря ≤1 %: Лейтан 26-08 = 29 145,60 ₽ (52 800 × 92 % × 60 %), Костина 25-08 = 28 704 ₽ (104 000 × 92 % × 30 %), Xoom 24-07 = 632,49 € (₽-строка 54 794,40, fx восстановлен из ведомости); pass-through-классификация на фикстуре; пустой ends_at; предоплата; аванс; read-only отпечатки. Соседние payroll-тесты (backtest/block-payout/forecast) зелёные.
