# Уведомления обращаются по имени, без фамилии, отчества и города (Opus 5 `claude-opus-5`, 21-09-2026)

- Приветствия «Намасте, {name}!» подставляли поле `users.name` целиком: «Намасте, Мухасанова Хадижа Абдурахмановна!», «Намасте, Иванов Иван, Москва!» (чекаут и пробное склеивают в name «Фамилия Имя, Город»). Теперь уходит только имя. Разбор — [`GreetingName`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Support/GreetingName.php): чистка скобок, города после запятой, хвоста после тире → словарь частых имён ([`GreetingNameDictionary`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Support/GreetingNameDictionary.php)) → слово перед отчеством → «Фамилия Имя» по окончанию фамилии → первое слово.
- Новая колонка `users.greeting_name` — «Имя для обращения» в карточке студента (подсказка показывает, что выберет автомат); заполненная важнее автомата. Чекаут и пробное пишут её из поля формы «Имя» — у новых студентов имя точное, без угадывания; склейка `name` не менялась.
- Покрытие: плейсхолдер `{name}` (`MessagePlaceholders` → шаблоны, должники, дожим, реактивация, автоответы поддержки), ручные напоминания должникам, сообщения лидам, боты привязки и входа, уведомление о сертификате, письма из карточки, черновик exit-анкеты и 22 письма (`resources/views/emails`). Имя на самом сертификате, письма преподавателям и служебные письма куратору не тронуты.
- Предпросмотр на проде (только чтение): `php artisan users:greeting-names-preview` — спорные случаи «имя в карточке → обращение».
- Тесты: `GreetingNameTest` (19 форм имени), `GreetingNameDeliveryTest` (4); обновлены ожидания `AutoReplyTrialTest`, `SurveyStudentEmailInviteTest`.
