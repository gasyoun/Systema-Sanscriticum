- **Автоопрос о присутствии перед занятием в Telegram-чате группы (16-11-2026).** За `ATTENDANCE_POLL_LEAD_MINUTES` минут до старта (дефолт 180) @zapisi_ORSbot вешает в чат группы неанонимный опрос «Занятие «…» сегодня в HH:MM (МСК). Будете?» с вариантами «Буду / Опоздаю / Не смогу» — команда `classes:post-attendance-poll` (каждые 5 минут, один опрос на слот «группа + время начала»; перенос занятия даёт новый опрос; меньше 20 минут до старта — не шлёт). Построен на опросах бота из PR #2587 (перенесён на свежий `main`: `telegram_polls`, `SendZapisiPollJob`, приём `poll_answer`, страница «Записи (бот)» → «Опросы» с поимёнными результатами); опрос теперь знает своё занятие (`telegram_polls.kind` / `schedule_id` / `schedule_start`). Голос ученика с привязанным Telegram пишется в предупреждения о занятии (`ScheduleAttendanceNotice`, источник `telegram_poll`): «Опоздаю» → late, «Не смогу» → absent, «Буду» и отозванный голос снимают предупреждение; голоса ручных опросов, участников не из состава занятия и голоса после переноса занятия предупреждений не трогают. Флаг `features.attendance_poll_autopost` (env `ATTENDANCE_POLL_AUTOPOST`, дефолт OFF); пилотный список групп — `ATTENDANCE_POLL_GROUP_IDS` (пусто — все группы с чатом). Денег и доступа не касается. **После деплоя обязателен `php artisan zapisi:set-webhook`** — иначе Telegram не пришлёт `poll_answer`. Тесты: `tests/Feature/AttendancePollTest.php` (11 кейсов), `ZapisiPollTest`.
