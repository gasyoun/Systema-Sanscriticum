# «Финансы» в админке: конечные размеры страницы вместо «все»

Страница «Финансы» (`/admin/payments`) 25.11.2026 отвечала 500 на каждый заход: в сессии администратора остался выбранный когда-то размер страницы «все», Filament запоминает его в сессии (`tables.<hash>_per_page`), и каждый заход рендерил все 9 900 платежей — PHP-FPM с лимитом 128 МБ падал с «Allowed memory size exhausted» в шаблоне таблицы. Сменить размер из интерфейса было нельзя: страница умирала до отрисовки селектора.

Теперь у таблицы «Финансы» только конечные варианты — 10, 25, 50 и 100 строк; верхняя граница держит самую большую таблицу школы в памяти с запасом. Застрявшее в сессии «все» вычищается валидацией Filament, то есть страница самовосстанавливается. Пин: `PaymentListPageSizeTest` — опции без «все», и страница с «все» в сессии открывается.

Данные и деньги не тронуты: менялось только предпочтение размера страницы, существующие админ-сессии на проде поправлены точечно.
