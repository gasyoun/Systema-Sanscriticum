# H3915 (OxAlpha z-ai/glm-5.3-flash, 03-09-2026): Exit-опрос на авто-триггер «завершение курса» — задача куратору с готовыми черновиками для личной отправки

Автоматизация из джей-дика куратора: [CURATOR_NASTYA_GORBACHENKO_JD_AND_AUTOMATION_02-09-2026 §3](https://github.com/gasyoun/Uprava/blob/main/docs/CURATOR_NASTYA_GORBACHENKO_JD_AND_AUTOMATION_02-09-2026.md) («Exit-опрос на авто-триггер "завершение курса" с ручным выбором тона и отправкой от её имени»).

- **Триггер:** событие `Course.is_completed` false→true (тоггл «Курс завершён» в CourseResource — единственный в системе смысл «поток закончился»). Хук в `Course::updated`, только на переход, дедуп по новому штампу `courses.exit_survey_triggered_at`.
- **Fence соблюдён (хандофф):** система студентам сама НЕ пишет ничего. На курс уходит ОДНО уведомление в кураторский чат (`CuratorNotifier::exitSurveyBatchReady`, канал `curators_chat_id`) с готовыми черновиками —куратор отправляет лично каждому, НЕ рассылкой (правило [ACQUISITION_SURVEY_INSTRUMENTS_2026H2](https://github.com/gasyoun/Uprava/blob/main/custdev/ACQUISITION_SURVEY_INSTRUMENTS_2026H2.md): один контакт — потом тишина; без вопроса «почему не оплатили»; обещание тишины в тексте).
- **Когорта курса** [`ExitSurveyAutoTrigger::cohortFor()`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/ExitSurveyAutoTrigger.php): «спросил цену → оплаты нет» — был реальный заказ (`is_conditional=false`, тариф не из `conversion.excluded_tariffs`), платных оплат по курсу нет и не было, последнее касание ≥ 14 дней (правило «Когда» инструмента, MIN_DAYS_SINCE_TOUCH).
- **Черновик** — канон приглашения анкеты 1 «Exit» + абсолютная ссылка на нативную анкету `url('/anketa/exit-price')` (движок опросов PR #2080, флаг `SURVEY_ENABLED`/`SURVEYS_ENABLED` — включённость анкеты не менялась этим хандоффом).
- **Флаг `exit_survey_auto_trigger`** (`EXIT_SURVEY_AUTO_TRIGGER`, default **OFF**) — полностью прод-инертно: при OFF ни хук, ни команда не делают ничего. Длинные списки черновиков режутся на сообщения ≤ 3500 символов (лимит Telegram 4096).
- **Догоняющий/ручной прогон:** `php artisan surveys:exit-survey-completed [--course=] [--force]` — завершённые курсы без штампа (включение флага ПОСЛЕ завершений); в расписание не заведено, событийного пути достаточно. Штамп ставится даже при пустой когорте (курс разобран).
- Тесты: [ExitSurveyAutoTriggerTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/ExitSurveyAutoTriggerTest.php) 6/6 (флаг OFF молчит и не штампует; переход-only; дедуп штампом + force; платившие/свежие/депозиты/conditional вне когорты; бэкфейс команды; отказ при OFF), регрессия кураторских уведомлений + оплат 18/18, миграция up/down на sqlite, Pint clean, ENV-инвентарь перегенерирован.
- **Осталось человеку:** деплой подхватит авто-деплой; решение MG о включении `EXIT_SURVEY_AUTO_TRIGGER=true` на проде + `config:cache` (не ранее ручной разсылки бумажного backlog'а до 10-09-2026).
