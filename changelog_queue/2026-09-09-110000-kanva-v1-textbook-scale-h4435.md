# H4435: Канва v1 — две шкалы (наши занятия / уроки учебника), ссылки в админку, канва в кабинете (OxAlpha z-ai/glm-5.3-flash, 09-09-2026)

Решения MG 08-09/09-09 (чат): программа «Канва и ответвления». Фаза 1 — сервис [`TextBookScale`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/TextbookScale.php) + [`config/edutech.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/config/edutech.php) + три поверхности (пост v2, вкладка ViewUser, кабинет студента).

- **Модель v2:** две шкалы никогда не смешиваются — «наши занятия» (календарные) и «уроки учебника» (Кочергина 1..40). Связь СОБЫТИЙНАЯ: одно занятие покрывает набор предметов канвы (заголовки записей уроков = источник истины: «Кочергина 3 (читка)», «Кочергина 7 (проверка), Кочергина 8 (читка)»); проверка/домашка того же урока = подкрепление канвы (не ответвление); Эмено/прочие источники = ответвления-источники; прыжки = порядок-ответвление. Прогресс группы = курсор по учебнику (макс. читка), НЕ пропорция сессий. Вес урока эмпирический: середина книги — 2-5 наших занятий на урок; **КОНЕЦ ТЯЖЁЛЫЙ** (правка MG 09-09) — урок у конца может занимать 2-3 наших занятия. Проекция «до конца» — по последним M тронутым урокам группы. Эмено-бюджет эталонно 5 наших занятий. Канва-lag = разница курсоров между группами семейства.
- **Поверхности:** (1) [`WeeklyFinishReport`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/WeeklyFinishReport.php) v2 — канва-строка у заголовка группы («Канва: урок 4/40 (+N к медиане) · до конца ≈ k наших занятий»), имя студента = `<a>` на `/admin/users/{id}`, в строке студента предмет канвы последнего факта («· Кочергина 4 (читка)»); (2) вкладка «Посещаемость и канва» в Filament ViewUser ([`attendance-canvas.blade.php`](https://github.com/Systema-Sanscriticum/blob/main/resources/views/filament/user/attendance-canvas.blade.php), реюз `ClassAttendanceService`-данных, позиция студента vs курсор группы, lag); (3) кабинет студента ([`StudentController::dashboard`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/StudentController.php) + dashboard.blade) — «Кочергина: вы на уроке X из 40 · группа дошла до Y».
- **Данные:** `textbook_lesson` колонка приоритетна, когда заполнена (сейчас — только гр.60/61); парсер меряет parse-rate сам. Тайм-коды завершённых групп — в TG-чатах (n8n), фаза 2.
- Тесты: `TextbookScaleTest` 7 (парсер читка/проверка/мульти/ответвление, курсор только по читке, колонка-приоритет, веса уроков, проекция по последним M, медианный lag) + регрессия 35/35 зелёная. Попутно чинит `PublicSchedulePageTest::it_renders_all` под H4434 (time-wrapping; UTC-подпись внутри time до JS — их дефект, помечен NB).
