- **H3761 добор (Opus 5 `claude-opus-5`, 31-08-2026): `--meeting-id` для потока, у которого Zoom-ссылки нет нигде.** Курс 332 («1 поток, 2025») не хранит `zoom_meeting_id` ни в карточке, ни в `zoom_link`, ни в занятиях — занятий у него ноль, потому что раздел «Занятия» появился 25-03-2026, а поток шёл с 09-2025. Цепочка резолва (курс → ссылка курса → ссылка занятия) для него честно возвращает «не разрешён», и команда молча пропускала курс. Теперь id можно передать вручную — только вместе с ровно одним `--course`, иначе одному потоку приписались бы занятия другого. Вместе со `--slot` и `--create-lessons` это единственный способ достать первый поток из Zoom (75 запусков сохранены с 21-08-2025). Тесты: [`BackfillStreamAttendanceTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/Attendance/BackfillStreamAttendanceTest.php) — заведение занятия под запуск в окне при полном отсутствии расписания, отказ без `--slot`, отказ при нескольких курсах (13 тестов). Флаги не трогались.
