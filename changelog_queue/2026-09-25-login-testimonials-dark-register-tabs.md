# Вход: тёмная сцена с бегущими отзывами, санскрит и вкладка регистрации

_Created: 25-09-2026 · Last updated: 25-09-2026_

- `/login` при ≥3 видимых отзывах: отзывы бегут колонками фоном на весь экран (по две слева и справа, центр пуст), карточка входа — по центру поверх них. Тёмная сцена (почти чёрный фон + зерно), отзывы — тёмное стекло с тонким золотым ореолом, карточка входа — тёмное стекло с золотой кромкой. Меньше трёх отзывов — прежняя светлая карточка без изменений.
- Интерактив: колонка встаёт на паузу под курсором; карточки (вход и отзывы) — свет за курсором, кромка загорается у курсора, лёгкий наклон; длинный отзыв раскрывается кликом. Мышь-only, `prefers-reduced-motion` без движения.
- Санскрит: заголовок नमो नमः вместо «С возвращением!», под формой строка молитвы Сарасвати (विद्यारम्भं करिष्यामि सिद्धिर्भवतु मे सदा). Наведение/фокус/тап по слову — транслитерация и перевод в подписи. Шрифт Tiro Devanagari Sanskrit (Google Fonts; CSP пока report-only — при строгом CSP откат на системный деванагари).
- Вкладки «Войти / Регистрация» в той же карточке — только при `features.guest_registration` (на проде OFF → одна карточка входа). Регистрация с карточки: имя, фамилия, телефон, email, город, пароль; `GuestRegisterController` пишет «Имя Фамилия» в `name`, `phone`, `city`; подтверждение пароля проверяется, только если прислано (страница `/register` с двумя полями работает как раньше). Ошибка возвращает на вкладку регистрации с сохранёнными полями, тексты ошибок по-русски.
- Админка «Маркетинг → Отзывы»: новые поля «Дата отзыва» (`reviewed_at`, печатается на карточке рядом с городом) и «На странице входа» (`show_on_login`, по умолчанию вкл., переключатель прямо в списке + фильтр). На входе: сначала избранные, потом по дате отзыва. Миграция аддитивная.
- Тесты: [`LoginTestimonialsTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/LoginTestimonialsTest.php) (+2: переключатель «на входе», дата), новый [`LoginRegisterCardTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/LoginRegisterCardTest.php) (6: вкладки по флагу, сохранение имени/телефона/города, ошибка телефона → вкладка регистрации, подтверждение пароля на `/register`, фолбэк имени).
- Переводы слов молитвы и приветствия написаны агентом — нужна вычитка преподавателем.
