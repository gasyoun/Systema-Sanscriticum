# H4199: отмена занятия reply-командой «Отмена занятия» в чате группы (OxAlpha z-ai/glm-5.3-flash, 06-09-2026)

Генерализация ручной отмены 06-09-2026 («Рецитация сутр Патанджали вс 10:00», schedule 606, группа 130 — сделано tinker'ом за 33 минуты до старта): админ отвечает **«Отмена занятия»** на пост-напоминание «Скоро занятие» → каскад +7 дней ([ScheduleMover::cancelAndShiftWeek](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Schedule/ScheduleMover.php)) + анонс об отмене с датой следующего занятия тем же zapisi-ботом в тот же чат.

- **`telegram_chat_posts`** (миграция `2026_09_06_090000`): `chat_id + message_id → schedule_id` (unique), `kind`, `posted_at`. Заполняет [SendZapisiBotMessageJob](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Jobs/SendZapisiBotMessageJob.php) после успешной отправки — новые nullable-параметры `scheduleId`/`kind`, старые вызовы (2 аргумента) совместимы и маппинг не пишут. [zapisi:remind-classes](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/RemindZapisiClasses.php) передаёт `scheduleId` + `kind=zapisi_reminder`.
- **[CancelClassCommandService](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Telegram/CancelClassCommandService.php)** — хук в [ProcessTelegramZapisiUpdate](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Jobs/ProcessTelegramZapisiUpdate.php) рядом с голосами кворума отпуска. Гейты: текст-команда («отмена занятия» / «отменяю занятие» / «отмена», нормализация пробелов+регистра) → whitelist `marketing_settings.zapisi_cancel_admin_ids` (telegram user_id через запятую, поле в [админке](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Filament/Resources/MarketingSettingResource.php), MG + преподаватели) → маппинг reply на занятие → занятие в будущем. Повторная команда на тот же пост подавляется клеймом `TelegramSendGuard::claimKey` на сутки — второй reply не сдвинет цепочку ещё на неделю. **Все отказы (whitelist-miss, нет маппинга, занятие прошло) — только в лог**: в студенческий чат бот пишет только подтверждение отмены. Анонс использует заголовок занятия без устаревающей хвостовой даты «(#13, 06.09.26)».
- **`schedule:cancel {id}`** ([CancelScheduleCommand](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/CancelScheduleCommand.php)) — агентский/операторский канал, тот же mover: цепочка, каскад, отчёт старый→новый слот.
- Тесты: ZapisiCancelClassCommandTest (9: каскад+анонс с проверкой титула и end, whitelist-miss, пустой whitelist выключает команду, не-команда, нет маппинга, прошедшее занятие, дубль-подавление клеймом, маппинг пишется при scheduleId / не пишется без, remind-диспатч несёт scheduleId+kind).
