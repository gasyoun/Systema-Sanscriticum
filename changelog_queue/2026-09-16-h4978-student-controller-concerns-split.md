# H4978: `app/Http/Controllers/StudentController.php` split into 5 `App\Http\Controllers\Concerns` traits, no behavior change (Sonnet 5 `claude-sonnet-5`, 16-09-2026)

`StudentController.php` was 1511 lines mirroring the `routes/web.php` split (H4941) and the `app/Console/Kernel.php` split (H4952). This pass groups its 26 methods by domain into 5 traits, leaving the controller itself as a thin shell carrying only `getUserUnlockedTariffs()` — the one method that touches the `Payment` model directly, kept in place per the money-contour out-of-scope fence in the handoff.

- **New traits** (`app/Http/Controllers/Concerns/`): `StudentScheduleConcerns` (calendar, messenger disconnect), `StudentDashboardConcerns` (cabinet home + hybrid job-nav pages: dashboard/library/progress/access + their private helpers), `StudentCourseContentConcerns` (course/lesson view, complete, note, materials, course library), `StudentCertificateConcerns` (certificate PDF/JPEG download + the shared `parseVideoId` static helper), `StudentMiscConcerns` (open lessons, skill drills, announcements).
- **Pure move, byte-identical:** every moved method's docblock+signature+body was verified byte-identical to its pre-move slice via a scripted extraction/diff pass against the pre-split commit (`18a1b677`) — all 5 trait bodies matched exactly, byte for byte.
- **Money-adjacent method left untouched:** `getUserUnlockedTariffs()` (queries `Payment` directly) stays on the controller itself, unmoved — flagged out of scope per `/money-pr-land` gating, same as the handoff's mission required.
- **Cross-trait static calls verified safe:** `showLesson()` (in `StudentCourseContentConcerns`) calls `self::parseVideoId()`, defined in `StudentCertificateConcerns` — both traits compose into the same class, so `self::` resolves correctly; external callers (`RecordingGateController`, `Api/CabinetController`, `Services/Access/LessonGate`, etc.) keep calling `StudentController::getUserUnlockedTariffs()` / `StudentController::parseVideoId()` unchanged.
- **Imports:** each trait carries only the `use` statements its own methods need; `StudentController.php` itself now needs only `Course`, `Payment`, `User`, `ClubEntitlement` plus the 5 trait imports.
- **Verification:** `php -l` clean on all 6 touched/new files; no unused imports (checked per file). This worktree has no `vendor/` (fresh worktree, per repo convention) — Pint and the full phpunit suite run in CI on the PR, same as the H4941/H4952 precedents.
- **Fence:** no behavior change — a pure file-split, same as the routes/web.php and Kernel.php precedents.
