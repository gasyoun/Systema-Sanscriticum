# H4118 (iPhone-friendly кабинет P0/P1): root-cause fix — Play CDN удалён, Tailwind компилируется через Vite + P0-волна стабильности/UI (OxAlpha z-ai/glm-5.3-flash, 05-09-2026)

Исполнение [H4118](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4118-OxAlpha_Systema-Sanscriticum_iphone-friendly-cabinet-p0_05.09.26.md) поверх находки F1 аудита H4117: кабинет, витрина, чекаут и auth-страницы больше НЕ зависят от runtime `cdn.tailwindcss.com` (v3.4.17, сломанный in-browser JIT без `hidden`/`sm:*`/`md:*` → десктоп-layout на iPhone, ox=646, карточка /login width:0).

- **P0-0 root cause (атомарная замена партиала):** [partials/tailwind-cdn.blade.php](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/partials/tailwind-cdn.blade.php) теперь `@vite('resources/css/app.css')` — все 6 подключений (student/shop layouts, login, register, 2×passwords) получают тот же self-hosted v4-бандл, что витрина/промо (токены H2560 в `@theme`, скан классов `@source "../views"`). Компиляция детерминирована билдом: `.hidden`/`md:*`(116)/`sm:*`(75) в бандле есть ещё до отдачи страницы. [BrandTokenParityTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/Ui/BrandTokenParityTest.php) переписан на три новые красные линии: Play CDN запрещён ВЕЗДЕ в views; партиал отдаёт compiled app.css через @vite; @theme-токены бренда не вымирают.
- **Квирks-хвост аудита:** локальный PHP 8.5 печатал deprecation `PDO::MYSQL_ATTR_SSL_CA` в вывод страницы ДО `<!DOCTYPE` → quirks mode → раздутый layout (те самые `<b>`-артефакты right≈646 в базовом отчёте H4117). [config/database.php](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/config/database.php) получил version-safe тернарник `Pdo\Mysql::ATTR_SSL_CA` / `PDO::MYSQL_ATTR_SSL_CA` (старый PHP не знает новую константу — branch не исполняется). Pint-импорт `use Pdo\Mysql;` ленив — на старых PHP не грузится.
- **P0-стабильность:** глобальные `wire:loading` (прогресс-бар) + `wire:offline` (баннер «Нет подключения») в [layouts/student.blade.php](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/layouts/student.blade.php) — аудит теперь видит wl=1/wo=1 на всех роутах; [lesson-heartbeat.js](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/public/js/lesson-heartbeat.js) больше не теряет молча study-time: delta вычитается только после подтверждённого POST, одна немедленная ретри-попытка, при сбое секунды едут следующим тиком (sendBeacon не тронут); viewport `interactive-widget=resizes-content`; [support-chat-widget](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/views/partials/support-chat-widget.blade.php) — высота от `visualViewport` (--scw-vvh) вместо `calc(100vh-120px)`.
- **P0-UI:** safe-area `env(safe-area-inset-*)` на шапку/скролл-контейнер/чат-виджет; dvh-стратегия с vh-фолбеком (`.h-cabinet-shell`, lesson side-col) вместо `h-screen`/`100vh`; пол 16px для форм-контролов (`main :is(input,select,textarea)` + `.scw`) — focus-zoom убит (аудит: input<16px=0); `playsinline webkit-playsinline` на нативном видео урока; legacy Telegram-layout без `user-scalable=no`; `color-scheme=light` (мета+CSS), НЕ тёмная тема. [PwaShellAssetsTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Unit/PwaShellAssetsTest.php) расширен safe-area/interactive-widget/color-scheme/wire:loading/100dvh/без-CDN ассертами.
- **Ловушка дня (в коммент.)**: blade-директива (`@livewireStyles`) внутри css-комментария в `<style>` компилируется и ломает rawtext-парсинг → текстовый узел посреди `<body>` → анонимный flex-item → shell w=0/x=390. Комментарий переформулирован.
