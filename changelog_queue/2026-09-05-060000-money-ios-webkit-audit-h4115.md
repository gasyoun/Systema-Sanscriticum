# H4115: money-surface iOS WebKit audit runner — Playwright WebKit iPhone над checkout/marathon/donate/paypal (H1391 bug class) (OxAlpha z-ai/glm-5.3-flash, 05-09-2026)

- **[`scripts/money_ios_webkit_audit.mjs`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/money_ios_webkit_audit.mjs)** (H1488-патерн `mobile_viewport_audit.mjs`): Playwright **WebKit** (тот же движок, что iOS Safari) с настоящими device-дескрипторами iPhone 14 / iPhone SE (3rd gen) над денежными поверхностями. GET-only по умолчанию (prod-safe, read-only); `--local` открывает интерактивный POST-прогон промокода и жёстко охраняется `assertPostSafety()` — не-localhost база отказывает даже с флагом.
- **Surfaces:** `/checkout/{tariff}` (слаги автодискаверятся с промо-страниц в два хопа: seed → `/k/{slug}` → money-link), `/online/konsultaciya`, донаты `/mecenaty`, `/paypal/{tariff}` (claim-страницы раздаются письмами, а не ссылками — прозондированы напрямую из найденных checkout-слагов, `MAX_PAYPAL_PROBES=3`; HTTP≥404 = skip), `/trial` (GET-страницы нет — форма живёт модалкой на `/k/{slug}`-страницах, покрытие идёт через них, тот же набор H1391-проверок).
- **H1391 bug class assertions:** горизонтальный overflow (scrollWidth−clientWidth), видимость pay-кнопки во вьюпорте + тап-таргет ≥44px, перекрытие cookie-баром (реальная bounding-box intersection против fixed/sticky-оверлеев + elementFromPoint-эвристика), фокусабельность видимых text/email/tel/number-полей, `_token` в серверных POST-формах (JS-fetch формы сознательно исключены — CSRF у них через header), ошибки консоли WebKit (console.error + pageerror).
- **Выход:** `storage/app/money-ios-audit/{report.json,summary.md,*.png}` (полные per-surface скриншоты; storage — не git). Exit 0 = чисто, exit 1 = есть находки. Реальные 3-DS/Apple Pay на живом устройстве остаются на ручном чек-листе H3926.
- **Первый прод-прогон 05-09-2026** (`BASE_URL=https://samskrte.ru`, 12 поверхностей × 2 устройства = 24 прогона): **18/24 с одной и той же находкой — тап-таргет pay-кнопки меньше 44px HIG**: checkout-страницы 42px (iPhone 14: 324×42, SE: 309×42), `/online/konsultaciya` и `/mecenaty` 40px (358×40 / 343×40). Overflow, консольные ошибки, мёртвые поля, CSRF и перекрытия — ноль; все три `/paypal/{tariff}` чистые (≥44px). Чинить кнопки — отдельное решение (денежный контур): это аудит-инструмент +baseline, не фикс.
