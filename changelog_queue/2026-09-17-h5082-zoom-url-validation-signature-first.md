### Security

- **Zoom url_validation больше не HMAC-оракул: подпись v0 проверяется до ответа на челлендж (OxAlpha `zai-coding-plan/glm-5.3-flash`, 17-09-2026, H5082 — remediation confirmed H5046 `zoom-url-validation-hmac-signing-oracle`).** [`ZoomWebhookController`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/Webhooks/ZoomWebhookController.php) отвечал на `endpoint.url_validation` ДО проверки `x-zm-signature`: неподтверждённый вызов получал `encryptedToken = hash_hmac(sha256, plainToken, секрет_подписи)` над НУЖНОЙ атакующему строкой — plainToken вида `v0:{ts}:{тело сфабрикованного события}` возвращал готовую корректную подпись (byte-match подтверждён в run-1-sandbox), и вторым запросом фабриковалось событие посещаемости. Фикс: ветка url_validation перенесена ПОСЛЕ `signatureValid()` — ровно санкционированный паттерн официального [zoom/webhook-sample](https://github.com/zoom/webhook-sample) (Zoom подписывает челлендж валидации тем же секретом и той же схемой v0), поэтому реальный bootstrap не меняется: подписанный челлендж по-прежнему получает echo `plainToken`/`encryptedToken` по контракту Zoom, неподписанный — 403 без какого-либо HMAC в теле. Существующие тесты `ZoomWebhookTest` адаптированы (url_validation теперь подписан), остальные Zoom-тесты без изменений. Тесты: [`ZoomUrlValidationNoOracleTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/Webhooks/ZoomUrlValidationNoOracleTest.php) (3: неподписанный челлендж 403 без утечки HMAC; неверная подпись 403; подписанный — контракт echo жив) + sandbox-доказательство Nv14 больше не воспроизводится.
