# H5081 (remediation H5046/0CU class-join-signed-url-no-expiry): join-ссылка на занятие стала временной + перепроверка canAccess на подписанной ветке (OxAlpha z-ai/glm-5.3-flash, 18-09-2026)

Исполнение [H5081](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5081-OxAlpha_Systema-Sanscriticum_remediation-classjoin-signedurl-0cu_17.09.26.md) — единственная confirmed-находка аудита H5046: трекинг-ссылка «Подключиться» из бота/напоминаний подписывалась `URL::signedRoute` **без срока жизни**, и подписанная ветка [JoinClassController](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/JoinClassController.php) доверяла подписи полностью, не проверяя доступ. Студент, отозванный из группы, с сохранённой ссылкой (Telegram/почта) продолжал попадать на платное живое занятие сколь угодно долго.

- **Ссылка стала временной:** [Schedule::trackedJoinUrlFor](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Models/Schedule.php) выдаёт `URL::temporarySignedRoute` с окном из нового `Schedule::joinLinkExpiry()` — конец занятия (`end`, иначе `start` + 2ч по `DEFAULT_DURATION_HOURS`) + 30 минут grace на опоздавших; занятие без даты (legacy) — относительные сутки. Все три места выдачи (`RemindUpcomingClasses`, `StudentSelfService` ×2) шлют ссылки только на будущие занятия (`start >= now`), так что окно в момент выдачи всегда открыто.
- **Подписанная ветка перепроверяет доступ:** валидная подпись теперь доказывает лишь, что ссылку выдал наш бот/кабинет — контроллер достаёт держателя по `u` и повторно прогоняет тот же `canAccess()` (группа/безгрупповое/сотрудник), что и для авторизованной ветки. Отозванный студент и ссылка на несуществующего пользователя получают 403 без Zoom-URL; истекшая подпись падает в анонимную ветку → редирект на логин.
- **Регресс-пины:** [JoinClassAccessTest](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/JoinClassAccessTest.php) +4: ссылка несёт `expires=` и окно end+30м; сохранённая ссылка отозванного студента → 403, ноль `zoom.us` в Location, ноль кликов; истекшая ссылка прошедшего занятия → логин, не Zoom; валидно подписанная ссылка на несуществующего пользователя → 403. Прежние 6 кейсов зелёные; смежные потребители `trackedJoinUrlFor` (RemindUpcomingClassesTest, StreamsSelfServiceTest, StudentSelfService*, AttendanceNoticeTest) — 59 passed суммарно. Pint clean.
- **Не тронуто:** безгрупповые занятия остаются открытыми авторизованным студентам, доступ сотрудников, запись кликов, структура ссылки (schedule/u/source), тарифы и платежи. Изменение только в deny-направлении для тех, у кого доступа нет и не должно быть.
