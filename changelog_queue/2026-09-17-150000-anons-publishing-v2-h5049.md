# Anons publishing v2: видимые CTA-плашки, декларативные манифесты, идемпотентность, аналитика и адаптеры (OxAlpha `z-ai/glm-5.3-flash`, 17-09-2026)

H5049. Прод-публикация анонсов и Telegram-сториз принимает декларативный манифест и даёт видимую брендированную
кликабельную измеримую повторяемую публикацию: CTA-плашка физически отрисовывается в пиксели изображения ДО
загрузки, а Telegram-клик-зона ложится ровно на измеренный прямоугольник плашки. Дефект v1 (mediaAreaUrl без
рисунка — ссылка есть, видимой плашки нет) закрыт и закреплён тестом-регрессией.

- **Ядро** [`app/Services/Anons/`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/):
  [`PublicationManifest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/PublicationManifest.php)
  (YAML/JSON, fail-closed валидатор: относительные пути, UTM в короткой ссылке, URL-первым в подписи, дубли
  адресатов, test_mode без приватного контура — всё отклоняется до публикации);
  [`PublicationKey`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/PublicationKey.php)
  (sha256 кампания|креатив|адресаты|слот — повторный прогон того же манифеста резюмирует/отчитывает, дубль
  создать невозможно, мутированный манифест под тем же ключом отклоняется);
  [`CtaPlaqueCompositor`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/CtaPlaqueCompositor.php)
  + [`PlaqueInspector`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/PlaqueInspector.php)
  (плашка в пикселях до загрузки; приёмка экспортированных байтов: покрытие фона внутри прямоугольника,
  формат/размерность/байты, безопасные зоны; «mediaAreaUrl без слоя плашки» = падение);
  [`AnonsPublishingService`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/AnonsPublishingService.php)
  (validate/preview/publish/status/metrics/rollback — один сервис под CLI и HTTP);
  [`SessionHealthProbe`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/SessionHealthProbe.php)
  (живой getSelf в подпроцессной полосе — путь сессии на диске ≠ живой сеанс; FLOOD_WAIT → bounded retry,
  AUTH_*/REVOKED → fail-closed на переавторизацию человеком).
- **Адресаты-автоматы** [`anons_destination_runs`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/migrations/2026_09_17_100000_create_anons_publications_tables.php):
  у каждого пункта назначения/кадра свой автомат pending→running→published|failed|blocked, bounded backoff,
  потолок попыток → blocked; постоянные ошибки валидации fail-closed; падение одного адресата не дублирует и
  не блокирует остальные.
- **Адаптеры платформ** ([`Adapters/`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Anons/Adapters/)):
  TelegramStoryAdapter (MTProto через отлаженный StoryPublisher, измеренный mediaArea уходит в sendStory),
  TelegramPostAdapter (Bot API sendPhoto + sendMediaGroup-альбомы); vk/senler — fail-closed до своих адаптеров.
  Легаси-поведение очереди stories:publish-story (#2637–#2643) сохранено без изменений.
- **Аналитика**: клики по /ga/ теперь СЧИТАЮТСЯ ([`TrackedLinkController`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Controllers/TrackedLinkController.php)
  писал только redirect — счётчика не существовало; `anons_link_clicks` без PII: слаг+UTM+время); story
  views/reactions/forwards через адаптер; ридомет [`anons:ops metrics`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/AnonsOpsCommand.php)
  джойнит наблюдения и клики по publication_key + UTM-кортежу; отсутствующее поле API — явное состояние
  `unavailable`, НИКОГДА ноль (`value|unavailable|not_supported|pending|failed`).
- **Серия кадров** — упорядоченная публикация с раздельными utm_content и резюмом частично опубликованной
  серии по recorded remote id; **архивный каталог** `anons_archive_items` (sha256, dhash, текст, теги,
  текущность, usage history) + [`scripts/anons_archive_worker.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/anons_archive_worker.php)
  (stories.getStoriesArchive живым сеансом) — старый вечнозелёный ассет ищется без перескана истории Telegram.
- **Безопасный тест-контур**: `test_mode: true` публикует ТОЛЬКО в приватный test_destination с пометкой
  `_test_` в UTM; промоция переиспользует принятый манифест по хэшу. До регистрации приватного аккаунта
  санкционированный смоук-дрилл: публикация с `deletion_policy: rollback_target` + немедленный bounded
  rollback (удаляет ТОЛЬКО свои recorded remote id, чужие публикации недостижимы).
- **API/CLI**: [`anons:validate|preview|publish|ops`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/ANONS_PUBLISHING_V2.md)
  + [`/api/anons`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/routes/api.php) (auth:sanctum:
  draft/preview/publish/status/metrics/rollback) — оба поверхности зовут один сервис.
- **Тесты**: [`tests/Feature/Anons/`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/Anons/)
  15 зелёных: валидация манифеста, пиксельная приёмка + регрессия «ссылка без плашки», идемпотентный
  репаблиш, отказ мутированному манифесту, транзиентный retry + резюм серии, fail-closed, ноль-vs-недоступно,
  изоляция тест-режима, API-контракт, счётчик /ga/, архивный поиск. Пять таблиц новой миграции.
