# Подтверждение почты для кабинета из Telegram-бота

Кабинет, созданный командой `/кабинет ваша@почта.com`, теперь может получить подтверждение адреса. На указанную почту уходит письмо с одноразовой ссылкой: она ставит отметку «почта подтверждена» и сразу пускает в кабинет. Пароль по-прежнему не нужен.

Подтверждение мягкое: вход по ссылке из бота работает и без письма, поэтому быстрый старт для нового ученика не ломается. Привязка Telegram по одному лишь email по-прежнему доступна только после оплаты — подтверждение почты не ослабляет этот защитный рубеж.

Новый флаг `CABINET_EMAIL_VERIFICATION_ENABLED` по умолчанию выключен; включается после выката. Тесты: отправка письма при создании кабинета, подтверждение и вход по ссылке, одноразовость, разграничение purpose, выключенный флаг.
