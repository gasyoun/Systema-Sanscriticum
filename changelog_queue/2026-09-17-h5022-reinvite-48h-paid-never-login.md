# H5022: автоматическое повторное приглашение в кабинет через 48 ч после оплаты без входа (Fable 5.1 `claude-fable-5-1`, 17-09-2026)

Решение MG (Q14, digital-marketing grill 16-09-2026): закрыть утечку «оплатил — ни разу не вошёл» (75,2 %, process mining 08-09-2026). Отчёт первого сухого прогона: [docs/RESULTS_REINVITE_48H_PAID_NEVER_LOGIN_H5022_17-09-2026.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/RESULTS_REINVITE_48H_PAID_NEVER_LOGIN_H5022_17-09-2026.md).

- **Новая команда [`students:reinvite-48h`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/SendPaidNeverLoginReinvite.php)** — через ≥48 ч после успешной оплаты (paid/success, не conditional, `first_paid_at` в окне 30 дней) студенту без единого входа уходит ровно одно приглашение: Telegram при привязанном chat id, иначе email ([`Reinvite48hMail`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Mail/Reinvite48hMail.php)). Вход — одноразовая magic-ссылка `/login-link/{token}` (маршрут кнопки «Разблокировать», TTL 72 ч). Копия ведёт с записей и своего темпа, без срочности. Сухой прогон по умолчанию, рассылка только с `--send`.
- **Идемпотентность и отчёт через `activity_events`:** новый тип `reinvite_48h_sent` (канал, `payment_id`) — маркер «уже приглашён» и основа `--report`: доля вошедших в течение 7 дней после приглашения против baseline 10,4 %. Плюс штамп `cabinet_invite_sent_at`, чтобы еженедельная `students:send-login-invites` не продублировала.
- **Расписание и флаг:** ежедневно 11:00 МСК `--send --limit=50`; kill switch `features.reinvite_48h` ← `REINVITE_48H` (**по умолчанию ON** по решению MG; выключить — `REINVITE_48H=false` + `config:cache`). Инвентарь env перегенерирован.
- **Первый сухой прогон на проде (read-only SELECT):** за 30 дней оплатили 56, из них подходят под 48-ч приглашение **2** (оба email); исторический пул never-login — 699. Свежая утечка мала (checkout сажает в кабинет сам), 75 % — старый пул, его добирает еженедельная капля; одноразовая волна по старому пулу той же механикой — `--lookback-days=3650`, решение человека.
- Тесты: [`SendPaidNeverLoginReinviteTest`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/tests/Feature/SendPaidNeverLoginReinviteTest.php) (8 кейсов); сиблинги `SendCabinetInvitesTest` + `LoginLinkNotifierTest` зелёные (27 тестов, 112 assertions). Pint clean.
