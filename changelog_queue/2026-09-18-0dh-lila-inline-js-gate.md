# 0DH: lila-дриллы больше не могут выйти в прод с синтаксически мёртвым inline-JS (OxAlpha `opencode/glm-5.3-flash`, 18-09-2026)

Класс [#2692](https://github.com/gasyoun/Systema-Sanscriticum/pull/2692): пропущенная запятая в inline-конфиг-массиве страницы — SyntaxError при загрузке, виджет не монтируется; статический HTML кэшируется, и юзеры держали мёртвый дрилл до TTL. Новый механический гейт [scripts/check_lila_inline_js.mjs](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/check_lila_inline_js.mjs): извлекает inline `<script>` (без src; JS-типы) из всех `public/lila/**/index.html` и прогоняет каждый через `node --check` (только парсинг, без исполнения); external-src и data-блоки (`application/json` и пр.) вне скоупа. Zero-dep (node:fs/child_process), самопроверка `--selftest` с positive+negative контролем — negative есть точная форма #2692 (массив с пропущенной запятой обязан отказать). CI: job `Lila inline JS gate (node --check)` в [ci.yml](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/.github/workflows/ci.yml) — selftest + свип на каждый PR/push. Локальная база: 25 inline-скриптов на 32 страницах — чисто (7 страниц без inline — хабы-каталоги).
