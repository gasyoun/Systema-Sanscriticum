Что различает «токен умер» и «GitHub лежит»: репозиторий публичный, поэтому анонимный `git ls-remote https://github.com/...` **с той же машины** прошёл, пока `origin` отдавал 401 — значит дело в креденшале. Теперь `origin` = `git@github.com:gasyoun/Systema-Sanscriticum.git`, ключ `/root/.ssh/id_ed25519_github_systema` (ed25519, без пароля), зарегистрирован в репозитории как **read-only** deploy key: прод только тянет, толкать ему нечего, и такой ключ не истекает — в отличие от PAT, который принесёт ту же бомбу через год. Ключ прибит к хосту блоком `Host github.com` с `IdentitiesOnly yes` (у root лежат ещё restic- и hermese-ключи, без этой опции SSH ловит «Too many authentication failures» раньше, чем дойдёт до нужного), а host-ключи github.com взяты из `https://api.github.com/meta` по проверенному TLS, а не голым `ssh-keyscan` — первое подключение не слепое TOFU.
