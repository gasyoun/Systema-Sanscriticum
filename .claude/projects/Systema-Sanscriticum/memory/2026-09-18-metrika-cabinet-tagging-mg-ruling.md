# Рулинг MG 18-09-2026: кабинет тегируется Яндекс.Метрикой — вебвизор в кабинете навсегда выключен

Рулинг (дословно): «А кто нам мешает отслеживать внутри кабинета, тоже Яндекс Метрика. Не вижу противоречий, может там можем придумать цели и отслеживать их, проанализируя какие цели необходимо добавить и во внешнем сайте, и внутри кабинета.»

Отменяет дефолт «кабинет не тегируем» (webvisor пишет полные сессии залогиненных, 152-ФЗ).

Опасная грань — **условие, без которого рулинг не работает**:

1. Кабинетный init счётчика `106964341` — только `{webvisor:false, clickmap:false}`. Включить вебвизор/карту кликов на кабинетных страницах = писать полные сессии студентов = нарушение 152-ФЗ. Никогда не «включить на попробовать».
2. Магазин (`layouts/shop`) сейчас `webvisor:true` безусловно — залогиненные студенты на `/k/*`, `/checkout/*` пишутся. Фикс: `webvisor => !auth()->check()`.
3. PII в Метрике запрещён: только имена целей; без `userParams`/`setUserID`. Truth — `activity_events` (H2378).

План целей и механика моста: [docs/METRIKA_GOALS_SHOP_CABINET_2026-09-18.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/METRIKA_GOALS_SHOP_CABINET_2026-09-18.md).
