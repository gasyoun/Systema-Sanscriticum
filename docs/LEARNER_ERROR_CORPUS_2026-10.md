# H6252 — Корпус ошибок учеников: рейтинг проблемных лемм и форм

_Created: 25-11-2026 · Last updated: 25-11-2026_

_Dr. Mārcis Gasūns_

Артефакт: [`learner_errors_2026-10.csv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/learner_errors_2026-10.csv) — 809 вхождений (без учёта строки заголовка). Экспортёр: [`ExportLearnerErrorCorpus.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Console/Commands/ExportLearnerErrorCorpus.php), ядро извлечения: [`LearnerErrorCorpusExtractor.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/LearnerErrorCorpus/LearnerErrorCorpusExtractor.php).

## 1. Что именно собрано

Первый корпус реальных учебных ошибок школы: частотный рейтинг проблемных лемм и грамматических форм, полученный из двух источников:

| Источник | Вхождений | Природа |
|---|---:|---|
| `homework-review` (комментарии проверяющих) | 269 | Исправления учителя — прямой след ошибки ученика |
| `homework-submission` (работы учеников) | 4 | Сопроводительный текст сдачи |
| `stenogrammy` (расшифровки занятий) | 536 | Фрагменты разбора ошибок на занятиях |
| **Итого** | **809** | Порог приёмки ≥500 пройден |

Источники обработаны локально; в артефакты не попали ни тела сообщений, ни пути к корпусу, ни имена.

## 2. Схема анонимизации (152-ФЗ)

CSV содержит ровно шесть колонок и **не содержит ни одного текстового фрагмента исходника**:

| Колонка | Содержание | PII-риск |
|---|---|---|
| `anon_id` | `u_`/`s_` + первые 12 hex `sha256('h6252|…')` | Ноль: односторонний хеш, без соли обратимого ключа нет |
| `source` | `homework-review`, `homework-submission`, `stenogrammy` | Ноль: таксономия источника |
| `lemma` | Только деванагари-последовательность либо IAST-токен с диакритикой | Ноль: отбор по алфавиту, e-mail/телефон/PII-тег отбрасываются |
| `form` | `devanagari` либо `iast` | Ноль |
| `error_type` | Фиксированная таксономия (см. §3) | Ноль |
| `context_hash` | `sha256` окна ±180 символов вокруг токена | Ноль: хеш, исходное окно не сохраняется |

Перед извлечением каждый текст проходит через существующий [`SupportStudentPiiMasker`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Support/SupportStudentPiiMasker.php) (H6182/H6918) в режиме `maskOrFail()` — при недоступности identity-сета текст **целиком отбрасывается** (fail-closed), а не попадает в выход. Дополнительно экстрактор отклоняет токены с `@`, цифровыми последовательностями ≥4 и маркерами `<PII:…>`.

Проверка на артефакте: 0 строк с кириллицей, 0 строк с `@`, 0 некорректных строк (все 809 строк имеют ровно 6 полей).

## 3. Методика извлечения

1. **Выгрузка.** Комментарии домашних заданий читаются из БД `HomeworkComment::whereNotNull('body')` (read-only, `cursor()`); срез расшифровок — из локального корпуса стенограмм,odings только строки с явными маркерами разбора ошибки (`ошибк`, `неправильн`, `обрати внимание`, `исправ`, `неточн`, `ошибоч`).
2. **Маскирование.** Каждый текст маскируется `maskOrFail()`; при исключении запись пропускается.
3. **Токенизация.** Из маскированного текста выбираются только деванагари-словоформы и IAST-токены, содержащие диакритику (`ā`, `ī`, `ū`, `ś`, `ṇ`, …). ASCII-слова (английский, служебные слова) не попадают в корпус.
4. **Классификация.** `error_type` определяется по маркерам в окне ±180 символов: `sandhi`, `long-vowel`, `orthography`, `case-ending`, `verb-form`, `transliteration`, `calligraphy`, `prosody`, `vocabulary`; при отсутствии маркера — `orthography` (дефолт контекста исправления).
5. **Ранжирование.** Строки сортируются по убыванию частоты тройки `lemma|form|error_type`, затем лексикографически — детерминированный воспроизводимый порядок.

Распределение по типам: `orthography` 626, `long-vowel` 65, `verb-form` 28, `vocabulary` 25, `calligraphy` 21, `case-ending` 18, `transliteration` 13, `sandhi` 11, `prosody` 2.

## 4. Canary — контроль PII-масок

Команда `php artisan learner-errors:export --canary` прогоняет 20 заранее известных примеров (имена, e-mail, телефоны в трёх форматах, само-представления, `@`-хэндлы, номера заказов) через тот же маскер. Результат прогона на реальном identity-сете: **20/20 замаскировано, exit 0**. Ограничение: примеры со смешанными формами (инициалы, телефон не начинающиеся с 7/8) не являются отдельным классом детектора и в canary не входят — это известная граница маскера, а не регрессия.

## 5. Воспроизведение

```bash
# На узле с БД и локальным корпусом стенограмм:
php artisan learner-errors:export \
  --harvest-db \
  --stenogrammy-dir=/path/to/stenogrammy \
  --output=storage/app/learner_errors_2026-10.csv \
  --min-rows=500
php artisan learner-errors:export --canary
```

Команда.fail-closed: при числе строк `< --min-rows` возвращает ненулевой код. `--input` принимает JSONL уже замаскированных записей для прогона на машине без БД.

## 6. Честные ограничения

- Это **первый, эвристический** корпус, не золотой лингвистический стандарт. `error_type` выводится из контекстных маркеров, а не из ручной разметки; часть определяний — автоматическая.
- Источникдомашних работ невелик (182 работы, 292 текста), поэтому 536 из 809 вхождений приходятся на срез расшифровок.
- Токены из расшифровок могут содержать шум OCR/транслитерации (`ahāchmin`, `banı`), что отражено в рейтинге без сглаживания — корпус намеренно показывает реальное состояние данных.
- Никаких записей в сам корпус, изменение видимости репозитория или публикация тел/путей не производилось (152-ФЗ, H2641/H8050).
