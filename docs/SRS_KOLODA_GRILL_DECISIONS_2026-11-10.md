# Grill-решения — улучшение SRS-колод (программа треков А–Г)

_Created: 10-11-2026 · Last updated: 10-11-2026_

Контекст: вопрос MG «в Системе есть Карточки. Как их улучить?» + тред Telegram от
10-11-2026 (David Dalé, три идеи: персональные колоды, пополняемые по источнику без
повторов; колоды разного размера/темы/сложности под конкретную потребность;
интервальное повторение грамматических явлений с ротацией примеров и масштабируемостью
без LLM-расходов). Сессия `/grill-with-docs`: 4 раунда фронтира + подтверждение общего
понимания (Q20). Исполнитель сессии: MiMo-V2.6-Flash (opencode, `xiaomi-token-plan-sgp`).

## Исходные факты (домашка сессии)

- Движок готов и жив: FSRS-6 ([app/Services/Srs/Fsrs.php](../app/Services/Srs/Fsrs.php)),
  5 режимов ревью (H1988), авторинг (H1487), прана/стрики, статистика.
  Переписывание планировща, SM-2, AnkiWeb-sync — ruled non-goals
  ([docs/SRS_ROADMAP_2026.md](SRS_ROADMAP_2026.md)).
- Контента много, навигации нет: 5 курсов Memrise, Anki Hindi Core 100,
  Bühler-парадигмы (78 карточек, теги `lemma`+`stem_class`, PR
  [#1073](https://github.com/gasyoun/Systema-Sanscriticum/pull/1073)), 570 корней,
  200 лигатур, урок-деки. В `srs_decks` **нет полей** topic/difficulty/tags
  ([app/Models/SrsDeck.php](../app/Models/SrsDeck.php): только name/slug/language/
  visibility + привязки); единственный фильтр хаба — язык (H1992,
  [app/Http/Controllers/SrsController.php](../app/Http/Controllers/SrsController.php)).
- Кросс-декового «уже выучено» нет: дедуп только внутри импорта (идемпотентность);
  задел — `srs_cards.source_word_id → DictionaryWord`, состояние per user×card.
- Идея №3 (грамматические явления): prior art — Bühler Option A (isolated cells;
  Option B отложена), авто-склонения из индекса Зализняка (98 639, не построено),
  verb-class trainer (не построен). Пулов примеров с ротацией — нет нигде.
  Свежий контекст: DSG-спайн 119 терминов от 07-11-2026 — «не SRS-ить сырую частоту».

## Применённые дефолты (не были объектом отдельного голосования)

1. Границы сегментов мега-деков (500/2000/остальное) и источник частотного ранга —
   существующие активы kosha/DCS, уточняются в брифе H7966; ничего не изобретать.
2. Новые `visibility` не заводим: таксономия рендерится на существующих страницах
   колод и гостевом триале (H1981).
3. Импорт-дедуп — только к системным артизан-импортам; ручное авторство студентов
   не трогаем (очередь и так фильтрует персонально).
4. Фильтр очереди — единообразно в `ReviewService::queueFor` для всех колод
   ([app/Services/Srs/ReviewService.php](../app/Services/Srs/ReviewService.php)) —
   это трек Б, не входит в Edit Scope H7966.
5. Оценка метрики WAU+разброс — с поправкой на шум (4 WAU); строка «разброс»
   оживёт с треком А.
6. Г-трек: P5 (хинди-контент) и P6 (аудио) остаются @WAITING по своим блокерам и в
   первую волну не входят.

## OPEN-узлы (записаны как незакрытые)

- **Форма интеграции спайка В** в продукт (новая note-type в ревью vs отдельный
  режим «грамматика») — гриллим при старте В.
- **Onboarding-программа для 1 152 не-стартеров** (29/1 161 вообще, 4 WAU) — @DECIDE
  MG, вне осей программы.
- **Границы сегментов и таксономические оси** — уточнение в брифе H7966 (дефолт 1).

## Исполнение

- Порядок: **А (H7966) → Б → В → Г**, каждый трек отдельным хэндоффом после
  закрытия предыдущего.
- Трек Б (known-words, оба уровня, same-shape, зрелость ≥ 21 д) и трек В (спайк
  падежных форм, гибридный пул, gold ≥ 95 %) минтятся по мере приближения очереди —
  брифы берут решения из этой таблицы.
- GTD: строка @DO на исполнение H7966; строка @DECIDE на онбординг-программу.

## Глоссарий

- **Трек А** — таксономия колод (тема/размер/сложность) + discovery-фильтры + сегментация мега-деков.
- **Трек Б** — known-words: «не повторять уже выученное» (импорт-дедуп same-shape + фильтр очереди).
- **Трек В** — спайк «грамматические явления с ротацией примеров» (первая семья — падежные формы).
- **Трек Г** — бэклог-полировка ревью-контура (P2b/P3/P4; P5/P6 @WAITING).
- **Зрелая карточка** — карточка с FSRS-интервалом ≥ 21 дня; порог «уже выучено».
- **Known-words** — фильтр, пропускающий зрелые по той же лемме карточки того же типа.
- **Пул ротации** — набор примеров явления, из которого каждое повторение даёт новый пример.
- **Мега-дек** — системная колода порядка 10 тыс. карточек (`sanskrit-core`, `sanskrit-cyrillic-only`).
- **Разброс подписок (spread)** — распределение студентов по колодам; guardrail-метрика, baseline 0 строк.
- **Offline-генерация** — разовая генерация контента агентом вне ревью-контура; runtime-LLM запрещён.

## Non-goals (подтверждены или не пересматривались)

- Runtime-LLM в ревью-контуре; анонимная персонализация для гостей.
- Контент вне sa/hi в этой программе (мультиязычность — только архитектурная посадка).
- `.apkg`/AnkiWeb-sync, SM-2, облачный TTS — старые rulings
  ([docs/SRS_ROADMAP_2026.md](SRS_ROADMAP_2026.md)), не перепредложены.
- Активация не-стартеров — вне осей (OPEN @DECIDE выше).
