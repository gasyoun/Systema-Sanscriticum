## Intended use / known misuse

**Intended use.** A planning reference for scoping and sequencing Sanskrit-HUB build work: which
workstream (A–E) a given session's task belongs to, which quarter it falls in, which pedagogy rung
or asset it should connect to, and which prior positioning decision already constrains the choice
(unified platform / `samskrtam.ru/sanskritHUB` / open-core+courses / all-four-docs). A future
session picking up Sanskrit-HUB work should read the roadmap + asset-pedagogy index before
proposing new structure, not re-derive workstream boundaries from scratch.

**Known/likely misuse.**
- Treating roadmap quarters/dates as committed delivery dates rather than planning targets — only
  the 28 Aug 2026 marathon (H440) is a real commitment; everything else can and will slip.
- Quoting "the number-one place for Sanskrit on the internet" as a measured claim rather than the
  positioning goal it is — the actual measurable proxy is the Year-2 north star in the roadmap
  (≥3 external citations, open-core revenue covers infra, A0→C2 populated).
- Re-opening the four locked positioning decisions (platform unification, home repo, business
  model, four-doc scope) without a fresh `@DECIDE` — they were closed 10-07-2026 by MG via
  structured questions and are not open for silent re-litigation inside a build session.
- Using the asset counts / link inventory as current without re-verification — they are a
  04-07-2026 `FEATURES_INDEX.md` snapshot, spot-checked only (backlog item 1), and the org's asset
  base changes weekly.

## Maintenance & sunset plan

The four-doc set is owned by whichever session is doing Sanskrit-HUB build work in
[`Systema-Sanscriticum`](https://github.com/gasyoun/Systema-Sanscriticum) — there is no dedicated
maintainer process; it is kept alive by being read and updated at the start of each Sanskrit-HUB
session (per this repo's `.ai_state.md` protocol) rather than by a scheduled review. The five
open backlog items above (link verification, the 5 roadmap `@DECIDE`s, the audio spike, per-quarter
handoffs, KPI dashboard) are the concrete signal that the plan is still active and not yet stale.
"Archived/ended" for this set means one of: (a) the roadmap's 8 quarters complete or are formally
abandoned and superseded by a Year-2+ plan, (b) the four positioning decisions are reversed by a
new `@DECIDE` round, forcing a rewrite rather than an update, or (c) Sanskrit-HUB itself is
deprioritized below Tier-0 in [`Uprava/GTD_NEXT_ACTIONS.md`](https://github.com/gasyoun/Uprava/blob/main/GTD_NEXT_ACTIONS.md)
§ Priority tiers, at which point the set moves to `handoffs/archive/`-style retirement rather than
continued live editing.
