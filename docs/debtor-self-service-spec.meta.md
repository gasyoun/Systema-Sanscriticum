## Известные ограничения / оговорки

- Спека описывает Phase 1 на момент 04-07-2026; фактический код мог разойтись с именами компонентов и маршрутов — метадок не верифицировал их против репозитория.
- Решения зафиксированы как «MG, 04-07-2026»; если бизнес-правила рассрочки менялись позднее, оговорки (промокод/прана не применяются) могли устареть.
- Граница фазы (что НЕ входит) — намеренный срез; часть отложенного покрывается сиблингом Phase 2, часть остаётся ручной работой куратора.

## Назначение / ожидаемое злоупотребление

- **По назначению:** входная точка для разработчика Phase 1 и для сессии, планирующей Phase 2; карта «что переиспользовать, чего не трогать».
- **Злоупотребление:** трактовать спеку как отражение текущего состояния кода (это план, а не аудит), либо реализовывать по ней Phase 2-функции, явно вынесенные за границу Phase 1.

## План поддержки и вывода из эксплуатации

- Обновлять при старте реализации (отметить сделанное), при появлении фич-теста и при мёрже Phase 1.
- Когда Phase 1 внедрён и покрыт тестами, спеку перевести в состояние исторической записи (архив реализации), передав живой фокус сиблингу Phase 2.
- Sunset: после закрытия Phase 2 обе спеки становятся историческим контекстом сервиса «Должники»; активным документом остаётся [`docs/debtors-manual.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/debtors-manual.md).
