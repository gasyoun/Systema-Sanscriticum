# Инструкция для бухгалтера

_Created: 02-07-2026 · Last updated: 21-08-2026_

Операционная книга и **карта денег школы** живут **в кабинете**, не в этом файле. Откройте панель и пункт **«Как работать бухгалтеру»**:

[https://samskrte.ru/admin/accountant-guide](https://samskrte.ru/admin/accountant-guide)

Живая очередь «какой расход был выплатой преподавателю» — отдельный экран рядом:

[https://samskrte.ru/admin/payout-attribution-guide](https://samskrte.ru/admin/payout-attribution-guide)

Этот документ — карта меню для команды. Пошаговых сумм и живых фамилий здесь нет (репозиторий публичный). Карта ролей — в [`finance-manual.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/finance-manual.md).

> Роль назначает супер-админ. Если разделов из карты нет — у учётной записи другая роль.

## Куда зайти

1. Адрес панели: [https://samskrte.ru/admin](https://samskrte.ru/admin).
2. После входа — группа **«Финансы»** → **«Как работать бухгалтеру»**.
3. На рабочих экранах (Финансы, Зарплаты, Расходы, Штурвал, Потоки, разметка выплат) справа вверху — та же кнопка.

## Карта меню

| Раздел | Группа | Что делать бухгалтеру |
|---|---|---|
| Как работать бухгалтеру | Финансы | Открыть книгу сценариев |
| Финансы (транзакции) | Продажи | Проводки, импорт, возвраты |
| Зарплаты | Продажи | Калькулятор блока, авансы, закрытие месяца |
| История выплат | Продажи | Журнал и экспорт |
| Финансовый штурвал | Финансы | ОПиУ, ДДС, Баланс, календарь |
| Расходы (opex) | Финансы | Операционные расходы школы |
| Планирование (шаблоны) | Финансы | Скачать excel-книги |
| Потоки курса | Финансы | Сравнение потоков, только чтение |
| Как размечать выплаты | Финансы | Живая очередь, не GitHub |
| Взаимозачёт | Финансы | Преподаватель = ученик, акт не перевод |
| Участники по блокам | Пользователи | Кто какой блок оплатил, только чтение |
| Студенты | — | Только просмотр карточки |
| Дашборд | — | Сводка |

## Чего в этой роли нет (это нормально)

- Должники и реактивация — администратор.
- Журнал финансов — супер-админ.
- Лиды, курсы, уроки, расписание, сертификаты, группы, домашние работы — другие роли.
