# Памятка: ответить на вопрос про следующий поток за пять минут

_Created: 18-08-2026 · Last updated: 19-08-2026_

Одна страница для бухгалтера. Полное описание раздела — §4k
[инструкции бухгалтера](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/accountant-guide.md).

## Куда зайти

1. `https://samskrte.ru/admin` — вход по своему email и паролю.
2. Левое меню → группа **«Финансы»** → **«Потоки курса»**.
3. Вверху — выпадающий список **«Семья потоков»**. «Кашмирский шиваизм» открывается
   сразу, выбирать ничего не нужно.

## Какие четыре цифры смотреть

| Что | Где на экране | Что означает |
|---|---|---|
| **Уникальных плательщиков** по каждому потоку | таблица «Ученики по блокам», нижняя строка | Сколько живых людей оплатили этот поток. Сравнение потоков между собой — это спрос. |
| **Удержание, блок 1 → последний** | там же, последняя строка | Сколько процентов дошли до конца. Ниже 60 % — повод посмотреть, где отваливаются. |
| **Выручка** каждого потока | блок «Деньги» | Сколько денег принёс поток. Средний чек рядом. |
| **Остаток** преподавателю | блок «Начислено, выплачено, остаток» | Сколько мы, по расчёту, ещё должны преподавателю. |

## Какая цифра предварительная и почему

**Остаток.** Если под ним стоит слово **«предварительно»** и рядом жёлтая плашка —
цифра ещё не ответ.

Причина простая: часть выплат преподавателю проведена в системе не через «Историю
выплат», а обычными платежами с тарифом **«Расход»**, заведёнными на служебного
пользователя «Системные расходы». В данных они выглядят ровно так же, как аренда или
реклама. Программа не имеет права решить за человека, что именно эти суммы — зарплата.

Поэтому экран показывает:

- **выплачено (подтверждённо)** — только то, в чём сомневаться не в чем;
- список **платежей, ждущих подтверждения**, с датой, курсом и суммой;
- строку **«если подтвердить все — остаток станет …»**.

Пока плашка есть, называть остаток преподавателю как окончательную сумму нельзя.

## Что делать дальше

1. **Посмотреть список ждущих подтверждения** (жёлтая плашка). По каждой строке
   вопрос один: это выплата преподавателю или обычный расход школы?
2. **Свериться с банковской выпиской** по датам и суммам из списка.
3. **Сообщить результат** — по итогам разметки остаток станет подтверждённым, и слово
   «предварительно» уйдёт с экрана само.
4. **Выгрузить в Excel** (кнопка вверху справа), если нужно показать цифры кому-то ещё:
   в файл попадают и плашка покрытия, и пометка о предварительном остатке.

## О чём экран честно молчит

- **Посещаемость почти не собрана.** Синяя плашка над блоком «Отток» говорит, по
  скольким людям вообще есть данные. Пустая клетка означает «не собрано», а не «не
  ходил»; отток считайте по оплатам, а не по посещаемости.
- **Курс «в записи» без схемы оплаты преподавателя** даёт начисление ноль. Это не
  ошибка расчёта: начислять не с чего, пока схема не задана.
- **Экран ничего не платит.** Он только показывает. Любая выплата по-прежнему
  заводится руками в разделе «Зарплаты».
