## Граница пилота

Автономно (без человека, под policy-gate):
- FAQ-класс «где материалы/записи» по курсам и расписанию;
- нудж «привяжи кабинет» для непривязанных;
- факты из системы (цена из каталога, запись, доступ) 1-в-1 без пересказа.

Остаётся человеку:
- любое расхождение по деньгам — полное молчание автомата (правило §4 дока куратора);
- сложный вопрос без фактов (хинт «💡», как сейчас);
- сертификаты, возвраты, конфликты.

## Корпус v1

Только материалы курсов + FAQ. История поддержки — ВНЕ корпуса
до закрытия GTD `0KL` (anonymisation-gate по 152-ФЗ).

## Killgate токенов (Q2)

- Потолок пилота на месяц ≤ месячной нормы подписки z.ai Max
  (цифру нормы вписывает MG — TBD, владелец строки: MG).
- Потолок на 1 тикет = месячная норма / плановое число тикетов.
- Нарушение = авто-стоп с трейсом (какой тикет, сколько токенов, на каком шаге).
- Еженедельно: факт vs подписка в §20-замер (п.4–5).

## Метрики (Q3)

- Главная: доля обращений, закрытых без человека (цель: растёт week-over-week).
- Сторожевые: precision цитат на спот-сэмпле N=20 ≥ 95%;
  ноль ПДн в корпусе; ноль авто-ответов в денежных спорах.
- База week-0 — хоть руками (§20), иначе «рост» считать не от чего.

## Go / no-go gate стройки

policy-скелет, математика killgate с цифрой MG, week-0 база.
