## Назначение

Стартовая точка для агента, которому поручено реализовать автооткрытие приёма домашних
заданий. План собран так, чтобы исполнитель работал 5–8 часов без человека: все развилки
закрыты рулингами D1–D14, ни одного открытого `@DECIDE` внутри волны 1.

## Аудитория

Исполняющий агент волны 1; человек, принимающий работу; будущая сессия, которая захочет
включить волну 2 (закрытие + гранты).

- `schedules` не имеет `lesson_id` — прочитана миграция создания таблицы, а не угадано
- `homework.blade.php` уже умеет состояние `awaitingPrompt` — прочитан blade
- в `Kochergina_unicode.mdx` 40 занятий, блоки `Упражнения`, занятия I–V на строках 229–1185
- методичка-компаньон покрывает занятия VI, X, XII, XVI, XVIII, XXI, XXII, XXX, XXXII,
  XXXVII, XXXIX — **занятий 1–5 в ней нет**, поэтому источник только сам учебник
- оба репозитория публичны (`gh repo view`), отсюда ограничение D14

## Ранжированный бэклог улучшений

1. **Спайк «сколько сдают после следующего урока»** — до включения `close_previous`.
   Единственное место, где принятое решение (D8) может оказаться вредным на живых данных.
2. **Отчёт «уроки в охвате без `textbook_lesson`»** — главный способ, которым пилот может
   тихо не сработать.
3. **Числа «до/после» по денежным тестам** — вписать в PR фактические, а не обещание.
4. **Решить судьбу общих уроков (`group_id` пуст) на двух потоках** — сейчас поведение
   честное, но не обсуждённое.
5. **Пересмотреть выравнивание на 09:00**, если поздние заливки записи окажутся частыми.
