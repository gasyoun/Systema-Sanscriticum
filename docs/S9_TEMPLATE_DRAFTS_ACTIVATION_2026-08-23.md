## Известные зазоры (осознанные, не чинились в этом проходе)

1. `{course}` вsuggester-контексте схлопывается в пустоту («Оплатить курс „“…») — задокументированное поведение резолвера; кандидат: course-aware подстановка из фактов диалога.
2. Одна привязка на категорию не различает подтемы (D2 «куда платить» vs D3 «чек получен») — кандидат: выбор среди привязанных по ключевым словам.
3. Ручная отправка канреплая куратором из библиотеки не инструментирована вообще — usage считается только по суггестеру и аудитам правок.
4. 456 uncategorized topic assignments снижают сигнал следующей ревизии.
