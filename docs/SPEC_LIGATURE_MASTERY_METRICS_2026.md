## 1. Определение «лигатура освоена» (тройка)

Пользователь **освоил** лигатурный материал, когда ОДНОВРЕМЕННО выполнены три условия
на его истории повторений лигатурных карточек (колода H6393; до её засева — срез пуст):

| # | Метрика | Формула | Знаменатель | Порог |
|---|---------|---------|-------------|-------|
| M1 | Удержание на интервале ≥21 д | `доля(rating ≠ 1)` среди повторов с `scheduled_days ≥ 21` | повторы с `scheduled_days ≥ 21` | ≥ 0.90 |
| M2 | Точность узнавания | `доля(rating ≠ 1)` по последним ≤20 лигатурным повторам юзера | те же повторы | ≥ 0.90 |
| M3 | Дельта на близнецах | `acc(twins-пробы) − acc(контроль-пробы)` того же юзера | twins- и контроль-пробы | ≥ 0 |

- `rating`: 1=Again, 2=Hard, 3=Good, 4=Easy (шкала FSRS движка); «вспомнил» = `rating ≠ 1`.
- M1 — эмпирическое удержание (Anki true-retention, mature). Ретривабельность FSRS
  (предсказанная R на момент повора) придёт с ре-оптимизацией весов Wave 5 —
  до того эмпирика честнее: не зависит от весов.
- M3, операционализация «дельты» (решение спеки, пересмотреть при телеметрии H6393):
  **остаточная конфузия** — юзер не делает ХУЖЕ на конфузных парах (близнецы из
  gold-сета Киселёвой), чем на одиночных. Альтернативное чтение «pre/post-прирост»
  требует лонгитюдных окон — отложено до режима близнецов H6393.
- Пороги M1/M2 = 0.90 зафиксированы решением MG; порог M3 = 0 — спека (нет
  экспериментального основания требовать прироста, есть — требовать отсутствия дефицита).

## 2. Harm-метрика (канарейка контента)

**harm = число ложных канонических форм в контенте колоды. Канарейка: harm = 0.**

Контент-источник (до канона H6392): [`public/lila/ligatures/data.js`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/public/lila/ligatures/data.js) — 200 уникальных лигатур топ-200 DCS; после засева колоды H6393 — плюс фронты карт лигатурных колод из снапшота.

Форма **канонична**, когда:

1. `s == NFC(s)` (нормализованность; у деванагари нет канонических декомпозиций,
   поэтому проверка дешёвая страховка, а не основной фильтр);
2. все символы — блок Devanagari `U+0900..U+097F`, без ZWJ/ZWNJ/пробелов/контрольных;
3. структура — конъюнкт `C (् C)+`: согласные, соединённые вирамой, ≥2 согласных,
   без висячей вирамы в конце;
4. романизация сходится: склейка IAST-глосс согласных по вираме = полю `iast`.

Любое нарушение = ложная форма (вред: учим неверному написанию/чтению).
Негативный контроль: ZWJ-склейки, латиница, висячая вирама, пробелы, рассинхрон iast —
все ловятся (см. приёмку PR). Позитивный: 0/200 на живом контенте.

## 5. Одна команда пересчёта

```sh
python3 scripts/ligature_mastery_eval.py          # таблица человеком
python3 scripts/ligature_mastery_eval.py --json   # машиночитаемо
```

Выход `0` — harm = 0 (канарейка чиста); выход `2` — найдены ложные формы.
Скрипт — stdlib-Python, без БД/сети: каждое число базлайна пересчитывается из
закоммиченного снапшота + контента.
