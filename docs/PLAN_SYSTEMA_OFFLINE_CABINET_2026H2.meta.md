## Known limitations

The plan intentionally does not select a secure-key Capacitor plugin before the capability
spike, because viability, tracked configuration, bridge access under remote `server.url`, and
performance are acceptance evidence rather than assumptions. It does not authorize deployment,
pilot enrollment, or video downloads.
