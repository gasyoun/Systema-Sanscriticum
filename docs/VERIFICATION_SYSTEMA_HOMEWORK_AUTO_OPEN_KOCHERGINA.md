## Критерии приёмки

| # | Результат | Критерий | Чем доказывается |
|---|---|---|---|
| A1 | Точка отсчёта | у урока без видео `recording_attached_at` пуст; после первого сохранения с видео — заполнен; повторная замена видео его НЕ двигает | `recording_stamp_is_set_once` |
| A2 | Расчёт момента | запись в 06:00 → открытие завтра 09:00; в 20:00 → завтра 09:00; в 21:30 → послезавтра 09:00 | `opens_at_aligns_to_next_nine_msk` (табличный тест по четырём краям из архитектуры) |
| A3 | Открытие | до момента `homework_enabled` ложно; после прогона команды — истинно, `homework_auto_opened_at` заполнен | `lesson_opens_after_delay` |
| A4 | Идемпотентность | второй прогон в тот же час не меняет `homework_auto_opened_at` и не шлёт второй пуш | `second_run_does_not_reopen` |
| A5 | Условие подставляется | `homework_prompt` содержит текст упражнений занятия N из источника | `prompt_is_filled_from_source` (синтетический mdx-фрагмент) |
| A6 | Ручное условие не затирается | если `homework_prompt` уже написан преподавателем, автомат его не трогает | `manual_prompt_is_preserved` |

| A14 | Ничего не сломано | зарплатный и платёжный наборы тестов зелёные до и после, с тем же числом ассертов | прогон до/после, числа в PR |

| A17 | **Две отсечки инверсии охвата** (H3078) | курс, начавшийся до `min_course_start`, вне охвата; начавшийся после — в охвате; урок с моментом открытия раньше `policy_epoch` не открывается никогда, позже — открывается | `course_that_started_before_the_floor_is_out_of_scope` · `course_that_started_after_the_floor_is_in_scope` · `lesson_due_before_the_policy_epoch_never_opens` · `lesson_due_after_the_policy_epoch_opens` |

## Команды проверки

```
composer install                       # в worktree, СВОЙ vendor, без junction
php artisan migrate --pretend          # миграция читаема и обратима
php artisan test --filter=AutoOpenHomework
php artisan test tests/Feature/Homework
php artisan homework:auto-open --dry-run
./vendor/bin/pint --test
```

Контрольный прогон на отсутствие регрессии в денежном контуре:

```
php artisan test --filter=TeacherSalary
php artisan test --filter=Payment
```

Числа «до» и «после» выписываются в тело PR. Расхождение в числе ассертов — это стоп по
контракту автономии, а не повод пожать плечами.

## Ручная проверка на одном уроке

Автотесты не покрывают того, что рассылка реально доходит. После мержа, на одном уроке:

1. Проставить `textbook_lesson` и добавить в `course_slugs` курс Кочергиной.
2. `php artisan homework:auto-open --dry-run` — убедиться, что урок в списке и время верное.
3. Прогнать без флага, открыть кабинет студентом — форма сдачи на месте, условие читаемое.
4. Проверить, что пуш пришёл один раз.

## Риски и незакрытые допущения

| Риск | Почему он реален | Что делаем |
|---|---|---|
| ✅ **`textbook_lesson` никто не проставит** — и пилот тихо не сработает | поле новое, заполняется руками, пять строк легко забыть | **РЕАЛИЗОВАЛСЯ 28-07-2026, закрыт 18-08-2026 (H3068).** Гр.60 и гр.61 встали на занятии #3: шесть уроков с записью и без приёма, студенты спрашивали куратора «куда прикреплять ДЗ». Пассивный отчёт волны 3 не помог бы — его тоже надо читать. Пустой `textbook_lesson` больше не выбрасывает урок из выборки (`open_without_textbook_lesson`, по умолчанию `true`): приём открывается с отсылочной формулировкой, а админам уходит push-напоминание проставить номер (`missing_mapping_alert`). `--dry-run` с пустым списком остаётся сигналом, но перестал быть ЕДИНСТВЕННЫМ |
| **Правовой** — воспроизведение текста Кочергиной 1998 в коммерческом кабинете | решение D6 принято человеком 27-07-2026 после того, как ограничение было названо; папка-источник фиксирует охрану авторского права | D14: текст не коммитится в публичный репозиторий и не пишется в `is_free`/`is_preview` уроки. Дальнейшее — не инженерный вопрос |
| **Парсер mdx хрупок** | заголовки занятий — обычный текст, не разметка; правка оцифровки может сдвинуть границы блока | `forLesson()` возвращает `null` вместо мусора при неуверенности; открытие не блокируется; тест на синтетическом фрагменте фиксирует контракт формата |
| **Поздняя заливка записи** двигает открытие на послезавтра | следствие выравнивания на 09:00 | принято (см. таблицу краёв); `homework_opens_at` виден в админке, монтаж можно поторопить |
| **Общий урок (`group_id` пуст) на двух потоках** | одна запись — одно открытие для обеих групп | в пилоте уроки Кочергиной привязаны к группе; для общих уроков поведение честное — открывается всем сразу |
| **Автозакрытие волны 2 отрезает догоняющих** | D8 закрывает предыдущее ДЗ при открытии следующего | D12: грант `HomeworkAccessGrant`; `close_previous` по умолчанию выключен, включается отдельно и осознанно |

## Спайк перед волной 2

Прежде чем включать `close_previous`, посчитать на живых данных: сколько работ сдаётся
**после** того, как вышел следующий урок. Если доля велика, ритм «одно ДЗ за раз» отрежет
реальных студентов, и правило D8 нужно будет обсуждать заново, а не выкатывать. Запрос — по
`homework_submissions.created_at` против `lessons.homework_auto_opened_at` следующего урока.
