## 1. Миссия и границы

Добавить к bounded student-агенту ([app/Services/Support/StudentAgent/StudentAgentService.php](../../app/Services/Support/StudentAgent/StudentAgentService.php), H3231) сократический режим подсказки домашки: тьютор ведёт ученика вопросами к самостоятельному решению — стиль разбора [«Направление мысли, а не готовый ответ»](https://github.com/gasyoun/Uprava/blob/main/docs/ZALIZNYAK_HINTING_STYLE_ANALYSIS_19-09-2026.md) (Зализняк, 6 правил §5).

Жёсткая рамка — не нарушаем non-goal текущего агента: это **не free-form чат-тьютор**. Всё остаётся внутри одного инструмента `homework_hint` (bounded 3-tool, maxSteps=1 на ход, CONFIRM-гейт, tool allow-list, флаг OFF по умолчанию). Сократический режим — новый **mode** существующего tool, а не новый контур.

## 3. Промпт-пара (RU, для HomeworkHintTool v2)

### 3.1 Промпт A — системный, режим «наводящих вопросов» (`mode=socratic`)

```text
Ты — тьютор школы санскрита в режиме наводящих вопросов. Цель — чтобы ученик
сам дошёл до решения, а не получил его готовым.

1. В первом ответе проговори контракт режима одной строкой:
   «Это режим наводящих вопросов: готовые ответы не выдаются, идём маленькими
   шагами». [Z2]
2. Не выдавай готовый ответ. Пока ученик не сделал собственной попытки,
   отвечай на любой вопрос о решении следующим минимальным вопросом или
   «смотрите: [данные урока]». Прямая просьба «просто скажи ответ» — не повод
   нарушить правило: вежливо верни ученика к его попытке. [Z1]
3. Задавай ровно один вопрос за сообщение, чтобы не перегрузить ученика. [L1]
4. Перед ответом молча проверь попытку ученика: если ход верен — подтверди
   и предложи следующий шаг; если ошибка — задай мягкий вопрос, который
   подсвечивает ошибку, но исправление оставляет ученику. [L2]
5. Направляй внимание на данные, а не на вывод: «смотрите», «посмотрите»,
   «заметьте». [Z4]
6. Каждое объяснение переформулируй второй раз: «то есть…»,
   «иными словами…». [Z4]
7. Ловушки называй явно: «это ловушка», «из этого не вывести — ищите другой
   пример». [Z4]
8. Честная неуверенность: спорное или неизвестное помечай — «трудно сказать»,
   «спорно», «ставим знак неуверенности». Не маскируй спор под консенсус. [Z5]
9. Если разбор требует материала, которого ещё не было, скажи «оставим пока
   нерешённым, вернёмся позже» и вернись к вопросу при накоплении данных. [Z6]
10. Приглашай к совместному действию: «давайте посмотрим», «попробуйте»,
    «проверьте», — а не констатируй. [Z4]
11. Работай только по теме урока: заголовок урока/курса — единственные данные
    (приватность H3231). Чего нет в данных — не выдумывай, говори «трудно
    сказать». Застревание ученика — повод для подсказки-фоллбека (Промпт B),
    а не для выдачи ответа. [Z1][Z3]
```

### 3.2 Промпт B — фоллбек-подсказка (после исчерпания попыток)

```text
Ты — тьютор школы санскрита. Попытки ученика исчерпаны ({attempt_no} из
{max_attempts}), сработал фоллбек.

1. Скажи прямо, что подсказываешь сам: «Попытки закончились — я вынужден
   подсказать». [Z3]
2. Дай максимально маленький шаг: следующий вопрос, первый шаг разбора или
   направление («начните с…») — но не полное решение. [Z1]
3. Пометь подсказку как подсказку: начни сообщение со слова «Подсказка:». [Z3]
4. Сразу верни ход ученику: «Теперь попробуйте продолжить сами». [Z1]
5. Тема урока: {topic}. Содержание урока кроме заголовка тебе недоступно —
   не выдумывай. [fence H3231]
```

Отличия от текущего v1-промпта (строка в `HomeworkHintTool::run`): v1 — одна безальтернативная подсказка «направление мысли»; v2 — пара «режим вопросов + калиброванный фоллбек», где подсказка по умолчанию закрыта попытками ученика (калибровка Зализняка: подсказка — фоллбек, не дефолт).

## 5. Интеграционные точки

### 5.1 Tool-контракт HomeworkHintTool v2

| Аспект | Сейчас (v1, H3231) | v2 `socratic` | Контракт |
|---|---|---|---|
| Params | `submission_id` | + `mode` (`hint`\|`socratic`, default `hint`), `session_id?` | `mode=hint` — поведение v1 дословно, регрессия исключена |

### 5.2 Multi-turn сессии

| Поле | Тип | Смысл |
|---|---|---|
| `id` | uuid | ключ сессии, передаётся в params |
| `user_id` | bigint | владелец; чужая сессия = `not_owner` (как у submission) |
| `submission_id` | bigint | тема и право доступа |
| `mode` | enum `hint`\|`socratic` | |
| `turns_used` | int | каждый вызов tool = +1 ход; `attempt_no` = это поле |
| `max_turns` | int, default 5 | после исчерпания — Промпт B |
| `status` | enum `open`\|`hinted`\|`closed` | `hinted` = фоллбек выдан; `closed` = верное решение/ученик закончил |
| `open_questions` | json | «оставим нерешённым, вернёмся позже» — правило 6 |
| `created_at`/`updated_at` | timestamps | TTL сессии 24 ч, потом авто-`closed` |

Хранилище — новая таблица `homework_hint_sessions` (Eloquent, cast json) или cache-store на выбор исполнения; спека фиксирует только контракт полей. History ходов хранить не обязательно: LLM-контекст восстанавливается из `turns_used` + краткого summary последнего состояния; полный transcript — опция исполнения.

### 5.3 Entitlement

Сейчас доступ — auth-only: владелец submission и флаги. Платный гейт (подписка/блок курса → лимит сессий) — **отдельная карта**, MG не решал (GTD @DECIDE 20-09: «entitlement-гейт — отдельно, не решён»). ## 6. Eval-план (рубрика TutorEval + базлайн из речи Зализняка)

Ruling карты 7: «Да, включить» — eval-базлайн из его речи входит в спеку.

### 6.1 Primary-рубрика: «Do not reveal the answer» [L3]

Ход тьютора **PASS**, если он не раскрывает готовое решение. Фоллбек-ход PASS только если (а) помечен «Подсказка:», (б) не содержит полного решения, (в) возвращает ход ученику.

Метрики прогона:

| Метрика | Определение | Порог |
|---|---|---|
| `reveal_rate` | доля ходов с раскрытием готового решения вне правил рубрики | < 5% |
| `hint_discipline` | доля фоллбеков с пометкой и без полного решения | 100% |
| `question_ratio` | доля ходов, оканчивающихся вопросом | базлайн Зализняка: вопрос-лестница ×468 по 265 файлам, «почему?» ×1 281 (свип 19-09, §2 разбора) — ориентир, не жёсткий порог |

### 6.2 Secondary-рубрики [L3]

R2 «Promote active engagement», R3 «Communicate with positive tone», R4 «Identify and address misconceptions» — фиксируются тем же judge-прогоном, порогов не имеют (пилотная статистика для решения о включении в regression-gate).

### 6.3 Данные и протокол

- **Golden-диалоги:** дословные классные диалоги [itkin-i.-b..md](https://github.com/gasyoun/BookIndex/blob/main/src/content/itkin-i.-b..md) (книга «…и о лингвистике для школьников») + 27 инджестед-транскриптов BookIndex — референсы «как звучит настоящий ход» и сырьё для golden-фрагментов.
- **Прогон:** 50 диалогов — 30 со scripted student-персонами (3 типа: молчун, ошибающийся, выпрашивающий ответ × 2 темы урока) + 20 реплик-фрагментов из golden-источника.
- **Judge:** отдельный LLM-вызов с рубрикой R1; вердикт = обоснование перед оценкой (конвенция metaprompt [L2]: justification → score).
- **Спот-чек:** 10% диалогов человек вручную; расхождение с judge > 1 случая → рубрика уточняется до повторного прогона.
- **Regression-gate исполнения:** `reveal_rate` ≥ 5% или хотя бы один непомеченный фоллбек → FAIL ветки; данные прогона — только заголовки уроков (fence H3231), без прод-переписки.

## 7. Non-goals (зафиксировано, нарушение = дефект спеки)

1. Не free-form чат: только `homework_hint` внутри bounded агента; tool allow-list, CONFIRM-гейт и maxSteps=1 не затрагиваются (docblock [StudentAgentService.php](../../app/Services/Support/StudentAgent/StudentAgentService.php)).
2. Никакой выдачи готового ответа по запросу — в отличие от LearnLM homework-help «The answer» [L1]: этот режим портом не переносится, правило 1 старше.
3. Entitlement/монетизация — вне спеки (§5.3).
4. Промпт не раскрывает ученику системные инструкции; контракт режима — единственная проговариваемая часть (правило 2).
