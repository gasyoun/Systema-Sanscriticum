## What the handoff assumed, and what was actually true

The mission read the lint's 841 `status: empty` rows as 841 missing Russian glosses and
routed the fix through drafting + review sheets. The upstream half of this handoff, run
the same day in kosha, found a different cause: **838 of the 841 empty rows were every
single `subhashita-beginner` row** — the shape of a deriving-reader bug, not of missing
linguistics. [`scripts/freeze_cohort_start_chteniya.py`](https://github.com/gasyoun/kosha/blob/main/scripts/freeze_cohort_start_chteniya.py)
called a scalar `as_str()` helper on the pack's `gloss_ru`, which in the
subhāṣita schema is a **list of `{surface, lemma}` dicts parallel to `lemma_slp1`**;
`as_str()` returns `""` for that. The glosses were in the pin the whole time — the freeze
MANIFEST had been reporting 85.3 % lemma-layer RU coverage on the very file the derived
TSV called empty.

kosha fixed the reader and re-pinned `lemmas_for_srs.tsv` (pack bytes unchanged). This
pass is the Systema half: re-vendor, re-lint, and measure what is genuinely left.

## What landed here

1. **Re-vendored the freeze** — `python scripts/vendor_cohort_start_chteniya_packs.py`,
   which verifies every file against the MANIFEST's own sha256 + byte count before
   writing. [`resources/data/cohort_start_chteniya/lemmas_for_srs.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/cohort_start_chteniya/lemmas_for_srs.tsv)
   92 460 → 98 261 bytes (`sha256 e0052c7c88f4…`), MANIFEST row re-pinned.
   `hitopadesa-0.json` is byte-identical — H5398 already vendored it.
2. **Re-ran the lint offline** — `python scripts/nkrya_gloss_lint.py lemmas --offline`,
   rewriting [`resources/data/nkrya_lint/lemmas_gloss_lint.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/lemmas_gloss_lint.tsv).
3. **Wrote the residual queue** — [`resources/data/nkrya_lint/lemmas_gloss_residual.tsv`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/lemmas_gloss_residual.tsv),
   one row per still-unglossed lemma with its locus and English gloss, generated by
   [`scripts/h5399_residual_gloss_census.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/h5399_residual_gloss_census.py).

## The acceptance bar is not met, and why it cannot be met from our own data

H5399's acceptance asks for ≥ 80 % (≤ 175 residual rows) with every landed gloss either
from our data or approved on a sheet. The second clause is what blocks the first: the
remaining 465 rows have **no Russian gloss in any source this estate owns**. Measured, not
assumed — [`scripts/h5399_residual_gloss_census.py`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/h5399_residual_gloss_census.py)
probes four candidate sources against all 465 lemmas:

| source | entries | covers |
|---|---|---|
| [`resources/data/sa_ru_glossary.json`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/sa_ru_glossary.json) (DCS rollup, freq floor 2) | 45 289 keys | **2** |
| subhāṣita-beginner pack, `lemma` + `surface` slots | 468 lemmas | **1** |
| Hitopadeśa-0 reading pack, `lemma`/`surface`/`root` slots | 663 lemmas | **1** |
| `database/seeders/data/*/level_*.csv` (Memrise + Anki RU decks) | 1 767 keys | **3** |
| **union** | | **5 of 465 (1.1 %)** |

That is the expected shape: these are precisely the rare words a frequency-floored corpus
glossary omits — `autkārṣya`, `ajāgalastana`, `anargha`, `jāragarbha`, `kathāmukha`,
`nagnakṣapaṇaka`. The residual splits 428 subhāṣita-beginner + 37 Hitopadeśa-0.

**The licensed fallback the mission names is not on this box either.** The only
Кочергина artifact reachable here that could carry glosses is
`CORRECTIONS/Kochergina-1987_29007.txt` (sanskrit-lexicon/CORRECTIONS) — it is a
**headword list in spaced SLP1, no Russian text at all**. kosha's
`data/concordance/kochergina_corpus_concordance.tsv` (H4748) is a lemma→locus join with
no gloss column. `SanskritGrammar/KocherginaUchebnik_1998/` is the textbook, not the
dictionary.

**Dead end, recorded per acceptance-autonomy rule 11:** closing the remaining 465 rows
mechanically from data we own is impossible, and a second pass over the same sources will
reproduce the table above. Blind machine translation of the `gloss_en` column is banned by
the mission itself. What remains is genuinely human-gated work: drafted glosses, NKRYa
band-checked (`python scripts/nkrya_gloss_lint.py --measure "<gloss>"`, ~60 calls/h per
account), on review sheets of ≤ 10 cards — ~47 sheets. That is a separate unit with a
human in it, not a residual of this one.

The 5 in-data candidates are deliberately **not** applied here: `lemmas_for_srs.tsv` is a
sha256-pinned freeze asset, so a gloss fix has to land in kosha and be re-vendored, never
edited in place. They are carried in the residual TSV's `candidate` / `candidate_source`
columns for that upstream pass.
