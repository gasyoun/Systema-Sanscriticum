## Чек-лист настройки

### Шаг 1 — взять webcal-ссылку фида · _веб, ~1 мин_

1. Зайти на сайт → `/teacher-calendar` (страница выдачи фида для
   преподавателя/админа, H6347; до неё токен выдавался только в студкабинете
   `/calendar`).
2. Скопировать **webcal-ссылку** с этой страницы.

> [!NOTE]
> Фид после H6347 содержит занятия и по студенческим членствам, и по группам,
> где пользователь **преподаёт** (courses.teacher_id / course_teacher pivot).

### Шаг 2 — подписать календарь Google на фид · _веб, ~2 мин_

1. На компьютере: calendar.google.com → слева «+» рядом с «Другие
   календари» → **«По URL»**.
2. Вставить webcal-ссылку (Google сам превращает `webcal://` в `https://`).
3. Проверить: в календаре появилась суббота 17.10.2026 09:00 «Грамматика по
   Кочергиной гр.57».

### Шаг 3 — дефолт-алерт 10 минут · _веб + планшет, ~2 мин_

> [!WARNING]
> **Google/Samsung Calendar у подписанных (webcal) календарей ИГНОРИРУЮТ
> VALARM** из фида: серверные напоминания (свойство `TRIGGER:-PT10M` в
> VEVENT) не доезжают до подписки. Поэтому алерт ставится **в приложении**:

1. calendar.google.com → шестерёнка → Настройки → выбрать добавленный
   календарь → «Уведомления о событиях» → **10 минут** (для «всё новое»).
2. На планшете (Google Calendar): Настройки → этот календарь → уведомления
   по умолчанию → **всплывающее + звук**; в Samsung Calendar: Настройки →
   «Время напоминания по умолчанию» → 10 минут.
3. Убедиться, что Samsung Calendar синхронизирует учётную запись Google
   (Настройки → Учётные записи → Google → Calendar).

### Шаг 4 — правило MacroDroid/Tasker «громко, поверх DND» · _планшет, ~5 мин_

Вариант A — **MacroDroid** (проще):

1. Установить MacroDroid, выдать разрешения: «Не беспокоить» (DND access),
   изменение системных настроек, автозапуск (Samsung: Настройки → Батарея →
   Неограниченно для MacroDroid).
2. Макрос «Занятие — громко»:
   - **Триггер:** «Событие календаря» → «Начало события» → все календари
     (или только фид-календарь расписания).
   - **Действия:** «Не беспокоить» → **выключить**; Громкость мультимедиа →
     максимум; Громкость системы → максимум; Громкость звонка → максимум;
     «Воспроизвести звук» → выбрать громкий сигнал (или «Сигнал будильника»).
   - Дополнительно: «Вибрировать» 3 с.
3. Тест: создать пробное событие через 2 минуты → tablet орёт при DND.

Вариант B — **Tasker** (гибче): Profile → Event → **Calendar Entry** (дата
любая) → Task: `Do Not Disturb` off → `Media Volume` 15 → `System Volume` max
→ `Alert Sound` → `Vibrate`. Разрешения те же: DND access + безлимитный
режим батареи для Tasker. Физические шаги на планшете исполняет **MG**.

### Шаг 5 — проверка канарейкой · _Tailscale/ручками_

Канарейка: пользователь «Гасунс Марцис Юрьевич» (teacher id 2) — его фид
после H6347 содержит субботы 09:00 МСК группы 89 «Грамматика по Кочергиной
гр.57» (#39 17.10.2026 — #74 19.06.2027):

```sh
curl -s "https://<host>/calendar/feed/2/<токен>.ics" | grep -E "SUMMARY|VALARM|TRIGGER" | head
```

Ожидаем: `SUMMARY:...гр.57`, `BEGIN:VALARM`, `TRIGGER:-PT10M` в каждом
VEVENT. Планшет доступен из Tailscale — при дистанционной проверке правил
MacroDroid можно дёргать тестовое событие через calendar.google.com с любого
устройства.

## Оговорки

- VALARM в фиде — не «оживой» будильник для подписок: это страховка для
  локального импорта `.ics` и для календарей, уважающих VALARM. Рабочий
  будильник = дефолт-алерт приложения (шаг 3) + MacroDroid/Tasker (шаг 4).
- При «Обновить ссылку» старый токен отзывается — шаги 2–3 придётся
  повторить на всех устройствах.
