# Партнерская (агентская) программа

_Created: 07-07-2026 · Last updated: 07-07-2026_

B2B-программа: внешний партнер (коллега, знакомый по совместным проектам)
рекомендует наши курсы и получает **фиксированную денежную выплату** за каждого
приведенного клиента, впервые оплатившего курс. Отдельная от студенческой
реферальной программы ([`config/referral.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/config/referral.php) —
кредит на счет самого студента); здесь вознаграждение — реальная выплата
внешнему человеку.

Всё за флагом [`config/partner.php`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/config/partner.php)
→ `partner.enabled`, по умолчанию **ВЫКЛ**. Пока выключено: публичный лендинг
отдает 404, раздел в админке скрыт, атрибуция и начисления не работают.

## Как запустить

1. `PARTNER_PROGRAM_ENABLED=true` в `.env` (+ при необходимости
   `PARTNER_REWARD_AMOUNT=1000`, `PARTNER_BOT_SECRET=<секрет для бота>`).
2. `php artisan migrate` (3 таблицы: `partners`, `partner_conversions`,
   `users.partner_id`).
3. Проверить публичный лендинг `/partners`, принять первую заявку и
   **активировать** партнера в админке (раздел «Продажи → Партнеры»).

## Как это работает

- **Атрибуция (last-touch):** партнер делится **чистой** ссылкой `/mitram/<КОД>`
  (без «?», удобно шарить) — она кладет код в сессию и уводит на главную.
  Легаси-форма `/?pref=<КОД>` тоже работает.
  [`CapturePartnerReferral`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Middleware/CapturePartnerReferral.php)
  кладет код в сессию и, как только клиент авторизуется, привязывает его
  (`users.partner_id`) — только для **активного** партнера, без перезаписи
  существующей привязки, без самопривязки.
- **Начисление:** при первой реальной оплате курса приведенным клиентом
  [`PaymentObserver`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Observers/PaymentObserver.php)
  зовет [`PartnerService::rewardForPayment`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/PartnerService.php);
  создается строка `partner_conversions` (статус `accrued` — «к выплате»),
  ровно один раз на клиента (unique `user_id`). Гейт «первой реальной оплаты
  курса» тот же, что и в студенческой программе (не deposit/trial/Расход/
  salary_payout/conditional/0 ₽/без курса).
- **Реверс:** при откате платежа (paid → failed/canceled) еще **не выплаченное**
  (`accrued`) вознаграждение снимается и слот освобождается. Уже выплаченное
  (`paid_out`) автоматически не откатывается — разбирается вручную.
- **Выплата:** администратор в админке (вкладка «Клиенты и выплаты» партнера)
  отмечает `accrued → paid_out`. «К выплате» = сумма `accrued`.

## Регистрация: бот → веб

Точка входа — Telegram-бот (`?start=agent`), он ведет человека на веб-лендинг
`/partners`, где показаны все условия/цифры и форма заявки. Бот — **отдельный
сервис**; в этот репозиторий он ходит по API (общий секрет
`X-Partner-Bot-Secret`, middleware
[`verify.partner.bot`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Http/Middleware/VerifyPartnerBotWebhook.php)):

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `POST` | `/api/partner-bot/register` | Завести/поднять партнера по Telegram (идемпотентно), вернуть код + `web_url` |
| `POST` | `/api/partner-bot/stats` | Статистика партнера (клиенты, к выплате, выплачено) по `code` или `telegram_username` |

Веб-регистрация (`POST /partners/register`) и это API создают одну и ту же
сущность `Partner`. Обе создают партнера в статусе `pending` — активирует человек
в админке.
