# Как впустить ученика в кабинет без пароля и «даже если ничего не помнит»

_Created: 02-08-2026 · Last updated: 21-08-2026_

> Живой гид куратора (этот сценарий внутри, с кадрами): 
> [https://samskrte.ru/admin/curator-guide](https://samskrte.ru/admin/curator-guide).
> Ниже — тот же runbook отдельным файлом.

> **Права:** magic link выдаёт **куратор** и **администратор**.
> Преподаватель и бухгалтер кнопку не видят.

Короткий runbook для поддержки. Ученик **не обязан** помнить пароль и часто
**не обязан** сам помнить email: главное — **найти его карточку** в админке и
выдать **одноразовую ссылку входа** (magic link). Ссылку передаёте в Telegram
(или иначе напрямую) — **минуя почту**, если письма не доходят.

Техническая основа (H849):  
[student-unblock-access-feed.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/student-unblock-access-feed.md) ·

Черновики для **учеников** (что им писать в чат):

## 1. Что это такое (одной фразой)

**Magic link** = ссылка вида `https://samskrte.ru/login-link/…`, по которой
ученик **сразу входит** в кабинет (`/dvaram`), **без ввода пароля**.  
Ссылка: **одноразовая**, живёт **24 часа**, в БД хранится только hash.  
После клика — «С возвращением…» и совет задать пароль в профиле.

Это **не** «войти как» (impersonation для супер-админа) и **не**
newsletter-magic (`/magic/…` подписки). Только токены назначения
`admin_unblock`.

---

## 2. Кто может выдать ссылку

| Роль | Может? |
|---|---|
| **manager** (куратор) | **Да** — кнопка в «Студенты», лента «Проблемы со входом», Telegram `/unblock` |
| **admin / super_admin** | Да — то же |
| Преподаватель / бухгалтер | Нет (бухгалтер видит список студентов, но не кнопку ссылки) |

Куратор **сам** находит карточку и выдаёт magic link — ждать админа не нужно.
Передать ссылку ученику — **лично** в Telegram, не в общий чат курса.

## 3. Сценарии ученика → что делать

### А. Помнит email, не помнит пароль (сам)

1. https://samskrte.ru/forgot-password  
2. «Проверить email и войти» → письмо → задать пароль.  
3. Спам. Если письма нет — **сценарий Б** (magic link в руки).

Куратору/админу в этом случае часто **не** нужно ничего: self-service.

### Б. Помнит email, почта «мертвая» / не приходит письмо

1. Админ находит студента (**Пользователи** → поиск по email).  
2. Кнопка **«Разблокировать (ссылка для входа)»** (иконка замка) → подтвердить.  
3. В **зелёном persistent-уведомлении** — ссылка на 24 ч.  
4. **Скопировать и отправить** ученику в Telegram (не полагаться на SMTP).  
5. Ученик открывает ссылку → в кабинете → по желанию задаёт пароль.

Опция «Также сбросить пароль» обычно **не нужна** — ссылка входит без пароля.
Включайте, если хотите ещё и временный пароль в том же уведомлении.

### В. Не помнит email, помнит ФИО / Telegram / курс / телефон

**Сначала найти карточку** — без карточки ссылку выдать нельзя.

Где искать в **Пользователи** (`/admin/users`):

- ФИО (и варианты написания),
- `telegram_username` / telegram id,
- телефон / город в имени,
- примечание куратора,
- курс: открыть курс → состав / платежи → студент,
- старые оплаты: **Финансы** / платежи по ФИО.

Короткая ссылка на карточку: `/u/{id}` (удобно в заметках).

Когда карточка найдена → **как в Б**: «Разблокировать» → ссылку в TG.

**Скажите ученику его email** (с карточки), чтобы дальше он мог
self-service: forgot-password и «Запомнить меня». Email в кабинете сам
ученик **не** меняет — только админ/куратор с правами на карточку.

### Г. «Ничего не помнит» (ни почты, ни пароля, ни логина)

Тот же **В**: опознать человека по **человеческим** признакам.

Минимум, что попросить у ученика в чате:

```
Как вас зовут (ФИО)?
Какой курс / группа / преподаватель?
Когда примерно платили (месяц/год)?
Есть ли чек / скрин перевода?
Какой Telegram / телефон указывали при записи?
```

Без совпадения с карточкой **нельзя** честно выдать magic link «вслепую» —
иначе риск входа не в тот кабинет. Если карточки нет (никогда не импортировали /
оплата только в чат) — сначала **создать/найти доступ** (импорт, ручная выдача
группы, платёж), потом ссылку.

### Д. Попал в «Проблемы со входом»

**Пользователи → Проблемы со входом** (`AccessAttemptResource`):

- неверный пароль, «email не найден», throttle сброса;
- фильтр «только неразобранные»;
- **Разблокировать** из строки (если есть `user_id`).

Проактивно: админам в Telegram может прийти алерт с кнопкой
**«Выслать ссылку для входа»** (нужен `ADMIN_TELEGRAM_ID` + бот).

### Е. Из Telegram, не заходя в Filament

Куратор или admin, привязанный к боту (роль manager/admin):

```
/unblock student@mail.ru
```

Ответ бота — одноразовая ссылка → переслать ученику.

## 4. Пошагово в админке (happy path)

1. Войти в `/admin` ролью **manager** (куратор), **admin** или **super_admin**.  
2. **Пользователи → Студенты** → найти студента.  
3. В строке таблицы: иконка **замка** → tooltip «Разблокировать (ссылка для входа)».  
4. Модалка: «Также сбросить пароль» — обычно **выкл**.  
5. **Разблокировать**.  
6. Уведомление «Готово — скопируйте…» → скопировать URL.  
7. Отправить ученику: «Откройте ссылку в браузере (действует ~24 ч, один раз)».  
8. Ученик → `/dvaram`. Попросить: **сменить пароль** в кабинете + при желании
   «Запомнить меня» на своём телефоне.

Параллельно сервис **снимает IP-троттл** с недавних попыток входа (если били
throttle) — это бонус; главная ценность — **ссылка в руки**.

---

## 5. Что происходит по клику ученика

1. `GET /login-link/{token}` (`AdminLoginLinkController`).  
2. Токен `purpose=admin_unblock`, не протух, не использован → `consume()`.  
3. `Auth::login($user, remember: true)`.  
4. Редирект на `/dvaram` + flash: задать пароль в профиле.  
5. Повторный клик по той же ссылке → **404** (так и задумано).

Если 404: выдать **новую** ссылку (старая сгорела или >24 ч).

---

## 6. Чего **не** путать

| Инструмент | Зачем | Кому |
|---|---|---|
| **Разблокировать / magic link** | Впустить **самого ученика** в **его** кабинет | куратор (manager) + admin |
| **Сбросить и выслать пароль** (ключ) | Новый пароль **на email** (нужна живая почта) | admin |
| **Forgot-password** на сайте | Self-service, если email известен | ученик |
| **Войти как** (impersonation) | Админ смотрит кабинет глазами ученика; **не** даёт ученику вход | super_admin, флаг `STAFF_IMPERSONATION` |
| Newsletter `/magic/…` | Подписка / полка магнитов, не «разблокировка» | другой purpose |

## 7. Шаблон сообщения ученику

**В библиотеке шаблонов (админка):**  
`Поддержка · E2 — magic-link вход (не знает пароль)`  
(сидер [MessageTemplateSeeder](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/database/seeders/MessageTemplateSeeder.php), H2339).

Перед отправкой: «Разблокировать» → скопировать URL → вставить вместо
`{login_link}` (авто-подстановки нет — ссылка одноразовая). `{email}` и
`{name}` подставляются из карточки.

Self-service, если email известен (без magic-link):  
`Поддержка · E1 — вход по email (forgot-password)`.

Копия тела E2 (если шаблона ещё нет на prod):

```
Намасте, {name}!

Мы нашли ваш кабинет. Откройте эту ссылку в браузере (один раз, действует около суток):

{login_link}

Вы попадёте в личный кабинет без пароля. Там в настройках задайте свой пароль
и при желании отметьте «Запомнить меня» на своём телефоне.

Ваш email в системе (для следующего входа): {email}

Кабинет: https://samskrte.ru/dvaram
```

Если email placeholder (`@no-email.com`) — **не** обещать вход по почте; только
magic link, пока админ не проставит нормальный email в карточке.
Ревизия всех support-канреплаев: [SUPPORT_CANREPLY_TEMPLATES_REVISION_2026-08.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/copy/SUPPORT_CANREPLY_TEMPLATES_REVISION_2026-08.md).

## 8. Безопасность (коротко)

- Выдача ссылки = возможность войти в кабинет → **куратор (manager)** и **admin**.  
- Не публиковать ссылку в **общем** чате курса — только **лично** ученику.  
- Не просить ученика «придумать» чужой email для новой регистрации — дубль
  кабинета **без** старых курсов.  
- После входа — свой пароль; старый magic link уже мёртв.

---

## 9. Если «не нашли» в базе

1. Другой email / транслит ФИО / девичья фамилия.  
2. Платёж / импорт не попал — см. оплаты, `import:academy`, ручная выдача
   группы.  
3. Оплата «до кабинета» **в счёт**, но только если запись есть; иначе
   восстановление по чеку вручную, **потом** magic link.
