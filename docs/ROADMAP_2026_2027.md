## Зафиксированные решения (02-07-2026)

- **Порядок приоритетов года:** (1) production operability → (2) money/finance
  hardening → (3) support/AI automation → (4) student-facing growth.
- **AI-приватность (`@DECIDE` снят):** разрешено отправлять support-контент в
  OpenRouter **включая импортированные приватные Telegram-ЛС** — в проде можно
  включать оба флага `features.support_ai_assist` **и**
  `features.support_ai_include_telegram`. В коде дефолты остаются ВЫКЛ
  (env-gated); включение — шаг активации прода.
- **Активация прода:** человеческие шаги (миграции, интерактивный TG-логин,
  Zoom-креды) MG делает в течение ~2 недель от 02-07-2026 → Волна 1 реалистична
  как июльский фокус.

Дополнено вторым интервью 02-07-2026 (Fable 5, `claude-fable-5`):

- **Деплой — скриптованный, на сервере:** один идемпотентный `deploy.sh`
  (pull → composer → vite build → сброс кэшей → migrate → рестарт Horizon →
  smoke-check), запускается вручную по SSH; полноценный CD через GitHub Actions
  не строим. Закрывает класс багов
  [#193](https://github.com/gasyoun/Systema-Sanscriticum/issues/193)
  («страница отдаёт старую разметку»). См.
  [`docs/deploy.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/deploy.md).
- **Laravel 10 → 11 вытянут в Волну 2** (был дефолтом в Волне 4): PHP 8.1 без
  security-патчей с декабря 2025, Laravel 10 — с февраля 2025; год на EOL-стеке
  для платёжного приложения — неприемлемый риск. Делается сразу после PHP 8.3
  (8.3 — пререквизит Laravel 11).
- **Словарь кабинета ↔ Кёльнская линейка:** одобрено как пункт роадмапа —
  подключить студенческий словарь к CDSL-данным (MW/PWG/Apte через
  Kosh/Salt API в `csl-apidev` или bulk-импорт), поверх — кураторский слой
  курсовой лексики. Уникальное преимущество: ни одна Sanskrit-LMS такого
  не имеет. Волна 4.
- **Продажа записей завершённых курсов**
  ([#190](https://github.com/gasyoun/Systema-Sanscriticum/issues/190)):
  включено в Волну 2 — ложится на существующую тарифную модель
  (`full`/`block_N`), монетизирует уже произведённый контент.

Ниже — дефолты, принятые без ответа (переспросить при случае):

- **Jivo:** решение об отказе — по данным в Q1 2027 (сравнить нагрузку кураторов
  и время ответа native inbox vs Jivo после Волны 3).
- **Прана:** ship & observe — опубликовать построенное, наблюдать данные,
  без новых механик в этом году; decay остаётся ВЫКЛ.
- **Наблюдаемость:** error-tracking (Sentry или self-hosted аналог) и
  регулярная проверка восстановимости Spatie-бэкапов — добавлены в Волну 2
  как дефолт; переспросить, если Sentry-подписка нежелательна.

## Волна 1 — Активация прода (июль 2026)

Всё уже построено — задача довести до боевой работы.

- [ ] `php artisan migrate` на проде: `support_conversations`,
  `chat_messages.ai_state`, FK `support_conversation_id`, прана-таблицы,
  `vk_auth_token`, zoom-поля + `webinar_attendances`, `referral_credit`.
- [ ] Telegram support → прод: `TELEGRAM_SUPPORT_ENABLED=true`,
  `TELEGRAM_SUPPORT_API_ID/API_HASH/SESSION`, первый **интерактивный**
  `php artisan telegram-support:sync` (QR/2FA — делает MG), проверка
  `/admin/telegram-support-analytics` на реальных чатах; донастроить
  `support_responder_mappings`; `telegram:backfill-usernames-from-notes --apply`.
- [ ] Identity backfill: `identity:backfill-social-accounts` на полной прод-БД
  (сухой прогон → ревью конфликтов MG → `--apply`). Локальный сухой прогон уже
  чист (13 кандидатов, 0 конфликтов). См.
  [`docs/support-identity.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/support-identity.md).
- [ ] Zoom: S2S OAuth app (`ZOOM_*`) + Event Subscription на
  `/api/webhooks/zoom` (`recording.completed`, `participant_joined/left`).
- [ ] Horizon-воркер на очереди `lectures` (редактор лекций v2).
- [ ] Прана: публикация партиалов + перки (`PranaPerkResource`), decay ВЫКЛ.
- [ ] **PHP 8.1 → 8.3** по чек-листу
  [`docs/php-8.3-upgrade.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/php-8.3-upgrade.md)
  (коммиты `843a1ca`/`86aebd2`).
- [ ] **Скриптованный деплой:** завести
  [`deploy.sh`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/deploy.sh)
  на сервере, все последующие выкладки — только через него; закрыть
  [#193](https://github.com/gasyoun/Systema-Sanscriticum/issues/193) первым же
  прогоном. Ритуал описан в
  [`docs/deploy.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/deploy.md).

**Критерий выхода:** TG-аналитика живёт на реальных данных cron-safe;
вебинарный цикл Zoom работает end-to-end; прод на PHP 8.3; выкладка —
одна команда, «старая разметка после деплоя» невозможна по построению.

## Волна 2 — Денежный контур и hardening (сентябрь–октябрь 2026)

Агентно-выполнимо, прод не требуется — начинается раньше при простое Волны 1.

- [ ] Тесты выплат преподавателям: late-payment picker, закрытые периоды,
  авансы, PayPal rate date, зеркальные `salary_payout`-транзакции,
  экспорт/письма.
- [ ] Добить покрытие доступа: `Tariff::upgradeCreditForUser` (containment),
  loyalty/deposit в `calculateFinalPriceForUser`, грани `block_N_hH` в
  `unlockingKeys`/`isUnlockedBy` — ни одного непокрытого ветвления.
- [ ] Security-проход по вебхукам (Tochka/Telegram/VK/MAX/Zoom): единый паттерн
  подписи + fail-policy, ротация `max_webhook_secret`; `/security-review` по
  накопленному diff.
- [ ] Долговой свип: мёртвый `prana.rewards.referral`, инлайн-литералы к канону
  (`Payment::PAID_STATUSES`/`scopePaid()`), Pint clean по всему дереву.
- [ ] **Laravel 10 → 11** (вытянуто из Волны 4, решение 02-07-2026): сразу после
  стабильного PHP 8.3 в проде. Ловушка: в Laravel 11 начинает работать метод
  `casts()` — проверить, что везде остаётся `protected $casts` без конфликтов;
  Filament v3 остаётся, v4 не трогаем в этой волне.
- [ ] **Продажа записей завершённых курсов**
  ([#190](https://github.com/gasyoun/Systema-Sanscriticum/issues/190)):
  лендинги завершённых курсов продают запись (целиком/поблочно) вместо
  «Записаться» — новый тип тарифа поверх существующих ключей
  `full`/`block_N`, доступ через тот же `PaymentObserver::grantAccess()`.
- [ ] **Наблюдаемость:** error-tracking в проде (Sentry/аналог) + прогон
  восстановления из Spatie-бэкапа на чистой БД (backup, который никогда
  не восстанавливали, — не backup).
- [ ] **Управленческий финансовый контур** (аудит vs «Нескучные финансы»,
  03-07-2026): ОПиУ по начислению на блоках → дебиторка-контур → ДДС/платёжный
  календарь → unit-экономика → баланс → финмодель (порядок фаз 1→2→3→4→6→5).
  Опирается на существующую блочную схему (`CourseBlock.starts_at/ends_at` =
  готовое признание выручки); главный закрываемый риск — невидимая рассрочечная
  дебиторка от поблочной продажи. Полный проект и маппинг сущностей —
  [`docs/FINANCE_MANAGEMENT_CONTOUR.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/FINANCE_MANAGEMENT_CONTOUR.md).
  Постоянные расходы импортируются из Yandex Forms (переиспользовать импортёр
  «Импорт оплат»).

**Критерий выхода:** денежные/доступные пути покрыты; секреты ротируемы;
security-review без открытых находок; прод на поддерживаемом Laravel 11;
записи завершённых курсов продаются.
