## Назначение и аудитория

Манифест школы samskrte.ru: 40 максим о том, как учить санскрит и как быть
санскритологом, по жанровому образцу «Жизненных правил для музыкантов»
Роберта Шумана (1848). Адресат — все слои сразу, как у Шумана: от студента
марафона до автора статей; разные правила читаются на разной глубине.

  [H1215](https://github.com/gasyoun/Uprava/blob/main/handoffs/H1215-Fable_Systema-Sanscriticum_lebensregeln-sanskritologov_18.07.26.md).

## Решения интервью (18-07-2026, MG)

| Параметр | Решение |
|---|---|
| Адресат | Все слои, как у Шумана — от новичка до автора статей |
| Голос | RWS-регистры zalizniak-method + zalizniak-shkolnikov; «ты»-императив; имена-канон (Панини, Бетлингк, Уитни, Кильхорн, Моньер-Вильямс, Кочергина, Зализняк) |
| Оси | Ухо vs. глаз (два канала, каждому свое — без идеологии) · ежедневное ремесло · инструменты и тексты · метод и доказательность · этос и сообщество |
| Объем и форма | Сколько выйдет честных (вышло 40); шумановский сплошной поток без рубрик |
| Санскрит в тексте | Почти без примеров — правила держатся на мысли, не на материале |
| Название | «Жизненные правила для санскритологов» |
| Дом | Systema / samskrte.ru (Tier 0); v1 сейчас, ревизия по стенограммам потом |
| Источники ревизии | Выступления Гасунса + записи курсов/марафона + интервью санскритологов (лекции Зализняка НЕ источник содержания — только голос через RWS) |

- Жанр: Robert Schumann, «Musikalische Haus- und Lebensregeln» (1848), ~68 максим;
  русские издания дают выборку (у MG — 38).
- Голос: [zalizniak-method.yml](https://github.com/gasyoun/RuWritingStyles/blob/main/styles/passports/zalizniak-method.yml)
