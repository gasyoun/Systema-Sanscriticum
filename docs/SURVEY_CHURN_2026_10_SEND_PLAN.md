# План рассылки анкеты churn-2026-10 (H5824, C4)

_Created: 04-10-2026 · Handoff: [H5824](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5824-OxAlpha_Systema-Sanscriticum_samskrte-student-survey_03.10.26.md) · Рулинг MG 03-10-2026 (batch-3 chat vote, sheet 0LV, пункт C4)._

## 1. Сет вопросов (что спрашиваем и зачем)

Анкета определена в `config/surveys.php` → `churn-2026-10`. Одна страница, 8 вопросов, 2–3 минуты. Обязательных два.

**Причины оттока (churn reasons):**

| # | id | Тип | Что покрывает |
| --- | --- | --- | --- |
| 1 | `stopped_main_reason` | radio, required | главная причина остановки (время / сложность / темп-расписание / бюджет / кабинет-записи / приоритеты / другой учитель / другое) |
| 2 | `stopped_more` | checkboxes | вторичные помехи: Zoom, обратная связь по ДЗ, поиск записей, поддержка куратора, качество записи, обстоятельства |
| 3 | `what_would_return` | radio, required | что вернуло бы: льготная цена, рассрочка, записи, медленный темп |
| 4 | `return_condition` | textarea | открытая формулировка условий возврата |

**Спрос на фичи (feature demand):**

| # | id | Тип | Что покрывает |
| --- | --- | --- | --- |
| 5 | `wanted_features` | checkboxes | архив-подписка, мини-курсы, разговорный клуб, разборы текстов, тренажёр, мобильное приложение |
| 6 | `subscription_interest` | scale 1–10 | готовность к подписке (сопоставимо с post3m/p2-format) |
| 7 | `next_wish` | radio | следующий курс/формат при возврате |
| 8 | `comment` | textarea | свободный комментарий |

Отличие от существующих волн: `churn-block` спрашивает только про остановку в середине курса, без спроса на фичи; `post3m`/`p2-format` — про спрос, но берут *текущих* учеников. `churn-2026-10` — единственная волна, где обе оси спрашиваются у **ушедших**.

## 2. Канал доставки (выбор и почему)

Выбрано: **личные приглашения куратора** по CSV из `survey:audience churn-2026-10`, с опциональным дублем через кабинетного бота тем, у кого есть `telegram_id`.

Обоснование:

- Контур опросов живёт по [ACQUISITION_SURVEY_INSTRUMENTS_2026H2](https://github.com/gasyoun/Uprava/blob/main/custdev/ACQUISITION_SURVEY_INSTRUMENTS_2026H2.md): чувствительные темы (деньги, уход) — **лично каждому**, не массовой рассылкой; один контакт — потом тишина; в тексте — явное обещание тишины. Отток — самая чувствительная из тем.
- Прецедент: волна `churn-block` была именно «куратор получает готовый CSV» (`SurveyAudienceCommand`, рулинг MG 25-08-2026).
- Машинные каналы остаются запасными, уже написаны и slug-параметричны:
  - `php artisan surveys:send-student-invites --slug=churn-2026-10 --send --limit=N` — кабинетный бот, но его аудитория = *текущие* ученики (не ушедшие) — для этой волны пригоден только для доводочной волны;
  - `php artisan surveys:send-student-email-invites --slug=churn-2026-10` — email-волна для недостижимых в Telegram (паттерн H4431).

Дедупликация между каналами уже гарантирована `UNIQUE(survey_slug, user_id)` в `survey_invitations`.

## 3. Черновик текста приглашения (для одобрения MG)

> **Telegram / email — личное сообщение от куратора:**
>
> Здравствуйте, {имя}! Это Настя из школы ОРС. Вы занимались у нас санскритом и потом остановились — и нам правда важно понять, что именно не сработало: так мы чиним курсы и для вас, если захотите вернуться, и для тех, кто придёт после.
>
> Анкета на 2–3 минуты, без упрёков, ответы видит только команда школы: {URL}/anketa/churn-2026-10
>
> Это единственное сообщение по этой теме — больше мы не напоминим. Если тема закрыта — просто пропустите, всё в порядке.

Ссылка ведёт на нативную страницу `/anketa/churn-2026-10` (движок анкет samskrte.ru, рулинг MG 24-08-2026 «вариант Б»).

## 4. Порядок запуска (после одобрения MG — только тогда)

```sh
# 1. Аудитория ушедших (CSV для куратора)
php artisan survey:audience churn-2026-10

# 2. Пилот на 3–5 внутренних (выборочно из CSV, лично)
#    (шаг руками куратора/MG — машина ничего не отправляет)

# 3. (опционально) машинный дубль по Telegram тем ушедшим, у кого telegram_id
php artisan surveys:send-student-invites --slug=churn-2026-10          # сухой прогон
php artisan surveys:send-student-invites --slug=churn-2026-10 --send --limit=100

# 4. Табуляция после ответов
php artisan survey:tabulate churn-2026-10 --json
# → storage/app/survey-tabulation/churn-2026-10-{дата}/report.md + free_text.csv (+ tabulation.json)
```

Плоская выгрузка для куратора в кабинете тоже работает: страница экспорта анкеты (`survey.export`) автоматически подхватывает новую волну.

## 5. Критерии успеха / провала

- **Пилот:** 3–5 внутренних респондентов проходят анкету целиком, вопросов не больше 8, время ≤ 3 мин.
- **Провал =** вопросы не покрывают причины оттока (например, нет варианта «бюджет» или открытого вопроса про возврат) → переработка сета, НЕ отправка.

## 6. Ограничения

- Отправка машине не делегирована: шаг 2 и «--send» требуют явного одобрения MG (этого требует и рулинг волны, и контур опросов).
- Аудитория `churn-2026-10` = та же выборка, что `churn-block` (оплатил блок N, не пришёл за N+1). Если MG захочет включить и «оплатил один блок и всё», выборка расширяется правкой `SurveyAudienceCommand::churnBlock()`.
