## Зачем этот план существует

Три мануала (студент / куратор / бухгалтер) никто не читал: они лежат в публичном GitHub, без кадров, и студенческий файл написан для команды. План переносит их в продукт по уже доказанной схеме гида преподавателя и закрывает H3084 (указания сотруднику — в кабинете).

## Кому адресован

Исполнителю H3212 в первую очередь. Человеку — как таблица решений: зачем Playwright, а не Dusk; почему PNG бухгалтера не в git; почему `student-manual.md` не удалили.
