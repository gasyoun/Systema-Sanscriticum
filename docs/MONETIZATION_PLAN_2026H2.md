## 1. Приоритетная лестница

1. **Новые плательщики.** Узкое место бизнеса — не удержание: повторные платежи дают почти всю
   выручку, а первых плательщиков за три года мало ([CUSTDEV §3.1](https://github.com/gasyoun/Uprava/blob/main/custdev/CUSTDEV_2026.md)).
   Оружие — диагностический марафон 28-08 и его тёплый хвост.
2. **Платные члены.** Клуб `/klub` запущен 16-08 ([статус запуска](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/STATUS_CLUB_LAUNCH_FREE_TIER_ACTIVATION_16-17_08_2026.md)),
   живых чекаутов пока ноль; перевести запуск в реальную рекуррентную выручку и измеренные продления.
3. **Маржа.** Дисциплина модели: юнит-слой, затем кэпы (§7). Идёт третьей по вниманию,
   не блокирует первые две ступени.

## 2. Ядро воронки

Марафон (28-08, вход ₽500 «Консультация») → тёплый хвост Дни 4–16 с A/B апселла (§3) →
клуб Free / Basic ₽1 000 / Club ₽2 000 ([контракт тиров](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/MEMBERSHIP_THREE_TIER_RECORDING_GATE_2026.md)) →
evergreen-курс из записей с проверкой куратора (идея #1, [#190](https://github.com/gasyoun/Systema-Sanscriticum/issues/190)) → живой поток.
Free-уровень — нижняя ступень знакомства (§4).

Guardrail всей лестницы — анти-срочностное правило в продающем контуре: скидка +9, рассрочка +8,
записи в своём темпе +5 поднимают конверсию; срочность −7, навал отзывов −6
([диагностика марафона §3](https://github.com/gasyoun/Uprava/blob/main/custdev/MARATHON_DIAGNOSTIC_2026.md)).
Внутри учебного контура даты с целью (аттестация) остаются обязательными.

## 3. A/B апселла — последовательные волны

В тёплом хвосте (Дни 4–16) два оффера идут **волнами**, не сплитом:

| Волна | Оффер | Окно |
|---|---|---|
| 1 | Флагманский: купон ₽1 000 на любой первый курс (дизайн от 09-07) | первые запуски марафона |
| 2 | Членский: Basic/Club как дешёвый вход под свой темп (когорта 25–34) | следующие запуски |

- **Главная метрика (объявлена заранее):** доля купивших трипваер, совершивших покупку
  оффер-ветки в течение 13-дневного окна.
- Вторичные: выручка на участника волны; доходимость до Дня 3.
- Честное ограничение: последовательные волны слабее случайного сплита (примесь календаря);
  волны держать короткими, вывод трактовать как направление, а не чистый эффект.
- Guardrail: анти-срочность действует на обеих волнах одинаково.

## 4. Выход бесплатного уровня

149 грантов истекают 15-09. Правило MG 22-08: **активный = любой просмотр урока за последние
21 день** — грант продлевается до **15-10**; остальные истекают по расписанию, без офферов.
Данные `LessonView` дают первую реальную конверсию free → Basic. Это measurement-ход,
а не выжимание продаж.

## 5. Клуб: живой чекаут и чекпоинт цен

1. Первое настоящее дело — **живой чекаут клубного тарифа**: контур «оплата → членство →
   группа → каталог» подтверждён пока только репетицией внутри `withoutEvents()`
   ([статус 16-17-08 §2](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/STATUS_CLUB_LAUNCH_FREE_TIER_ACTIVATION_16-17_08_2026.md)).
2. **Чекпоинт цен:** после первых данных о покупках и продлениях пересмотреть лестницу
   (базис анализа — [H240](https://github.com/gasyoun/Uprava/blob/main/handoffs/archive/H240-Fable_Systema-Sanscriticum_membership_pricing_sizing_analysis_06.07.26.md)).
   Триггер — накопление первой когорты покупок/продлений; дата не фиксируется.
3. Top-тир ₽5 000 — вне этого цикла; прежний гейт go/no-go на 01-10 отменён решением 22-08.

## 6. Автосписание — решение до декабрьского пика

Режим решения — **data-triggered**: сразу после первых наблюдаемых продлений месячного
членства, без календарной даты; жёсткий предел — решить **до декабрьского пика**
(сезон подарочных сертификатов). Входы для выбора провайдера:
[режимы рекуррентных платежей Точки](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/ARCHITECTURE_TOCHKA_RECURRING_BILLING_MODES_2026.md)
и [PayPal Subscriptions](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/ARCHITECTURE_PAYPAL_SUBSCRIPTIONS_2026.md).

## 7. Маржа: сначала юнит-слой, потом кэпы

Порядок подтверждён ([аудит бизнес-модели §5](https://github.com/gasyoun/Uprava/blob/main/SYSTEMA_BUSINESSMODEL_AUDIT_vs_noboring.md)):

1. **Юнит-слой** `lead_id` → доход (идея #5): агентно-выполнимо; разблокирует ROI-дашборд
   и цифру маржи юнита.
2. **Кэпы** (потолок стека скидок, пол эффективной цены, лимит доли рассрочки) —
   калибруются данными юнит-слоя; параметры — отдельный `@DECIDE` MG после слоя.
   До тех пор кэпы не вводятся.

## 8. VK-тест платного трафика

Малый платный тест **параллельно запуску марафона**: канал VK (лучший конвертирующий
соц-канал по CUSTDEV), бюджет ≈ **₽20–40 тыс. суммарно**, UTM-поля атрибуции заполняются
обязательно. Результат (CAC/ROI канала) питает юнит-слой §7. Связка лид→пользователь на входе
уже не рвётся ([email-only подписка через magic-link](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/newsletter-subscribe.md));
канал→оплата замыкается юнит-слоем.

## 9. Декабрьская игра — подарочные сертификаты

Идея #2: тариф «в подарок» + код активации поверх готового `CertificateService`
(DomPDF + публичная верификация). Пик спроса — декабрьские праздники; сборка — к началу
декабря. Диаспорный сценарий («оплатить курс/членство родственнику в России») работает
сам собой, без отдельного EN-продукта.

## 10. SEO / публичный словарь — верх воронки

Поиск — крупнейший внешний канал (~39 % визитов) без какого-либо SEO-продукта. Хребет —
Yandex-first плейбук ([SEO_STRUCTURED_DATA_PLAYBOOK](https://github.com/gasyoun/Uprava/blob/main/SEO_STRUCTURED_DATA_PLAYBOOK.md));
публичные страницы словаря (идея #6, клейка с CDSL — Волна 4 роадмапа) — долгий питатель
воронки членства.

## 11. Горизонт — январская когорта

Январский поток с деванагари-входом — отдельная сборка поверх движка марафона:
[H445 (Sonnet) — marathon devanagari January cohort build](https://github.com/gasyoun/Uprava/blob/main/handoffs/H445-Sonnet_Systema-Sanscriticum_marathon_deva_january_cohort_09.07.26.md).
В этом плане значится горизонтом, не строительством.
