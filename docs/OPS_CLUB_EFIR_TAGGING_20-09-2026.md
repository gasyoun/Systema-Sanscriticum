# Клуб: тегирование эфиров `club_efir` в Filament — до 30.09.2026

_Created: 20-09-2026 · Last updated: 20-09-2026_

Задача куратора. Время: ~10 мин на партию. Дедлайн: **до 30.09.2026** — первый эфир субхашита-клуба; подписчики должны видеть эфир к этой дате.

## Зачем

20-09-2026 на проде включён `MEMBERSHIP_CLUB_STREAMS_ONLY` (rehearsal PASS 13/13 — [отчёт разблокировки](https://github.com/gasyoun/Uprava/blob/main/reports/N03_CLUB_REHEARSAL_UNBLOCK_20-09-2026.md)). Доступ подписчиков Club/Top к записям теперь идёт по предикату «урок помечен как эфир клуба» (`Lesson::isClubStreamRecording()`, H3648). Урок без метки = **подписчик его не видит**. Сейчас помечено 0 из 1742 уроков.

## Что помечать

Записи живых клубных эфиров — уроки курса **«Клуб»** (в базе course #444). Обычные уроки покупных курсов не трогаем.

## Шаги (Filament)

1. Открыть `https://samskrte.ru/admin` → боковое меню **«Уроки»** (или напрямую `https://samskrte.ru/admin/lessons`).
2. Найти уроки клуба: фильтр/поиск по курсу «Клуб».
3. Открыть урок-эфир → поле **«Класс записи»** → выбрать **«Эфир клуба (синоним)»** (это значение `club_efir`) → **Сохранить**.
4. Повторить для каждого клубного эфира.

Примечание: вариант «Эфир клуба (членство Club/Top)» (`club_stream`) открывает доступ так же — в предикате это синонимы (`RecordingKind::isClubStream()` покрывает оба). Для новых тегов используется `club_efir` (решение H5184/N03, MG 20-09).

## Проверка после тегирования

На .92:

```sh
cd /var/www/html && php artisan tinker --execute='echo App\Models\Lesson::where("recording_kind","club_efir")->count();'
```

Число должно расти с каждым тегом. Контрольный тест доступа: у активного подписчика Club эфир появляется в кабинете.

## На будущее

Каждый новый клубный эфир получает «Класс записи» = `club_efir` при загрузке записи — тогда следующих «партий» не потребуется.
