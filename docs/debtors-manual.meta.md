Метадок-компаньон к [`docs/debtors-manual.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/debtors-manual.md) — держит контекст ВОКРУГ руководства (назначение, провенанс, бэклог улучшений, ограничения), не пересказывая его содержимое.

## Предмет

- **Документ:** [`docs/debtors-manual.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/debtors-manual.md)
- **Назначение:** пользовательское руководство менеджера по сервису «Должники» в Filament-админке — как читать список, оформлять договоренности/рассрочки, conditional access, разовые доступы и что делает автоматика под капотом.
- **Аудитория:** менеджеры и кураторы, работающие с оплатами и долгами студентов; вторично — разработчики, сверяющиеся с регламентом.
- **Формат/контракт:** длинное read-only руководство на русском, 16 разделов + FAQ. Источник правды для контента — Blade-шаблон `resources/views/pdf/debtors-manual.blade.php`; этот MD поддерживается параллельно для чтения на GitHub и вставки в Notion/Telegram. При изменении логики оба обновляются вместе.

## Известные ограничения / оговорки

- Дублирующийся источник контента (MD + Blade-шаблон) — риск рассинхронизации; синхронность держится только на дисциплине автора.
- Руководство описывает поведение UI и автоматики на момент написания; времена cron-задач, пороги (3+ просрочки, 6/12 мес., 10 000 ₽) и названия статусов зашиты в текст и устаревают при изменении конфига/кода.
- Часть цифр (веса дисциплины, пороги тиров) вынесена в `config/discipline.php` и помечена как требующая калибровки — руководство ссылается, но не воспроизводит их.
- Нет скриншотов: весь UI описан прозой.

## Назначение / известные злоупотребления

- **Использовать для:** обучения менеджеров, справки по ежедневной работе с долгами, сверки ожидаемого поведения сервиса.
- **НЕ использовать как:** спецификацию для реализации (источник истины — код и Blade-шаблон, не MD), финансовый регламент (conditional-платежи намеренно не считаются оплатой — это описано, но правовую/бухгалтерскую сторону документ не покрывает), или актуальный снимок cron-расписания без сверки с кодом.

## План поддержки и вывода из эксплуатации

- **Ревизия:** при любом изменении логики сервиса «Должники» обновлять MD и Blade-шаблон в одном проходе.
- **Владелец:** команда Systema-Sanscriticum (админка/платежи).
- **Sunset:** документ живёт, пока существует сервис «Должники» в Filament-админке. При замене платёжного модуля — переписать или архивировать вместе с ним.
