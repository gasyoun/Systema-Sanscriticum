(feature-тест `KocherginaMaterialBundlesTest`, HTTP 200 без auth), а не заявления
о готовых production-ссылках.

## Проверки

- `php artisan test --filter=KocherginaMaterialBundlesTest` — контракт наборов
  (разделы, порядок, признак готовности, версия+формат, blocked-без-ссылки),
  публичность маршрутов, 404 на неизвестный slug, различение сборников 54/100,
  отсутствие внутренних локаторов источников на страницах.
- Реальные команды и вывод — в PR и в Delivery-полях H8210.
- Мобильное чтение: страницы на max-w-3xl контейнере и Tailwind-брейкпоинтах
  (как публичные FAQ); функциональная проверка мобильного аудио невозможна до
  публикации аудио (пункт заблокирован явно).

## Deploy (известный рецепт, исполнение — человеческое действие)

Стандартный `deploy.sh` на прод (samskrte.ru); новых миграций, jobs и конфигов нет.
После deploy прогнать построчный smoke: четыре URL из таблицы «Страницы наборов»
должны отдавать 200 без входа; якоря разделов Конспекта — 200.
