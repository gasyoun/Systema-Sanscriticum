## Субъект

- **Документ:** [`docs/webhook-security.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/webhook-security.md)

- **Аудитория:** инженеры и оператор деплоя Systema-Sanscriticum, ревьюеры безопасности; тот, кто добавляет новый вебхук и должен выбрать fail-policy.

## Известные ограничения / оговорки

- Документ — **снимок на дату прохода**: при изменении middleware матрица может разойтись с кодом, автоматической сверки нет.
- Покрывает только *входящие* вебхуки; исходящие вызовы и их секреты вне охвата.
- «Гэпов не найдено» относится к посту́ре подписи/fail-policy, а не к полному аудиту безопасности приложения.

## Предполагаемое использование / известное злоупотребление

- **Использовать:** как чек-лист при добавлении/ревью вебхука и как справку оператору по деплой-секретам.
- **Не использовать:** как доказательство, что приложение в целом безопасно, или как актуальный список эндпоинтов без сверки с роутами — это специфичный по времени снимок.

## План поддержки и вывода из эксплуатации

- Обновлять в том же PR, что меняет любое вебхук-middleware или добавляет эндпоинт (новая строка матрицы + fail-policy).
- Пересматривать при каждом security-проходе (roadmap A.x).
- Вывод из эксплуатации — только если матрица будет заменена сгенерированным из кода реестром эндпоинтов.
