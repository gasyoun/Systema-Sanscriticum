# План: автооткрытие приёма домашних заданий после проведённого урока (Кочергина, занятия 1–5)

_Created: 27-07-2026 · Last updated: 27-07-2026_

Приём домашних заданий по первым пяти занятиям грамматики Кочергиной должен открываться
**сам**, на следующий день после того, как занятие проведено, с условием «все упражнения к
Занятию N» — без ручного тумблера в Filament. Сегодня открытие — это один булев флаг
`lessons.homework_enabled`, который преподаватель щёлкает руками; никакого открытия по
времени в системе нет вообще. Этот план закрывает ровно этот разрыв и ничего больше.

Один найденный тупик, зафиксированный чтобы его не искали снова: у таблицы `schedules`
**нет `lesson_id`**. Занятие расписания и урок связаны только соглашением по ключу
`(course_id, group_id, lesson_date)`. Поэтому «через N часов после занятия» не может
отсчитываться от `schedule.end` без новой связи — и решение D2 ниже отсчитывает от записи.

## Принятые решения

Все 16 рулингов интервью 27-07-2026. Исполняющий агент принимает их как данность и
не переспрашивает.

|---|---|---|
| D1 | Сигнал «урок проведён» — **загружена запись урока** | у студента гарантированно есть что пересмотреть до того, как его просят сдавать |
| D2 | Отсчёт — **от момента появления записи**, новая колонка `recording_attached_at` | точное время есть всегда; Schedule с уроком не связана (см. тупик выше) |

### D6 и D14 — правовая оговорка и что из неё следует технически

[README папки Кочергиной](https://github.com/gasyoun/SanskritGrammar/blob/main/KocherginaUchebnik_1998/README.md)
прямо фиксирует: текст 1998 года под охраной авторского права, публичный оверлей несёт
только верификационную метадату. Решение воспроизводить полный текст упражнений в кабинете
принято человеком 27-07-2026 после того, как это было названо; план его исполняет. Из него
следуют два **технических** ограничения, которые не являются повторным обсуждением решения:

1. **Текст никогда не коммитится в этот репозиторий.** Systema-Sanscriticum публичен.
   Источник читается из соседнего клона SanskritGrammar по пути из конфига; в git попадает
   только код извлечения. Ни сидера с текстом, ни фикстуры с текстом.
2. **Уроки `is_free` и `is_preview` видны гостю без оплаты.** Автозаполнение отказывается
   писать в них текст учебника, пишет отсылочную формулировку («Выполните все упражнения к
   Занятию N») и логирует отказ. Урок при этом всё равно открывается.

## Контракт автономии

Исполняющий агент работает 5–8 часов без человека. Правила на это время:

- **При неоднозначности** (D13) — применить помеченный в плане вариант по умолчанию,
  записать выбор в раздел «Журнал решений» файла реализации, продолжить. Не останавливаться.
- **Остановиться** только если: миграция не накатывается на чистой базе; падает
  существующий зарплатный или платёжный набор тестов; источник Кочергиной недоступен
  и при этом волна 1 требует текста.
- **Права на коммит** — по правилу handoff-scoped: коммит → PR → merge без переспрашивания,
  handoff H1764 уже существует. Ветка — своя, работа — в worktree, не в главном дереве.
- **Не трогать** (ограда): `app/Services/TeacherSalaryService.php` и весь зарплатный контур,
  `PaymentObserver` и платежи, `Payment::grantAccess()`, `LessonAccessGrant` и логику
  доступа к урокам, `course_teacher`, `group_reviewer`, `csl-orig`. Ни одного сидера
  «на живой базе». Изменения `HomeworkService` — только добавление, ни одной правки
  существующих методов приёма и вердикта.
- **Watcher.** В этом репозитории внешний процесс откатывает незакоммиченные изменения
  рабочего дерева. Любая запись файла — по протоколу `/watcher-safe-commit`: сочинять в
  scratchpad, приземлять и коммитить одним вызовом shell, проверять выживание против HEAD.
