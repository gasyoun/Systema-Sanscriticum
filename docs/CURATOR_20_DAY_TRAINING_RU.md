# Программа «20 дней кураторской панели» — для Насти (30 минут в день)

_Created: 07-09-2026 · Last updated: 07-09-2026_

**Решение MG (07-09-2026):** 20 дней × 30 минут, только кураторская панель, практика
на живых данных, каждый сдаёт под своим входом. Настя всегда остаётся куратором
(role=manager) — рулинг 07-09-2026, роль не меняется; оба теста открыты manager'у.

Этот документ не дублирует существующие книги. Руководство по панели —
[CURATOR_ADMIN_GUIDE_RU.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/CURATOR_ADMIN_GUIDE_RU.md)
(часть I сценарии, часть II справочник). Базовый вход в кабинет для учеников —
[5-дневный брифинг](https://github.com/gasyoun/Uprava/blob/main/docs/BRIEFING_CURATOR_CABINET_5_DAYS_25-08-2026.md).
Мануал «Как устроен Институт» и ролевые квизы к нему — отдельная работа (H4295), здесь не дублируется.

## Как пользоваться (для MG)

1. **Каждое утро** пересылайте Насте в Telegram блок «День N» (~2 мин). Блоки готовы как есть.
2. **Вечером** попросите ответить на два вопроса «Проверь себя»; сверка — в разделе «Ответы» внизу (Насте не пересылать).
3. Неверный ответ → короткий разбор по указанному разделу руководства, день не сдвигается.
4. **День 20 — зачёт в панели, два теста:** базовый «Проверка овладения кабинетом» (зачёт 8/10)
   и «Программа 20 дней — зачёт» (Обучение → Руководство → «Программа 20 дней — зачёт», зачёт **16/20**).
   Попытки пишутся в базу под каждым своим входом: у Насти и у вас — раздельный прогресс.
5. Практика — на живых данных, без ограничений: все действия в программе обратимы
   (выдача ссылок, примечания, Keep в календаре). Необратимых кнопок у роли manager нет — это защита данных.

## День 1 — Панель: вход и ориентация

```
🐳 День 1. Знакомство с панелью.

1. Откройте samskrte.ru/admin и войдите своей почтой.
2. Посмотрите меню слева: разделы «Обучение», «Пользователи», «Продажи».
3. На главной найдите карточку «Скоро срок оплаты (7 дней)» — это ваши должники с датой обещания.
4. Пункта «Зарплаты» у вас нет — так и задумано, это не поломка.
```

Практика: войдите, найдите виджет, откройте одного ученика из него.
Проверь себя: 1) Нет «Зарплат» — это поломка? 2) Что показывает «Скоро срок оплаты (7 дней)»?

## День 2 — Руководство всегда под рукой

```
🐳 День 2. Всё, как пользоваться панелью, — в одном месте.

1. Панель → «Обучение» → «Руководство».
2. Часть I — восемь частых сценариев с картинками.
3. Часть II — справочник по каждому пункту меню.
4. Ученику для справки давайте https://samskrte.ru/dvaram/help, не эту страницу.
```

Практика: откройте часть I и найдите сценарий «Впустить ученика без пароля».
Проверь себя: 1) Где в панели живёт руководство? 2) Какую ссылку даёте ученику, а какую — нет?

## День 3 — Чат с куратором: Входящие vs «Мои»

```
🐳 День 3. Все сообщения учеников сходятся в одну ленту.

1. Панель → «Чат с куратором» (кабинет, Telegram и VK — всё здесь).
2. Вкладка «Входящие» — диалоги, которые ещё никто не взял.
3. Вкладка «Мои» — только те, что взяли вы. Пустая «Мои» при живом входящем — норма.
4. Имя ученика открывает его карточку прямо из чата.
```

Практика: откройте «Входящие», выберите любой диалог, посмотрите карточку ученика из треда.
Проверь себя: 1) Где лежит диалог, который ещё никто не взял? 2) Пустая «Мои» — что проверить первым?

## День 4 — Чат: полный цикл треда

```
🐳 День 4. Диалог: взять, ответить, закрыть.

1. Взять диалог из «Входящих» — он появится в «Мои».
2. Ответить — ученик увидит ответ в том канале, откуда писал.
3. Когда вопрос закрыт — отметить тред решённым, он уйдёт в закрытые.
4. Письмо с незнакомого адреса: «Входящие письма» → прочитать → «Привязать пользователя».
```

Практика: возьмите один тред, ответьте и закройте его.
Проверь себя: 1) Что делаете с тредом, когда вопрос решён? 2) Куда попадает письмо от незнакомого адреса?

## День 5 — Magic-ссылка: впустить без пароля

```
🐳 День 5. Ученик не помнит пароль.

1. Сначала его собственные средства: samskrte.ru/forgot-password, «Проверить email и войти».
2. Не помогло — «Студенты» → карточка → иконка замка «Разблокировать (ссылка для входа)».
3. Ссылка живёт около 24 часов и сгорает после первого клика.
4. Отправляем ТОЛЬКО в личку Telegram этому ученику, не в чат группы и не в канал.
```

Практика: найдите у любого ученика кнопку замка и посмотрите модалку (ссылку не отправляйте).
Проверь себя: 1) Куда отправляется одноразовая ссылка? 2) «Зарегистрируйтесь заново» — можно ли предлагать?

## День 6 — Сгоревшая ссылка и «Проблемы со входом»

```
🐳 День 6. Частые ловушки входа.

1. Ученик нажал ссылку второй раз и видит «не найдено» — ссылка сгорела, выдаём новую.
2. «Лента неудачных входов» — раздел «Проблемы со входом»: неверный пароль, «email не найден», троттл.
3. В строке проблемы — та же кнопка замка: сразу выдать ссылку.
4. Из Telegram: /unblock student@mail.ru — бот вернёт ссылку, всё равно переслать лично.
```

Практика: откройте «Проблемы со входом», включите фильтр «только неразобранные».
Проверь себя: 1) Ссылка нажата повторно и «не найдено» — что делать? 2) Где видно всех, кто не смог войти?

## День 7 — Карточка ученика

```
🐳 День 7. Карточка — главное рабочее место.

1. «Студенты» → поиск: ФИО и варианты написания, Telegram, телефон, город.
2. Не нашлось — ищите по оплате через «Финансы» или по курсу.
3. Короткая ссылка на карточку: /u/{номер} — удобно писать в заметки.
4. На карточке: курсы, группы, обещания, оплаты, примечание куратора.
```

Практика: найдите двух учеников своего потока, одному добавьте примечание.
Проверь себя: 1) Какая короткая ссылка открывает карточку? 2) Ученика в «Студентах» нет — где искать дальше?

## День 8 — Домашние задания

```
🐳 День 8. Статусы домашних работ.

1. Карточка ученика → сводка ДЗ: сдано / на доработку / принято.
2. «На доработку» = преподаватель вернул работу; ученик правит и сдаёт снова на странице урока.
3. Статус «черновик» преподаватель не видит — ученик не нажал «Отправить на проверку».
4. Зачёт ставит только преподаватель; куратор работы за него не принимает.
```

Практика: откройте сводку ДЗ у одного ученика и проговорите вслух, что значит каждый статус.
Проверь себя: 1) «На доработку» — это зачёт? 2) «Сдавал, а у препода пусто» — что проверить первым?

## День 9 — Группы: мягкий выход

```
🐳 День 9. Ученик перестал ходить, но оплата осталась.

1. Карточка → вкладка «Группы (активный состав)» → статус «Активен» или «Вышел».
2. «Исключить (сохранить доступ)» — исчезает из списков и напоминаний, оплаченные уроки открыты.
3. Снятие программы/доступа — другой инструмент: он отзывает доступ. Не путать.
4. «Уроки пропали» = сняли доступ вместо мягкого выхода — вернуть может администратор по оплатам.
```

Практика: найдите ученика со статусом «Вышел» и проверьте, что оплаченные уроки у него открыты.
Проверь себя: 1) Что делает «Исключить (сохранить доступ)»? 2) Ученику сняли доступ по ошибке — кто вернёт?

## День 10 — Расписание: переносы

```
🐳 День 10. Занятие сдвинулось.

1. Разовый перенос: «Расписания» → строка занятия → ⋯ → «Перенести» → новое время. Длительность сохраняется.
2. Ученики видят новое время сразу; о переносе в чат группы пишет куратор — сама система не уведомляет.
3. «Отменить (+неделя цепочки)» → «Сдвинуть на неделю»: это занятие отменяется, все следующие уезжают на +7 дней.
4. Сдвинули случайно — тем же «Перенести» верните на место.
5. Постоянная смена дня/времени — генератор потока, флаг «Не трогать прошедшие занятия» оставляем включённым.
```

Практика: найдите ближайшее занятие своего потока и посмотрите кнопки ⋯ (ничего не нажимайте).
Проверь себя: 1) Что делает «+неделя цепочки»? 2) Кто сообщает группе о переносе?

## День 11 — Обещания оплаты

```
🐳 День 11. «Оплачу 10-го» — дата появляется только из карточки.

1. Сообщение в Telegram дату в кабинете НЕ создаёт.
2. Карточка ученика → вкладка обещаний → дата, сумма (пусто = весь долг), комментарий.
3. Ученик видит договорённость у себя во вкладке «Мои долги».
4. Когда деньги приходят сами — обещание закрывается, вручную подтверждать не нужно.
5. На главной — виджет «Скоро срок оплаты (7 дней)»: у кого срок подходит или прошёл.
```

Практика: проверьте виджет на главной и откройте обещания одного ученика.
Проверь себя: 1) Дата обещания появится сама из сообщения в чате? 2) Где ученик видит договорённость?

## День 12 — «Платил, а урок закрыт»

```
🐳 День 12. Первое действие — не новый счёт.

1. Карточка урока у ученика → блок «Почему закрыто?».
2. «Открыть оплаченные блоки» — часто ключи просто не пересобрались, и этого достаточно.
3. Деньги в базе сами не правим: расхождение — скриншот платежа + строка администратору.
4. Рассрочки, подтверждение задним числом, исключение из чата за долг — операции администратора.
```

Практика: найдите ученика с закрытым уроком и откройте блок «Почему закрыто?».
Проверь себя: 1) Первый шаг при «платил, а закрыто»? 2) Кто правит деньги в базе?

## День 13 — Посещаемость: подпись в Zoom

```
🐳 День 13. Отметки приезжают из Zoom по подписи окна.

1. Засчитывается «Имя Фамилия» как в кабинете — включая латиницу и уменьшительные.
2. НЕ засчитывается: одно слово («Анна»), устройство («iPhone»), почта, номер телефона.
3. Лечение: своё окно → «Переименовать» → имя и фамилия. Zoom запомнит.
4. Ученик «ходил, а отметок нет» → сначала спросить, как подписан; за прошедшие занятия подпись связывает администратор.
```

Практика: откройте отчёт посещаемости курса и найдите две неопознанные подписи.
Проверь себя: 1) Подпись «Анна» — засчитается? 2) Ученику с прошлыми пропусками что обещаете?

## День 14 — Заявки и доска

```
🐳 День 14. Лиды — заявки с лендингов и форм.

1. «Заявки (Лиды)» — список; «Заявки — доска» — те же заявки колонками.
2. Двигаем карточку, когда статус РЕАЛЬНО сменился, не «для красоты».
3. «Не создайте ученику второй кабинет, чтобы быстрее» — пустой кабинет без оплат.
4. Рядом: «Лист набора» (очередь в полные группы) и «Список ожидания» (голоса за будущие курсы).
```

Практика: откройте доску заявок и найдите заявку своего потока.
Проверь себя: 1) Когда двигать карточку на доске? 2) Ученик не попал в группу — куда попадает?

## День 15 — Служебные разделы

```
🐳 День 15. Три вспомогательных места.

1. «Каникулы преподавателей»: окно дат «С»/«По»; в окне — пометка на расписании и молчание бота напоминаний. Преподаватель может выставить окно сам — перед правкой спросить его.
2. «Ответчики» и «Темы»: кто и по каким правилам ловит обращения; без задачи не трогаем.
3. «Входящие письма»: письмо от знакомого ученика само попадёт в его диалог; незнакомое — «Привязать пользователя».
```

Практика: откройте «Каникулы преподавателей» и найдите, кто сейчас в окне.
Проверь себя: 1) Что происходит с занятиями в окне каникул? 2) Можно ли менять «Темы» по своей инициативе?

## День 16 — Календарь контента

```
🐳 День 16. План постов школы.

1. «Маркетинг» → «Календарь контента» — слоты с датами и статусами.
2. Типы: teacher_spotlight (спотлайт учителя), student_story (история ученика), evergreen, forward и другие — фильтр «Тип».
3. Keep — запланировать: проставляет время публикации (полдень слота по МСК).
4. Cancel работает, пока до публикации больше 24 часов.

```

Практика: откройте слот «Спотлайт учителя: Гасунс» и проверьте ссылку на его страницу samskrtam.ru.
Проверь себя: 1) Что делает кнопка Keep? 2) До какого момента работает Cancel?

## День 17 — Очередь сториз (Telegram)

```
🐳 День 17. Публикация в канал @rusamskrtam.

1. «Контент» → «Очередь сториз и постов» — черновики тех же постов, что в календаре.
2. Прочитать текст → проставить «Когда публиковать» → «Одобрить».
3. Часовой тик заберёт одобренный пост в срок и отметит опубликованным.
4. Черновик без «Одобрить» не уйдёт никогда — можно править спокойно.
```

Практика: возьмите черновик спотлайта Гасунса, поправьте текст, поставьте время через час и одобрите. Пост уйдёт в канал — это нормально.
Проверь себя: 1) Что нужно, чтобы пост ушёл в канал? 2) Как часто издатель забирает одобренные?

## День 18 — Согласие: красная линия

```
🐳 День 18. Истории учеников публикуются только с явным «да».

1. Слоты «История ученика» стоят с пометкой HOLD: текста нет, публиковать нельзя.
2. Галочка в анкете «можно ли связаться для уточнения» — это НЕ согласие на публикацию.
3. Таблица отзывов тоже НЕ доказательство согласия — там нет поля согласия.
4. Согласие: личный запрос ученику → явное «да» → строка в consent-реестре (кто, когда, где сказал, формулировка).
5. Только после этого: пишем историю, снимаем HOLD, ставим время, одобряем.
```

Практика: найдите слот «История ученика: Петрова Рада» и убедитесь, что он HOLD без текста.
Проверь себя: 1) Ответ «Да» в анкете — это согласие на публикацию? 2) Что записываем в реестр согласий?

## День 20 — Выпускной: зачёт в панели

```
🐳 День 20. Проверка пути.

1. Тест 1: «Обучение» → «Руководство» → «Проверка овладения кабинетом». Зачёт — 8 из 10.
2. Тест 2: «Обучение» → «Программа 20 дней — зачёт». Двадцать ситуаций, зачёт — 16 из 20.
3. Попытки пишутся в базу. Не сдала — повторяем дни с ошибками и сдаём снова.
4. Сквозной сценарий для уверенности: ученик заплатил → вход по ссылке → «платил, а закрыто» → что жмёте?
```

Сквозной сценарий: выдали ссылку → ученик вошёл → «урок закрыт» → «Почему закрыто?» → «Открыть оплаченные блоки» → не помогло: скрин платежа + строка администратору.

## Ответы (MG, Насте не пересылать)

1. Д1: 1) Нет — по роли. 2) Учеников с обещанной датой оплаты, которая подходит или прошла.
2. Д2: 1) Обучение → «Руководство» (samskrte.ru/admin/curator-guide). 2) Ученику — /dvaram/help; руководство — только сотрудникам.
3. Д3: 1) Во «Входящих». 2) Вкладку «Входящие» — диалог ещё не назначен.
4. Д4: 1) Отметить решённым → в закрытые. 2) «Входящие письма» → «Привязать пользователя».
