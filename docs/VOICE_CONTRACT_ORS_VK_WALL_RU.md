# Голосовой контракт стены ВК «Общество ревнителей санскрита» (ОРС)

_Created: 28-07-2026 · Last updated: 28-07-2026_

Редакционный контракт для русскоязычной NEW-копии стены [vk.com/rusamskrtam](https://vk.com/rusamskrtam)
(ОРС): регистр, зачины, эмодзи, CTA, хэштеги, длина. Каждое правило выведено из
измеренной вовлечённости самой стены, а не из вкусовых предпочтений. Потребители
контракта: четыре семейства шаблонов
[`ForwardDraftGenerator`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Content/ForwardDraftGenerator.php)
и их полиш-промпты `CuratorAi`, а также промо-фильтр
[`EvergreenScorer`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/app/Services/Content/EvergreenScorer.php)
(H1754; машинерия — H1567, Wave 4 роадмапа
[ROADMAP_SYSTEMA_VK_ORS_CONTENT_CALENDAR_2026H2.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/ROADMAP_SYSTEMA_VK_ORS_CONTENT_CALENDAR_2026H2.md)).

## 1. Данные, на которых стоит контракт

Полный корпус стены: `vk_ors.db` в
[IndologyScholars/vk-ors/data](https://github.com/gasyoun/IndologyScholars/tree/main/vk-ors/data)
— 7 608 постов за 2015–2026, из них 5 450 с текстом. Рабочий срез —
**«современная эпоха»: 2022+ с ≥100 просмотров, n = 2 799** (просмотры ВК надёжны
только с 2017, а нормы аудитории свежих лет важнее). Метрика — **медианный
like-rate** (лайки/просмотры, %); базовая линия среза — **2,73 %**. Метрика
нормирована на охват, поэтому «длинные посты репостят и им накручивает охват»
на неё не влияет напрямую.

Замечание к CSV: `top_posts_by_likes.csv` — это **60 логических записей**
(195 — счёт *физических строк*: экскерпты многострочные; так посчитан «195 rows»
в H1754). Скорер реально потребляет 60 верхних постов.

Все цифры ниже воспроизводятся скриптом сессии H1754 (Fable 5, `claude-fable-5`);
запросы — обычный `sqlite3` + `re` по `posts.text`.

## 2. Регистр: предметная конкретика, общинный голос

Что измеримо работает (медианный like-rate против базы 2,73 %):

| Маркер | n | like-rate |
|---|---|---|
| Явная дата события («17 сентября», «01.12») | 480 | 2,77 % |
| Имя + фамилия персоналии | 1 383 | 2,83 % |
| Название источника в «ёлочках» | 645 | 2,90 % |
| Год издания/события («1929 г.», «2024 г.») | 462 | 2,77 % |
| Деванагари в тексте | 143 | 2,98 % |
| Общинное 1-е лицо мн. ч. («у нас», «собираемся», «встретимся») | 278 | 2,79 % |

Правила:

- **Каждый пост несёт хотя бы один проверяемый факт**: название текста, слово с
  переводом, дату, имя, год. Названия источников — всегда в «ёлочках».
- Голос — **первое лицо множественного числа общины** («собираемся», «разбираем»,
  «у нас»), не корпоративное «мы рады предложить вам».
- Деванагари/IAST уместны и не отпугивают (2,98 % — выше базы): слово дня даётся
  письмом деванагари с латинской транслитерацией.

Запрещены в NEW-копии: перечисленные фразы и их родня («это уникальный шанс»,

## 4. Зачины

Топ-дециль современного среза (n = 279) против нижней половины (n = 1 400):

| Форма зачина | топ-дециль | нижняя половина |
|---|---|---|
| Анонс с явной датой в первых 200 знаках | 14 % | 7 % |
| КАПС-заголовок первой строкой | 22 % | 15 % |
| Вопрос в первой строке | 4 % | 8 % |
| Пост начинается с хэштега | 0 % | 2 % |

- Анонс события **начинается с даты и факта** («17 февраля — съезд …»), не с
  подводки.
- КАПС-заголовок первой строкой — допустимый, но необязательный приём
  (по всему срезу он нейтрален: 2,72 % при n = 414); если используется — одна
  строка, не больше.
- Не начинать пост вопросом и никогда — хэштегом.

## 5. Эмодзи

| Эмодзи в посте | n | like-rate |
|---|---|---|
| 0 | 1 608 | 2,84 % |
| 1–2 | 822 | 2,65 % |
| 3–5 | 302 | 2,36 % |
| 6+ | 67 | 2,55 % |

Эмодзи-зачин (2,82 %) чуть выше среднего, но лучший бакет — **ноль эмодзи**.
Правило: **по умолчанию без эмодзи**. Единственная разрешённая форма — одна
пара, обрамляющая КАПС-заголовок («🎉 У НАС ПЕРВАЯ ТЫСЯЧА! 🎉» — 29,0 %,
рекорд среза), и только для действительно праздничного/событийного поста.
Рассыпать эмодзи по абзацам (стиль «📖 …», «🔤 …», «💡 …») запрещено — это
бакет 3–5 с худшим результатом 2,36 %.

## 6. CTA

Все жёсткие формы CTA стоят ниже базы 2,73 %:

| Форма CTA | n | like-rate |
|---|---|---|
| «пишите» + ссылка | 80 | 1,89 % |
| «записаться / запись на» | 67 | 1,66 % |
| Голая ссылка t.me последней строкой | 57 | 1,55 % |
| Вопрос-концовка («…?») | 81 | 2,32 % |
| «Подробнее: ссылка» | 15 | 2,75 % |

Правила:

- В NEW-копии (forward-слоты) — **не более одной ссылки**, нейтральной формой:
  «Подробнее: URL» или ссылка как самостоятельный факт (запись эфира, радио,
  корпус). Это единственная форма CTA на уровне базы.
- Запрещены: «пишите в личку/куратору», «запишитесь», «регистрация по ссылке»,
  закрывающий вопрос ради вовлечения. Продающие посты со своей экономикой
  (типа [wall-88831040_23448](https://vk.com/wall-88831040_23448): 471 лайк на
  27 064 просмотров = 1,7 %) — не жанр forward-слотов; их пишет человек.
- Короткий пост-ссылка допустим, только когда ссылка сама по себе примечательна:
  «Санскритское радио» — 21,3 %, «Как устроен санскритский корпус» — 20,9 %.

## 7. Хэштеги

Посты с хэштегами: 2,56 % (n = 772) против базы 2,73 %; в топ-дециле постов,
начинающихся с хэштега, — 0 %. Живые теги стены — архивно-навигационные
(`#bookzealots` 313, `#санскрит` 197, `#читаем_с_орс` 66 — из `hashtags.csv`),
охвата они не приносят.

Правило: **NEW-копия выходит без хэштегов.** Исключение — пост, продолжающий
существующую серию, берёт ровно её тег (`#читаем_с_орс`), в конце поста, не
более одного.

## 8. Длина и цитаты

| Длина, знаков | n | like-rate | медиана просмотров |
|---|---|---|---|
| 1–100 | 499 | 2,71 % | 866 |
| 101–300 | 775 | 2,58 % | 767 |
| 301–700 | 689 | 2,68 % | 874 |
| 701–1 500 | 432 | 2,79 % | 1 073 |
| 1 500+ | 404 | 2,87 % | 1 290 |

Худший бакет — 101–300 знаков: ровно та «короткая дружелюбная заметка», которую
предписывали старые полиш-промпты («максимум 2 абзаца»). Правила:

- Целевая длина NEW-черновика — **400–1 200 знаков** с реальным содержанием;
  сжимать содержательный пост ради краткости запрещено.
- Исключение вниз — пост-ссылка §6 (факт сам за себя).
- Цитата из источника — 1–6 строк оригинала с переводом или пересказом;
  название цитируемого текста обязательно в «ёлочках» (§2: «ёлочки» — 2,90 %).
  Простыня без комментария не нужна: длинные посты работают, когда длина —
  это разбор, а не объём.

## 9. Промо-фильтр EvergreenScorer (ретюн H1754)

`EvergreenScorer::PROMO_PATTERN` исключает продающие посты из повторной
публикации (evergreen-переработка постов возрастом ≥12 месяцев — рекламировать
прошлогодний набор нельзя). Старый паттерн
(`скидк|\bруб\b|₽|запис.{0,20}марафон|марафон.{0,20}цена`) был угадан по ключевым
словам, которых стена почти не употребляет: «скидк» — 3 поста за 11 лет,
«марафон» — 4, «промокод» — 0, «тариф» — 0. Реальный промо-словарь стены,
измеренный по 5 450 текстам: формы «запис-» (записаться/запишитесь/запись на —
79 пропущенных постов), «регистрац-» (31), «оплат-» (19), «стоимост-» (16),
«рублей/руб.» (в т. ч. пропускался из-за ASCII-`\b`).

Новый паттерн (см. код) — строгое надмножество старого: старый ловил 78/5 450,
новый — 196/5 450, потерянных исключений 0. Ложные срабатывания сняты явными
границами: «неоплатонизм» (≠ «оплата»), «записи лекций»/«ЗАПИСЫВАЛИСЬ»
(≠ «записаться»), «за рубежом»/«Рублёв» (≠ «рублей»), «оценка»/«сцена». На
реальном входе скорера (60 записей `top_posts_by_likes.csv`) новый паттерн
дополнительно исключает ровно один пост — 23448, самый продающий пост стены
(«Чтобы записаться на онлайн-курс … пишите»), который старый паттерн пропускал
и отсеивало только отсутствие тематического ключа.

## 10. Применение к четырём семействам шаблонов

| Семейство | Главные правила |
|---|---|
| `reading_group_tease` | общинный голос §2, названия в «ёлочках», без эмодзи §5, без «любой уровень» §3, CTA — «расписание в сообществе», не «пишите» §6 |
| `dictionary_tip` | факт-лидер: слово + деванагари/IAST + перевод §2; без эмодзи-префикса §5 |
| `event_promo` | зачин с даты §4; без цен, без «запишитесь» §6; факты только из `Schedule`/`Course` |
| `faq_micro_answer` | вопрос-ответ телом, не вопросом-зачином §4; «Подробнее: URL» — разрешённая форма §6 |

Полиш-промпты `CuratorAi` обязаны передавать §2–§6 как ограничения и целевую
длину §8 (2–3 абзаца вместо прежнего «максимум 2 абзаца» у контентных жанров).
Изменение любого правила здесь тянет за собой шаблоны и промпты в
`ForwardDraftGenerator` — править в одном PR.
