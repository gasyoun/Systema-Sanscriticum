# MANUAL_EXPENSE_ENTRY_ACCOUNTANT_RU.md — метадокумент

_Created: 31-07-2026 · Last updated: 31-07-2026_

- **Назначение:** рабочая инструкция бухгалтера школы (роль `accountant`) по вводу
  операционных расходов в «Финансы → Расходы (opex)» — обязанность закреплена
  решением MG 31-07-2026 ([issue #953](https://github.com/gasyoun/Systema-Sanscriticum/issues/953)).
- **Аудитория:** Мария (бухгалтер); MG как контролер ритма; агент, проверяющий
  свежесть расходной стороны ОПиУ.
- **Происхождение:** H2016, Fable 5 (`claude-fable-5`), 31-07-2026 — по следам
  моста «Расход»→Expense (H2003, релизы v1.80.11–v1.80.12) и гарда будущих дат
  (H2008, v1.80.13). Цифры прошлой практики — из живой БД (440 записей,
  13 514 495 ₽, июнь 2025 — июнь 2026).
- **Бэклог улучшений (по убыванию ценности):**
  1. Скриншоты формы «Расходы (opex)» после первой рабочей сессии Марии.
  2. Чек-лист сверки с банковской выпиской (когда появится доступ к выписке).
  3. Правило категоризации повторяющихся контрагентов (после разнесения legacy-строк).
- **Ограничения:** статья у 440 legacy-строк — «Налоги, банк, прочее» до ручного
  разнесения; назначение у них пустое и невосстановимо из системы.
- **История ревизий:** 31-07-2026 — создан (H2016).
