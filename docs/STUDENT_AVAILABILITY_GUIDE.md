> 2. Напишите в личку боту: `/кабинет korolevan889@gmail.com`
> 3. Бот пришлёт одноразовую ссылку — откройте её (живёт 15 минут), и вы окажетесь в кабинете.
> 4. Если ссылка протухла — напишите боту `/вход`, придёт новая.

>
> Чтобы нам не предлагать вам занятия в неудобное время, откройте в кабинете

**Важно:** `/кабинет` создаёт бесплатный кабинет с открытыми плейлистами. Доступ к платному

Прод-флаги уже включены: `TELEGRAM_CABINET_PROVISION=true`, `TELEGRAM_CABINET_LOGIN=true`,
`TELEGRAM_CABINET_EMAIL_LINK=true`. Пользователя с этим email в базе не было — значит
команда создаст аккаунт с нуля.

## 2. Записанные окна доступности

TZID `Europe/Moscow`, источник `student`, `kind=allow`:

| День | RRULE | Окно |
|---|---|---|
| Четверг | `FREQ=WEEKLY;BYDAY=TH` | 20:00–23:59 |
| Пятница | `FREQ=WEEKLY;BYDAY=FR` | 18:00–23:59 |
| Суббота | `FREQ=WEEKLY;BYDAY=SA` | 09:00–11:00 |
| Суббота | `FREQ=WEEKLY;BYDAY=SA` | 14:30–23:59 |
| Воскресенье | `FREQ=WEEKLY;BYDAY=SU` | 17:00–23:59 |

Понедельник, вторник и среда — строк нет;для ученика со строками отсутствие окна
означает «недоступно». Ученик без единой строки не фильтруется.

## 3. Как это работает

- **Студент**: вкладка `/dvaram/availability` (пока `AVAILABILITY_WINDOWS_ENABLED=true`)
  сеткой пн–вс, до двух интервалов на день; для каждого интервала выбирает режим
  «Удобное время» (`allow`) или «Неудобное время» (`deny`). Неудобное время студента
  перекрывает его же удобное; строки куратора по-прежнему приоритетнее любых студенческих.
- **Куратор**: Filament → «Студенты» → «Окна доступности»; может добавить `allow`
  или `deny` — строки куратора приоритетнее студенческих.
- **OfferGate**: `app/Support/StudentAvailability.php` — `allows()` для момента и
  `allowsSlot()` для строк витрины вида «пн 18:00». В кабинете фильтруются только
  карточки списка ожидания (новые офферы). Купленные курсы, «Продолжить обучение»,
  расписание, Zoom и ДЗ не затрагиваются.

## 4. Включение на проде

1. Выкатить код, выполнить `php artisan migrate --force`
   (создаёт `student_availability_windows`).
2. `AVAILABILITY_WINDOWS_ENABLED=true` + `php artisan config:cache`.
3. Проверить: `/dvaram/availability` открывается, Filament-ресурс виден куратору,
   карточка «пн 18:00» скрыта, «сб 17:00» видна.
4. Откат: `AVAILABILITY_WINDOWS_ENABLED=false` + `config:cache` — гейт молча выключается,
   данные остаются.
