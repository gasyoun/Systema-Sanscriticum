# Standing policy — инструкции учебного процесса живут на сайте, не на GitHub

_Created: 22-11-2026 · Last updated: 22-11-2026_

## Rule (MG, 21-11-2026)

Любые инструкции, связанные с учебным процессом (управление ботом в чате
группы, кабинет, домашки, доступы, расписания), адресованные преподавателям/
кураторам/студентам, публикуются на сайте — **не** ссылками на GitHub-файлы.

## Mechanism

Закоммиченный Markdown в `docs/` рендерится на живом URL через
`App\Support\MarkdownGuide` (паттерн H3499: `/help/kabinet` ←
`docs/STUDENT_CABINET_GUIDE_RU.md`). Тот же deploys-цикл, что и код: страница
не может разойтись с поведением. Существующие и новые поверхности:

| URL | Источник |
|---|---|
| `/help/kabinet` | `docs/STUDENT_CABINET_GUIDE_RU.md` |
| `/help/uchitelyu` | `docs/TEACHER_HELP_RU.md` (гид преподавателя: бот «Почтальон», H8526) |

Новая инструкция = новая секция в существующем SOURCE (или новый SOURCE +
роут по этому образцу, строго до catch-all `/{slug}`), гвард-тест по образцу
`TeacherHelpPageTest` (словарь страницы ↔ словарь кода).

## Corollary

Git-репозиторий остаётся source of truth (правки через PR, история, ревью) —
GitHub не поверхности, а источника. Ссылки в рассылках/чатах — на живой URL
сайта; ссылка на blob-файл GitHub в учительской переписке не используется.
