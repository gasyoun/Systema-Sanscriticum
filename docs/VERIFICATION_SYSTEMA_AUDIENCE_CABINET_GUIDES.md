## 5. Риски

| Риск | Вероятность | Чем плох | Что делаем |
|---|---|---|---|
| Playwright не в CI, кадры протухнут | средняя | гид врёт про кнопки | freshness warn + команда пересъёмки |
| Второй браузерный стек рядом с Dusk | средняя | две инструкции «как снять» | Dusk не трогаем; Playwright только `scripts/capture-guide-screenshots.mjs` |
| Неэкранированный Markdown | низкая | XSS | константный путь, как TeacherGuide |
| Студент не найдёт `/dvaram/help` | средняя | снова непрочитанный мануал | пункт меню **«Как пользоваться»**, не «документация» |
| PDF студента разъедется с кабинетом | средняя | решение 10 сознательно даёт PDF | в PDF колонтитул «актуально в кабинете: /dvaram/help» |
| Watcher сожрёт uncommitted md | высокая на main | потеря текста | только worktree; коммит сразу |
| Кадры бухгалтера случайно в git | высокая на волне 3 | H3084 повтор | gitignore `storage/app/guide-shots/` + тест «в docs/screenshots нет accountant» |
| «Влить спутники» раздует куратора | средняя | снова не читают | решение 17: не весь debtors-manual |
| Рефакторинг TeacherGuide «заодно» | средняя | ломаем живой гид препода | забор: не трогать |

## 6. Что выяснить до съёмки, не до текста

Логин фикстурного студента на `artisan serve`: пароль фабрики, CSRF, `APP_URL`. Это шип шага 5, не повод откладывать шаги 1–4. Если логин не встаёт за час — журнал, skip кадров, текст всё равно мержится.
