# Карточки открытых занятий в @samskrte_bot

_Created: 14-10-2026 · Last updated: 14-10-2026 (страница воронки, перезапуск Horizon)_

Каждое открытое бесплатное занятие приходит подписчикам @samskrte_bot карточкой
(по образцу ботов конференций): баннер, подпись «🎙 название / 📅 когда, онлайн
в Zoom, участие бесплатное / кто ведёт / ссылку пришлём перед началом», кнопка
**«✅ Я иду»** и постоянное нижнее меню бота.

## Что уходит и когда

| Стадия | Когда | Кому |
|---|---|---|
| `announce` | ежедневно 12:00, занятия через 2–3 дня (`announce_days`) | все подписчики бота, кроме заблокировавших |
| `morning` | 09:00 в день занятия; занятие раньше 12:00 — накануне в 19:00 | все, кроме нажавших «Не смогу» |
| `zoom` | каждые 5 минут, за 30 минут до начала | только нажавшие «✅ Я иду» |

Кто нажал «Я иду» позже рассылки ссылок, получает ссылку сразу.
Нет ссылки на подключение (Zoom-встреча → «Ссылка на Zoom» → единая ссылка курса) —
алерт в `ADMIN_TELEGRAM_ID`, людям ничего не уходит.

Каждая стадия уходит чату **один раз** (журнал `open_lesson_card_sends`),
повторный прогон команды безопасен.

## Какие занятия

Только с галочкой **«Открытое занятие: анонс в боте»** (Расписание → занятие →
секция «Анонс в боте @samskrte_bot», видна админам). Автоотбора нет: пробное
занятие в системе платное, разовые курсы бывают платными, а карточка обещает
«участие бесплатное» и раздаёт ссылку Zoom. Обзорные без галочки подсвечены
в списке расписания как «💡 кандидат».

В той же секции — свой баннер (иначе баннер курса 16:9 / 4:3 или обложка
витрины; webp перекодируется в jpg) и приписка к подписи. В меню строки — действие
«Карточка в бот: предпросмотр» шлёт карточку вам в личку.

## Аудитория

`bot_subscribers`: все, кто нажал `/start` в @samskrte_bot (с токеном магнита или
без), плюс засев из `leads.telegram_chat_id` миграцией. 403 / «chat not found» →
`blocked_at`, больше не шлём; повторный `/start` снимает блокировку.

Ссылка на карточку конкретного занятия для анонсов в канале и на лендингах:
`https://t.me/samskrte_bot?start=ol_<schedule_id>`.

## Воронка бота (по образцу @AlpinaAIconfbot)

**/start** без токена (флаг ON) — три сообщения: карточка ближайшего открытого
занятия → «🎁 Подарки для начинающих» с кнопкой «✍️ Участвовать» и текстом
согласия → «Остальные разделы — в меню внизу 👇» с нижним меню. Флаг OFF —
прежнее приветствие ждуна.

**Нижнее меню** (`config/open_lesson_cards.php` → `menu`):

```
[        🎙 Ближайшие занятия        ]
[  📚 Программа  ] [    🎁 Подарки    ]
[    🌐 Сайт     ] [  ✍️ Участвовать  ]
```

Программа — видимые курсы с ближайшим занятием + «Расписание» + «Ждун»;
Подарки — полка подписчика (`SubscriberMagnet`, Filament); Сайт — сайт, канал,
«Стать добровольцем». Каждый раздел заканчивается одним призывом «Анкета
короткая — минута… Участие бесплатное.» и кнопкой «✍️ Участвовать».

**✍️ Участвовать:** «Остался шаг 🙌» + «✅ Подписаться» (канал @samskrte) →
«✅ Я подписался» (или слово «подписался») — бот проверяет подписку
`getChatMember` (бот должен быть админом канала; если Telegram не ответил —
пропускаем, не запираем) → согласие (`consent_at`) → анкета: имя, интерес,
удобное время → **лид в CRM** (`utm_source=samskrte_bot`, `utm_campaign=bot_join`,
`is_promo_agreed`, заметка «Анкета в @samskrte_bot»; существующий лид по
`telegram_chat_id` обновляется, не дублируется; новый — в чат маркетологов) →
подарки ссылками + карточка ближайшего занятия. Повторное «Участвовать» —
сразу подарки.

**Описание бота до /start** — `php artisan open-lessons:bot-profile`
(`bot_description`, `bot_short_description`). Картинку к описанию Bot API не
задаёт: @BotFather → `/setdescription` → Edit Description Picture.

## Включение

1. Деплой (`deploy.sh`), миграции.
2. **Перерегистрировать вебхук** — бот теперь принимает `callback_query`
   (без этого «✅ Я иду» и кнопки ждуна не доходят):
   `php artisan telegram:webhooks --set --only=magnet`.
3. `.env`: `OPEN_LESSON_CARDS_ENABLED=true`,
   `OPEN_LESSON_CARDS_TEST_CHAT_IDS=<свой chat_id>` → `config:cache` →
   **`php artisan horizon:terminate`**. /start и кнопки обрабатывает очередь
   (`ProcessTelegramMagnetUpdate`), а воркеры Horizon держат конфиг с момента
   запуска: без перезапуска бот продолжает отвечать по-старому.
   **Тестовый режим:** пока список не пуст, новый бот целиком (приветствие,
   меню, «Участвовать», кнопки, рассылки карточек) работает только для этих
   чатов; остальные видят прежнее приветствие ждуна.
4. Нажать `/start` в @samskrte_bot, поставить галочку на занятии, затем
   `php artisan open-lessons:cards --stage=announce --only-chat=<chat_id>`.
   Проверить фото, подпись, «✅ Я иду» (кнопка меняется на «✅ Вы записаны»),
   нижнее меню, deep-link.
5. `php artisan open-lessons:bot-profile`; картинку описания — в @BotFather.
   Проверить, что @samskrte_bot — админ канала @samskrte (иначе подписка не проверяется).
6. `php artisan open-lessons:cards --stage=announce --dry-run` — занятия и число
   получателей.
7. Очистить `OPEN_LESSON_CARDS_TEST_CHAT_IDS` → `config:cache` → `horizon:terminate`.
   Дальше всё по расписанию.

## Где смотреть

- **Админка → Маркетинг → «Воронка @samskrte_bot»** (только админы):
  - цифры воронки: аудитория → нажали «Участвовать» → подписались на канал →
    заполнили анкету → лид, с долей от предыдущего шага;
  - таблица «Открытые занятия в боте»: доставлено анонсов / утренних карточек /
    ссылок Zoom, «Я иду» и «Не смогу» по каждому занятию с галочкой;
  - список подписчиков: шаг анкеты, ответы, лид, кто заблокировал бота;
    фильтры по шагу, «нажимал Участвовать», блокировке, источнику.
- Лиды из бота — «Продажи → Заявки», источник `samskrte_bot`, ответы анкеты в заметке.
- `open_lesson_card_sends` — что, кому и когда ушло (`message_id`, `sent_at`).
- `open_lesson_rsvps` — «Я иду» / «Не смогу», `zoom_sent_at`.
- Колонка «В боте» в списке расписания — число «Я иду».
- Лог: `OpenLessonTelegram: telegram api not ok`.

Код: `app/Services/OpenLessonCards/*`, `app/Console/Commands/SendOpenLessonCards.php`,
`app/Jobs/SendOpenLessonCardJob.php`; тесты `tests/Feature/OpenLessonCards/`.
