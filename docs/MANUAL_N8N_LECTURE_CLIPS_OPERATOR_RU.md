## 1. Как устроен контур (одной схемой)

```
Опубликованный урок (video URL + transcript с AI-таймкодами)
        │
        ▼  кнопка «Нарезать лекцию»  (нужен CLIP_MARKETING_ENABLED=true)
DispatchLectureClipExtractionJob
        │  POST + X-Webhook-Secret
        ▼
n8n: Webhook → Expand spans → ffmpeg cut → VK upload → Laravel callback
        │
        ▼
Строки «Клипы лекций» (LectureClip)
        │
        ▼  тумблер «Бесплатный» (~3 на лекцию)
Витрина / дальше — контент-план (соцпосты и т.д., пока в разработке)
```

**Важно:** Laravel **не** режет видео. Он только шлёт границы (секунды + заголовки) в n8n и **записывает** ответ. Весь тяжёлый ffmpeg и загрузка в ВК — в n8n.

## 2. Перед первой нарезкой (чеклист «можно ли жать кнопку»)

Без этого кнопка либо не видна, либо job молча ничего не сделает.

### 2.1. Флаг и меню

1. В `.env` на сервере: `CLIP_MARKETING_ENABLED=true`.
2. `php artisan config:clear` (или `config:cache` после правки env).
3. В админке `/admin` появится группа **«Маркетинг» → «Клипы лекций»**.  
   Если пункта нет — флаг выключен или вы не 🔴 админ (`RoleGate::adminOnly()`).

### 2.2. n8n (делает оператор один раз, потом только чинит)

См. [issue #666](https://github.com/gasyoun/Systema-Sanscriticum/issues/666), кратко:

- Воркфлоу `docs/n8n/lecture-clip-extract.workflow.json` импортирован и **Active**.
- В env n8n заданы `VK_ACCESS_TOKEN` (право **`video`**, а не только `photos`+`wall`)
  и `VK_VIDEO_GROUP_ID`; SSH-кред `n8n` подставился в ноды нарезки.
- В Laravel `.env`:
  - `N8N_CLIP_EXTRACT_WEBHOOK` — Production URL вебхука n8n  
  - `N8N_CLIP_EXTRACT_SECRET` — тот же секрет, что Header Auth на webhook n8n (`X-Webhook-Secret`)  
  - `N8N_CLIP_CALLBACK_SECRET` — секрет callback n8n → Laravel  

### 2.3. Готовность **конкретной** лекции

| Требование | Зачем |
|---|---|
| Урок **опубликован** (`is_published`) | Job иначе отказывается |
| Есть URL видео (`video_url` / YouTube / Rutube) | n8n скачивает/режет источник |
| Есть `transcript_file` с таймкодами (Deepgram / n8n-формат) | `ClipSpanPlanner` строит спаны; без слов — пустой список, нарезки не будет. Заполняется автоматически: ZOOM-сценарий шлёт ответ Deepgram на `POST /api/lessons/{lesson}/transcript` сразу после создания урока. У уроков **до 28.07.2026** поля нет — их транскрипты в LMS не попадали |
| Пройден AI-шаг **таймкоды** в редакторе лекций (очередь `lectures`) | Границы клипов = уже проверенные AI-таймкоды, **не** пересчитываются заново |

**Как понять, что таймкоды есть:** в кабинете/лендинге у урока открывается стенограмма с кликабельными метками времени; в админке редактора лекций — успешный прогон задачи «timecodes» без ошибки в `error_log`.

## 3. Обычная операция: нарезать одну лекцию

**Кто:** 🔴 админ.  
**Где:** `/admin` → **Маркетинг** → **Клипы лекций**.

### 3.1. Шаги

1. Открыть **Клипы лекций**.
2. В шапке списка нажать **«Нарезать лекцию»** (иконка ножниц).
3. В списке выбрать **опубликованную** лекцию (поиск по названию; в селекте до 200 последних).
4. Подтвердить. Должно появиться уведомление:  
   *«Запрос на нарезку поставлен в очередь»* / *«n8n получит спаны…»*.
5. Подождать 1–15 минут (зависит от длины урока и ffmpeg-воркера).
6. Обновить список: появились строки с заголовками вида «… — фрагмент N: …», колонкой времени и галочкой **«В VK»**, если callback принёс `vk_video_id`.

### 3.2. Что происходит «под капотом» (чтобы читать логи)

1. Job `DispatchLectureClipExtractionJob` (очередь Laravel) при флаге ON:
   - берёт урок;
   - `ClipSpanPlanner::planSpans` — куски ~90 с из предложений транскрипта, до 12 спанов;
   - POST на `N8N_CLIP_EXTRACT_WEBHOOK` с телом `action=clip_lecture`, `lesson_id`, URL видео, `spans[]`, `callback_url`.
2. n8n режет каждый span, грузит в VK, шлёт callback.
3. `POST /api/webhooks/lecture-clip-callback` (при флаге ON) пишет строки **идемпотентно** по паре `(lesson_id, start_seconds, end_seconds)` — повторный запрос не плодит дубликаты тех же границ.

### 3.3. Отметить бесплатные фрагменты (~3 на лекцию)

1. В таблице **Клипы лекций** найти строки нужной лекции.
2. Тумблер **«Бесплатный»** включить у 2–4 лучших кусков (политика редакции; в коде жёсткого лимита «ровно 3» нет — это правило процесса).
3. При необходимости поправить **заголовок** клипа (кнопка «Изменить») — для ВК/витрины удобнее короткие человеческие названия, чем «фрагмент 7: …».

Фильтр **«Бесплатный»** в таблице помогает оставить только кандидатов на витрину/соцсети.

## 4. Еженедельный ритм (рекомендуемый)

После того как n8n и флаг уже живут на проде.

| День / триггер | Действие |
|---|---|
| После публикации новой записи занятия | Убедиться: транскрипт + AI-таймкоды готовы |
| Тот же день или на следующий | Админ: **Нарезать лекцию** для этого урока |
| +15–30 мин | Проверить список клипов; при пустоте — §6 |
| После появления клипов | Отметить 2–4 **Бесплатный** |
| Раз в неделю | Пройтись по бесплатным: заголовки, нет ли мусорных кусков (вступление, «слышно?») |
| По мере готовности | Дальше — посты/рассылки (см. §8: пока код волн 2–5 может быть не влит) |

Не гоните **все** уроки курса в первый день: нагрузка на ffmpeg/VK квоты.

## 5. Соседние n8n-операции (не клипы, но тот же n8n)

Краткая эксплуатация; настройка — [docs/n8n/README.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/n8n/README.md) и issue #666 часть C.

### 5.1. Расписание → Google Таблица

**Где в Laravel:** раздел **Расписание** → кнопка выгрузки в Google Таблицу (и авто-sync при изменениях, если webhook в `.env`).

**Оператор:** воркфлоу Active; лист не удалять шапку; webhook URL в `N8N_SCHEDULE_SHEET_WEBHOOK`.  
**Осторожно:** лист **полностью перезаписывается** (кроме первой строки шапки) — не хранить в нём ручные правки, которые нельзя потерять.

### 5.2. Ежемесячный пост «сейчас идут курсы»

**Где:** кнопка **«Опубликовать в соцсети»** в Расписании или планировщик `schedule:post-monthly` (1-е число, 10:00 МСК).

**Проверка без публикации:**

```bash
php artisan schedule:post-monthly --dry
```

Показывает текст, в n8n/ВК **не** шлёт.

## 6. Неполадки (что проверить по порядку)

| Симптом | Вероятная причина | Что сделать |
|---|---|---|
| Нет пункта «Клипы лекций» | Флаг OFF или не админ | `CLIP_MARKETING_ENABLED=true`, `config:clear`; роль admin |
| Уведомление «в очереди», но строк нет | n8n не Active / неверный webhook / secret | Executions в n8n; сверить `N8N_CLIP_EXTRACT_*` |
| Job в логах: «нет AI-таймкодов» | Нет/пустой transcript | Редактор лекций: транскрипт + задача timecodes |
| Job: «лекция не опубликована» | Черновик | Опубликовать урок |
| n8n падает на ffmpeg | Placeholder URL / воркер лёг | issue #666 шаг A2–A3; логи воркера |
| n8n падает на VK | Токен/права video | Community token Video+Wall; не в git |
| Клипы есть, **В VK** пусто | Callback без `vk_video_id` | Починить VK-ноду; повторный dispatch (те же границы обновятся только если firstOrCreate — без id перезалить вручную или править поля) |
| Callback 404 | Флаг OFF | Включить `CLIP_MARKETING_ENABLED` |
| Дубликаты клипов «как будто» | Другие `start/end` (новый planSpans) | Нормально при смене транскрипта; старые строки удалить вручную при необходимости |

**Логи Laravel (ориентиры):**

- `DispatchLectureClipExtractionJob: clip_marketing выключен`
- `N8N_CLIP_EXTRACT_WEBHOOK не задан`
- `нет AI-таймкодов для нарезки`
- `n8n вернул 4xx/5xx`

**Откат «выключить всё» без потери данных:**

```env
CLIP_MARKETING_ENABLED=false
```

```bash
php artisan config:clear
```

Меню пропадает, job no-op, callback 404. Таблицу `lecture_clips` **не** дропать.

## 7. Права и безопасность

- Секреты n8n/VK **только** в env n8n и Laravel `.env`, не в issue, не в git.
- Публичный callback защищён секретом middleware; URL не светить в открытых чатах.
- Бесплатные клипы — публичный контент: **не** отмечать фрагменты с чужой закрытой методичкой / ПДн студентов / внутренними обсуждениями.
- Полный транскрипт платного урока **не** выкладывать в открытый пост (политика контент-плана: короткая цитата ≤2 предложений — см. план H2).
