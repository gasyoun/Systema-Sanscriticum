# НКРЯ-линт учительских колод Memrise и корпусного глоссария (H5401)

H5401 (Opus, 🟡2 medium) — вторая волна линта [H5285](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5285-Opus_Systema-Sanscriticum_nkrya-beginner-gloss-lint_23.09.26.md): те же правила прогнаны по пяти колодам Memrise и по [sa_ru_glossary.json](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/sa_ru_glossary.json). Словарь Бюлера — отдельная волна (grill 23-09-2026, Q5). Исполнитель: Claude Code Opus 5 (`claude-opus-5[1m]`); токен «Opus» в имени файла хендоффа — провенанс, не исполнитель. Первый отчёт волны: [NKRYA_GLOSS_LINT_BEGINNER_SRS_REPORT_23-09-2026.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/NKRYA_GLOSS_LINT_BEGINNER_SRS_REPORT_23-09-2026.md).

## Что добавлено в инструмент

1. Пресет `glossary` в [scripts/nkrya_gloss_lint.py](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/scripts/nkrya_gloss_lint.py): источник — JSON, а не TSV; 26 071 статья × до трёх русских глосс из поля `g` разворачивается в 65 802 строки (по строке на глоссу, `gloss_idx` 1–3). Пишутся только *действенные* строки (`flagged_only`): те, где есть `inflected`, `inflected_ambiguous`, `rare`, `soft_rare`, `c19_only` или `not_russian`. `phrase`, `name` и `unknown` (полоса ещё не измерена) — контекст, не дефект.
2. Пресеты `memrise_<ID>` — по одному на колоду, каждый склеивает `level_*.csv` колоды в один источник и добавляет колонку `level`. Колоды учительские, поэтому в пресете стоит `flag_only`: замена синонима не предлагается никогда (grill 23-09-2026, Q3 — формулировка преподавателя остаётся, современная подсказка только после голосования).
3. Очередь измерений [band_queue.tsv](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/band_queue.tsv): все ещё не измеренные пары (лемма, часть речи) с числом задетых строк, по убыванию. Это порядок, в котором неприсмотренный проход должен тратить квоту НКРЯ, и `--drain-queue N` его исполняет.
4. `--selftest` вырос с 20 до 28 offline-проверок (JSON-источник, `flagged_only`, `flag_only`, очередь).

Команда прохода (offline, ~10 с):

```bash
NKRYA_CLIENT_SRC=~/Documents/GitHub/SanskritLexicography/RussianTranslation/src \
python3 scripts/nkrya_gloss_lint.py memrise_6502608 memrise_6508023 memrise_6517849 \
    memrise_6522419 memrise_6679375 glossary --offline
```

## Что нашлось

| источник | строк | не в словарной форме | фраза | имя | полоса 1 (`rare`) | полоса 2 | не по-русски |
|---|---|---|---|---|---|---|---|
| memrise_6502608 | 2 124 | 7 (+2 неоднозначных) | 1 764 | 117 | 0 | 2 | 0 |
| memrise_6508023 | 1 157 | 3 (+2) | 548 | 25 | 0 | 0 | 0 |
| memrise_6517849 | 78 | 0 | 0 | 0 | 0 | 0 | **78** |
| memrise_6522419 | 356 | 2 (+1) | 274 | 18 | 0 | 0 | 0 |
| memrise_6679375 | 166 | 34 (+2) | 36 | 1 | 0 | 0 | 0 |
| глоссарий | 65 802 | **15 593** (+1 126) | 10 | 4 | 16 | 36 | 0 |

1. **В учительских колодах «не словарная форма» — это не дефект, а замысел.** Колода спрягаемых форм 6679375 (`गच्छति` — «идет», `म्लायति` — «вянет») и колода 6502608 (`kuru` — «сделай», `prāpya` — «получив», `jñātvā` — «узнав») переводят *конкретную форму*, и русская глосса зеркалит её намеренно. Это ровно тот случай, ради которого Q3 сделал колоды flag-only: механическая нормализация к инфинитиву здесь испортила бы карточку. Флаг остаётся как опись, предложения не выписываются.
2. **memrise_6517849 — не словарная колода, а парадигма склонения.** Все 78 строк в «русской» колонке несут санскритскую форму и грамматическую помету (`bhānuḥ N., sg.`), поэтому линт помечает их `not_russian`. Русских глосс в этой колоде нет вообще — судить её по НКРЯ нечем; при импорте в SRS её надо вести как грамматическую, а не лексическую.
3. **Три четверти глосс учительских колод — фразы** (1 764 из 2 124 в 6502608): «(m) глупец, невежда», «несравнимый, несравненный». Словарной формы у фразы нет, полоса считается по каждому знаменательному слову.
4. **В глоссарии 15 593 глоссы (24% из 65 802) не в словарной форме** — «сказано», «сближении», «родился», «искусен». Это ожидаемо: глоссы вынуты из выровненного корпуса, то есть из связного текста. Правка нужна не в самом `sa_ru_glossary.json` (он производный), а в порождающем проходе; строка с предложенной формой лежит в колонке `gloss_lemma` [glossary_gloss_lint.tsv](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/glossary_gloss_lint.tsv).
5. **Все 16 редких глосс глоссария — тот же класс, что нашёл H5285: слитное «не-» на санскритском отрицании a-/an-.** «нерождённый» (0,50 ipm, полоса 1) у `aja`, `ajanman`, `ajāta`, `atarkya`, `aparasparasaṃbhūta`, `bhrūṇahatyā`; «нестареющий» (0,35 ipm) у `ajara`, `ajurya`, `nirjarāyu`; плюс `anartha` «не-артха» — дефисная транслитерация, которой в НКРЯ нет вовсе.

## Вердикт по листам голосования: новых карточек нет

Приёмка H5401 требует «листы на кандидатов замены или письменный вердикт „нет“». Вердикт — **нет новых карточек**, по трём причинам:

1. Колоды Memrise flag-only по Q3: кандидатов замены там не бывает по правилу, а не по факту измерения.
2. В глоссарии единственное предложение замены из наших же данных — `anartha` «не-артха» → «вред» (полоса 3, 30 ipm). Эта карточка уже стоит в листе [systema_nkrya_gloss_lint_rare_swaps_23-09-2026.html](https://gasyoun.github.io/vote/sheets/systema_nkrya_gloss_lint_rare_swaps_23-09-2026.html) (H5285, ⏳ ждёт голоса) вместе с `ajara` «нестареющий» → «вечно молодой» и карточкой-правилом про a-/an-. Дублировать её вторым листом — значит спрашивать одно и то же дважды.
3. Остальные 15 редких строк — те же две леммы («нерождённый», «нестареющий») в других статьях: их судьбу решает **карточка-правило** уже стоящего листа, а не 15 новых карточек. Проголосованное правило применяется ко всем строкам разом.

Поэтому в [REVIEW_SHEETS_INDEX](https://github.com/gasyoun/Uprava/blob/main/REVIEW_SHEETS_INDEX.md) новой строки не заводится; H5401 расширяет охват уже висящего листа, а не открывает свой.

## Лимит НКРЯ: почему полосы почти везде пустые

Очередь измерений содержит **13 680 неизмеренных лемм** (по 65 802 + 3 881 глоссам). При измеренных ~60 запросах в час на аккаунт (лимит на ключ, общий для всех сессий) полный проход — около 228 часов работы. Поэтому:

1. Детерминированная половина линта (словарная форма, фраза, имя, «не по-русски») посчитана **полностью и без сети** — она и даёт почти всю пользу для учительских колод.
2. Полосы НКРЯ набираются порционно: очередь отсортирована по числу задетых строк (`сын` — 451 строка, `бог` — 425, `весь` — 348), так что первые же сотни запросов закрывают непропорционально много.
3. Неприсмотренный проход по очереди, возобновляемый (кэш сохраняется каждые 20 запросов):

```bash
RUSCORPORA_API_TOKEN="$(security find-generic-password -s ruscorpora-api -w)" \
NKRYA_CLIENT_SRC=~/Documents/GitHub/SanskritLexicography/RussianTranslation/src \
python3 scripts/nkrya_gloss_lint.py --drain-queue 400 --interval 12
```

Ключ лежит в keychain Mac (`ruscorpora-api`); над ssh чтение падает с rc=36 — запускать из окна Терминала на самом Mac (это и было блокером H5397). В этом проходе ключ прочитался, и порция очереди действительно измерялась вживую — кэш вырос с 67 до 84 ключей (17 верхних лемм очереди измерены живьём за ~20 минут — это и есть наблюдённая скорость ~60 запросов в час), см. [nkrya_evidence_cache.tsv](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/resources/data/nkrya_lint/nkrya_evidence_cache.tsv).

## Что НЕ менялось

Ни один источник не правился: `database/seeders/data/memrise_*/level_*.csv` — выгрузки чужих колод, `resources/data/sa_ru_glossary.json` — производный артефакт. Линт только описывает; правка идёт в порождающие проходы и — для колод — только после голосования.
