## Changed

- `resources/views/student/lesson.blade.php` — layout containers and styles only:
  - homework (`@include('student.partials.homework')` and the explicit no-homework state) moved
    out of `.lesson-main-col` into a new sibling container `.lesson-homework-col` placed **after**
    `.lesson-side-col` in the DOM — the transcript/materials/notes tab panel now precedes homework
    in DOM order, focus order and (on narrow screens) visual order;
  - mobile (<768px): `.lesson-layout` switched from `display: block` to flex column with
    `gap: 1.5rem` (replaces the old side-col `margin-top`), so DOM order = visual order;
  - desktop (≥768px): `grid-template-areas: "main side" "homework side"` reproduces the previous
    geometry exactly — main column left, sticky 420px side column right, homework in the left
    column below the main column; sticky/`dvh` handling (H4118) preserved verbatim;
  - Alpine state, note-save behavior and the homework partial untouched (sibling-brief boundary).
- `tests/Feature/LessonMobileMaterialsOrderTest.php` — new behavioral checks (written first,
  red on `bd3fe127`, 5/5 failing; green after the fix).

## Unchanged
