## A. Куратор → ученик

### A1. Зафиксировали отсрочку (после «Договориться» в админке)

```
Здравствуйте, {name}.

Зафиксировали отсрочку оплаты:
• курс(ы): {course}
• блок(и): {block}
• дата в системе: {date}

До этой даты: {access_rule}
(пример access_rule: «доступ к материалам открыт по договорённости» /
«доступ к неоплаченному блоку закрыт — открывается после оплаты»)

Оплатить: кабинет → «Мои долги»
https://samskrte.ru/dvaram

За день до даты может прийти автоматическое напоминание — это нормально.
Если к дате оплаты не будет, доступ и участие в учебном чате пересмотрим.
```

### A2. Мягкое напоминание (кнопка «Напомнить» / вручную)

```
{name}, добрый день.

По курсу «{course}» (блок {block}) в системе есть неоплаченный блок.
Пожалуйста, оплатите в кабинете → «Мои долги» или напишите, если нужна отсрочка с конкретной датой — зафиксируем в системе.

https://samskrte.ru/dvaram
```

### A3. Предупреждение перед отзывом / исключением из чата

```
{name}, добрый день.

Обещанная дата оплаты {date} по курсу «{course}» прошла / близко, оплаты в системе нет.

Ближайшие шаги с нашей стороны (если не получится закрыть долг):
1) отзыв временного доступа к материалам;
2) исключение из учебного Telegram-чата курса;
3) при необходимости — статус «исключён» по курсу.

Напишите сегодня, если нужна короткая новая дата — зафиксируем в кабинете.
Иначе ориентируйтесь на оплату здесь: https://samskrte.ru/dvaram → «Мои долги»
```

### A4. После оплаты (коротко)

```
Оплата по «{course}» получена, доступ должен открыться сам (обычно минуты).
Если урок ещё под замком — на карточке урока «Почему закрыто?» → «Открыть оплаченные блоки».
```

### A5. Ответ, если ученик думает, что «уже написал = уже записано»

```
Сообщение в Telegram мы видим, но дата оплаты в личном кабинете появляется только после фиксации в системе (кнопка «Договориться»).

Сейчас зафиксировали: до {date}, курс «{course}».
Проверьте вкладку «Мои долги»: https://samskrte.ru/dvaram
```

## B. Ученик → куратор / @rusamskrtam

### B1. Просьба об отсрочке (копировать)

```
Здравствуйте.

Не успеваю оплатить в срок.
Курсы: …
Было нужно: … (например 2.08 и 10.08)
Прошу отсрочку до: 20.08.2026
Оплачу: все перечисленные / только …

Пожалуйста:
1) зафиксируйте дату в Systema (чтобы она была в кабинете «Мои долги»);
2) напишите, остаётся ли доступ к материалам и учебному чату до этой даты.

Спасибо.
```

### B2. «Написал раньше — проверьте, есть ли в кабинете»

```
Здравствуйте. Ранее писал(а) про отсрочку до {date}.
Подтвердите, пожалуйста, что дата уже в кабинете (вкладка «Мои долги»), а не только в переписке.
```

### B3. После оплаты, доступ не открылся

```
Оплатил(а) {course}, доступ к блоку ещё закрыт.
Email кабинета: …
Проверьте, пожалуйста. Я уже смотрел(а) «Мои оплаты» / «Почему закрыто?».
```

## C. Чеклист куратора после ЛС (30 секунд)

1. [ ] Открыть **Должники** / карточку → **Обещания**
2. [ ] **Договориться** на согласованную дату (каждый курс отдельно, если несколько)
3. [ ] Решить тогл **доступ под обещание**
4. [ ] Ответить ученику **A1** или **A5**
5. [ ] Не оставлять «договорились в чате» без строки promise

---

## D. Запреты в 1:1

- Не стыдить; без «коллекторского» тона.
- Не обещать, что «одно сообщение само создаст дату в кабинете».
- Не путать: кик из чата ≠ отчисление с курса.
- Не включать conditional access «по умолчанию» на рецидивистах (🚩).
