## Как работает система (коротко)

1. Ученик платит на **paypal.me/gasuns** (получатель `gasyoun@gmail.com`), комиссия PayPal — на отправителе, EUR предпочтительно.
2. Ученик сам подаёт уведомление на форме `samskrte.ru/paypal/{tariff_id}` («Уведомление об оплате через PayPal»): вставляет dump деталей из PayPal Activity → поля дата/сумма/валюта заполняются сами; свой PayPal-email и опц. txn/скрин.
3. Дальше автоматика:
   - **свой ученик** (вошёл в кабинет до отправки) → платёж сразу `paid`, доступ мгновенно, письмо-подтверждение;
   - **гость с новым email** → `pending`, вы сверяете в Filament, доступ после вашего «Подтвердить PayPal» (обычно ≤1 рабочий день);
   - куратору летит Telegram, админу — письмо; Google Sheet наполняется по paid автоматически.

## Скрипт первого теста

### Шаг 1 — что отправить ученику

Возьмите живой тариф: id виден в Filament → Тарифы (например, «Йога-сутры Патанджали, вторник 15:00 (2026)», курс 381: тарифы 4851–4855; вс 10:00, курс 433: 4986–4990). Ссылка строится как `https://samskrte.ru/paypal/{tariff_id}` — например `https://samskrte.ru/paypal/4851`.

Готовое сообщение (скопировать целиком):

```
🐳 Здравствуйте! Для оплаты из-за рубежа у нас штатный путь через PayPal:

1. Переведите оплату по ссылке paypal.me/gasuns (комиссию PayPal
   оплачивает отправитель — иначе сумма придёт неполной).
2. Откройте форму: [ПРЯМАЯ_ССЫЛКА]
3. Вставьте целиком текст деталей платежа из PayPal в поле
   «Вставить детали из PayPal» → нажмите «Заполнить из вставки» —
   дата, сумма и валюта подставятся сами.
4. Впишите свой PayPal-адрес в поле «С какого PayPal платили»,
   приложите скрин — и отправьте.

Если вы уже наш ученик и войдёте в кабинет перед отправкой — доступ
откроется сразу. Подтверждение придёт на ваш email 🙏
Полная инструкция: samskrtam.ru/faq/p/paypal
```

### Шаг 2 — что проверить вам (5 минут)

1. **Filament** (samskrte.ru/admin) → Payments:
   - свой вошедший ученик → запись сразу `paid`, провайдер `PayPal`;
   - гость → `pending` в фильтре «Заявки PayPal на проверке» → кнопка «Подтвердить PayPal» (или «Нет платежа — отменить» для фейка).
2. **Сверка суммы**: личный PayPal Activity vs поля from/date/amount заявки; выборочная пост-сверка своих — фильтр «PayPal: без сверки» → «Сверка пройдена» (штампует `verified_at`).
3. **Email ученику**: `PaypalClaimStudentAckMail` (варианты trusted/guest) должен прийти автоматически.
4. **Доступ**: у trusted — группы курса навесились мгновенно; у подтверждённого гостя — после перевода в paid.

### Если что-то пошло не так

- Форма 404 → на проде выключен флаг `PAYPAL_CLAIM_ENABLED` (.env .92) — проверить `php artisan tinker --execute="var_dump(config('services.paypal.enabled'));"`.
- Скрин ученика хранится приватно (disk `local`) — смотреть кнопкой proof в админке, ссылка `/admin/payments/{payment}/paypal-proof`.
- Ученик прислал только скрин без заявки — шаблон `/оплата-paypal-скрин` ([Telegram_templates.md](https://github.com/gasyoun/ORS-FAQ/blob/main/Telegram_templates.md)); фолбэк — Payment вручную в Filament (см. buyer-path доку).
