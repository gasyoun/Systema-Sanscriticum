# Для преподавателя: уроки и SRS-карточки (колода)

_Created: 31-07-2026 · Last updated: 01-08-2026_

Краткая инструкция для преподавателей (в т.ч. Елены Трефиловой), которым
нужно **самим** править уроки и создавать карточки на [samskrte.ru](https://samskrte.ru).

## Источник правды: Systema, не Memrise

**Новые карточки и правки делайте только на samskrte.ru** (админка → SRS).

- Memrise community-курсы закрываются / нестабильны; колода «Продлёнка» уже
  перенесена в Systema (курс 6679375).
- Студенты учат и набирают очки **у нас** (кабинет SRS + таблицы лидеров).
- Memrise **не** обязателен. Если очень хочется зеркалировать туда же —
  выгрузите CSV из Systema (см. ниже) и загрузите в Memrise вручную. Это
  опция, не основной путь.

## Вход

1. Откройте [https://samskrte.ru/admin](https://samskrte.ru/admin) (или
   `/admin` на стенде).
2. Войдите **своим** аккаунтом преподавателя (роль `Преподаватель`, привязка
   к карточке «Преподаватели»).
3. Если админка не открывается — напишите администратору: нужны
   `role=teacher` и `teacher_id` на вашем пользователе.

## Уроки

- Меню: **Уроки** (или Dashboard перенаправит туда).
- Видны только курсы, где вы указаны преподавателем.
- Можно **создавать** и **редактировать** уроки своего курса (материалы,
  ДЗ, ссылки).

## SRS / колода (карточки)

Нужен включённый SRS на сайте (`SRS_ENABLED` — на проде уже включён).

| Раздел | Зачем |
|---|---|
| **Допматериалы → SRS — колоды** | Новая колода, название, язык, видимость; внутри — список карточек |
| **Допматериалы → SRS — карточки** | Все карточки сразу; удобно править перевод/IAST/деванагари; **импорт и экспорт CSV** |

### Создать карточку в колоде (основной способ)

1. **SRS — колоды** → нужная колода (например «Продлёнка…») → блок **Карточки**.
2. **Добавить карточку**.
3. Заполните: деванагари / IAST / кириллица (по необходимости) + **перевод** (обязателен).
4. Направление: «Скрипт → перевод» или наоборот.
5. Сохраните.

### Новая колода

1. **SRS — колоды** → **Создать**.
2. Название, slug (можно оставить авто), язык (`sa` / `hi` / …).
3. Дальше добавляйте карточки как выше.

### Импорт готового CSV (bulk)

В **SRS — карточки** кнопка **Импорт CSV**. Колонки: ID колоды, деванагари,
IAST, кириллица, перевод, направление. Для разового переноса с Memrise
администратор уже заливал пакет; **новые** слова — через форму или свой CSV
в Systema.

### Экспорт CSV (бэкап / опционально в Memrise)

В **SRS — карточки** кнопка **Экспорт CSV**:

1. При необходимости отфильтруйте колоду в таблице.
2. **Экспорт CSV** → дождитесь уведомления → скачайте файл.
3. **Бэкап** — храните у себя.
4. **Memrise (по желанию)** — откройте CSV в Excel/Google Sheets, возьмите
   колонки «слово» (IAST или деванагари) + «перевод» и вставьте в bulk-add
   Memrise. Systema при этом остаётся главным местом правки.

## Что видят студенты

После сохранения карточки доступны в учебном SRS (кабинет / колода).
Студенты **не** видят Filament-админку. Очки за повторения идут в
таблицы лидеров (SRS / Продлёнка / …).

## Словарный запас (DictionaryWord)

**Допматериалы → Словарный запас** — основной каталог слов (деванагари, IAST,
кириллица, перевод). Роль **преподаватель** может создавать, править и
удалять слова (Елена Трефилова — основной редактор).

- При создании выберите **словарь** (контейнер; создавать новые словари
  «Словари» пока только admin).
- Слова из этого раздела можно привязывать к SRS-карточкам (поле «Слово
  словаря»).

## Чего здесь нет (и не нужно ждать)

- Не трогайте разделы «Платежи», «Финансы», «Пользователи» — они для
  администратора/бухгалтера.
- Сами **контейнеры** словарей (`Словари`) — admin-only; слова внутри —
  доступны преподавателю.
- Не продолжайте **только** Memrise: данные и студенты — на samskrte.ru.

## Если что-то не получается

Напишите администратору (или ответьте в issue на GitHub): не открывается
админка, нет пункта SRS, ошибка при сохранении, нужен bulk-импорт большой
таблицы.
