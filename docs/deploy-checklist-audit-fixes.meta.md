Метадок о документе [deploy-checklist-audit-fixes.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/deploy-checklist-audit-fixes.md) — не пересказывает чек-лист, а фиксирует его происхождение, статус и границы применимости.

## Предмет

- **Ссылка на документ:** [docs/deploy-checklist-audit-fixes.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/deploy-checklist-audit-fixes.md)
- **Назначение:** разовый чек-лист выкатки конкретного merge develop → main (коммит `8a90b7b` от 2026-07-02), несущего фиксы после аудита безопасности — прежде всего перевод вебхуков TG/VK в режим fail-closed.
- **Аудитория:** тот, кто выполняет выкатку на прод (DevOps/мейнтейнер); одноразовое чтение в момент деплоя, не справочник для повторного использования.
- **Формат/контракт:** линейный чек-лист «до выкатки → команды на сервере → хвост миграций → проверка после»; шаги с квадратными скобками означают пункты ручной верификации, а не машинно-проверяемый gate.

## Происхождение

- **Документ создан:** 06-07-2026 (первый коммит файла; сам деплой — 02-07-2026).
- **Метадок написан:** 13-07-2026, H891, Opus 4.8 `claude-opus-4-8`.
- **Следующее упрочнение:** после закрытия чек-листа его материал (fail-closed вебхуки, throttle-лимиты чекаута, IDOR-фикс сертификатов) переносится в постоянный [SECURITY_ROADMAP.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/SECURITY_ROADMAP.md); одноразовый чек-лист сам по себе долгоживущим быть не должен.

## Известные ограничения / оговорки

- Документ привязан к одному merge-коммиту (`8a90b7b`, 2026-07-02) — вне контекста именно этой выкатки он не применим и легко вводит в заблуждение.
- Zoom-посещаемость описана условно («если включаем этим же деплоем») — часть пунктов могла не относиться к фактической выкатке.
- Пункты проверки — ручные, без автоматического подтверждения; успех фиксировался человеком в момент деплоя, а не в файле.
- Файл не сообщает, была ли выкатка успешной; статус закрытия чек-листа снаружи не виден.

## Назначение / возможное неверное использование

- **По назначению:** прочитать один раз при выкатке коммита `8a90b7b`, отметить критичный шаг с двумя webhook-секретами до появления 403 на ботах.
- **Не по назначению:** использовать как generic-runbook для любых будущих деплоев Systema-Sanscriticum — команды и хвост миграций специфичны для состояния прода на 02-07-2026; для повторяемой процедуры см. deploy.md.

## План поддержки и вывода из эксплуатации

Чек-лист по своей природе одноразовый: его срок жизни — окно вокруг выкатки 02-07-2026. После подтверждения, что все четыре пункта проверки закрыты на проде, документ считается отработавшим — долгоживущие меры безопасности из него переезжают в [SECURITY_ROADMAP.md](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/SECURITY_ROADMAP.md), а сам файл остаётся как исторический артефакт аудита. Обновлять его под будущие деплои не нужно — для этого существует общий deploy.md.
