# ТЗ: каталог /online в стиле Arzamas

**Цель.** Переподать существующий каталог курсов (`/online`) в стиле каталога
[arzamas.academy/courses](https://arzamas.academy/courses): фильтры — это видимая
горизонтальная навигация чипами, а не свернутая форма; у карточек настоящие обложки.

**Важно перед стартом.** Бэкенд-функционал уже есть — это задача про **подачу (UX/верстку)**,
а не про новую логику. Серверная фильтрация по категориям/формату/преподавателю и поиск
с сохранением в URL уже работают в Livewire-компоненте. Не переписывать движок фильтрации —
переиспользовать его методы.

---

| Фильтр по формату (live = «идет сейчас» / recorded = «в записи») | `CourseCatalog.php` → `$format` (`#[Url(as:'format')]`) | ✅ есть |

у нас это уже есть. Копировать нужно только **раскладку фильтров** и **обложки**.

## Задача 1 — фильтры из сайдбара в горизонтальные чипы (главное)

**Файл:** `resources/views/livewire/shop/course-catalog.blade.php`

Сейчас фильтры живут в левом сайдбаре (на мобиле — свернуты в аккордеон «Фильтры»).
У Arzamas фильтры — две строки «таблеток» над сеткой, всегда видимые. Перенести так же.

### 1.1. Разметка — две строки чипов под поиском, над счетчиком

Строка A — **формат/статус** (одиночный выбор, как радио):
```
[ Все ] [ Идет сейчас ] [ В записи ]
```
Привязка к уже существующему свойству:
- «Все» → `wire:click="$set('format','')"`
- «Идет сейчас» → `wire:click="$set('format','live')"`
- «В записи» → `wire:click="$set('format','recorded')"`
- активное состояние чипа: `format === 'live'` и т.д.

Строка B — **категории** (множественный выбор), генерируется из `$this->categories`:
```
[ Все ] [ Грамматика ] [ Хинди ] [ Рецитация ] [ Философия ] ...
```
Привязка к существующим методам:
- каждый чип → `wire:click="toggleCategory({{ $category->id }})"`
- активное состояние: `in_array($category->id, $categoryIds)`
- чип «Все» → `wire:click="resetFilters"` (или сброс только категорий, см. ниже)
- внутри чипа показывать счетчик курсов категории (он уже считается в `categories()`)

### 1.2. Стиль чипа (Tailwind, темная тема проекта)

Базовый чип:
```html
class="inline-flex items-center gap-2 rounded-full px-4 py-2 text-sm
       border border-[#1F2636] bg-[#141A28] text-gray-300
       hover:border-[#E85C24]/50 transition cursor-pointer whitespace-nowrap"
```
Активный чип (добавить через `@class([...])`):
```html
'bg-[#E85C24] text-white border-[#E85C24]'  // активный
```
Обертка строки — горизонтальный скролл на узких экранах:
```html
class="flex gap-2 overflow-x-auto pb-2 -mx-1 px-1 [scrollbar-width:none]"
```

### 1.3. Преподаватель

Селект преподавателя оставить как есть, но переместить либо в правый край строки A,
либо в небольшое выпадающее меню «Еще фильтры», чтобы не ломать чип-ленту.
Логику (`$teacherId`) не менять.

### 1.4. Сайдбар

Удалить левую колонку фильтров и развернуть сетку курсов на всю ширину
(сейчас `grid-cols-1 md:grid-cols-2 xl:grid-cols-3 2xl:grid-cols-4` — оставить).
Кнопку «Сбросить фильтры» (`resetFilters`) показывать справа от строки B,
только когда `$this->hasActiveFilters` истинно (метод уже есть).

**Acceptance:**
- На десктопе и мобиле обе строки чипов видны без раскрытия аккордеона.
- Клик по чипу мгновенно перефильтровывает сетку и обновляет «Показано: X из Y».
- Состояние фильтров отражается в URL (`?cat=`, `?format=`, `?q=`) — поведение `#[Url]` сохранено.
- Активные чипы визуально выделены оранжевым `#E85C24`.

## Задача 2 — обложки карточек (вторая по важности)

**Проблема:** у ~90% курсов `image_path` пуст → карточка показывает серую заглушку ॐ.
У Arzamas каждая карточка — живая иллюстрация; единственная наша карточка с настоящей
обложкой («Бхагавад-гита») резко выигрывает.

**Файл:** `resources/views/components/shop/course-card.blade.php` (блок cover image).

Реализовать **типографскую обложку-фолбэк** вместо ॐ, когда `image_path` пуст:
цветной фон по категории курса (`course->categories->first()->color`), на нем — имя
преподавателя сверху и название курса крупно (как сделано вручную у «Бхагавад-гиты»).

Псевдоразметка фолбэка:
```blade
@if($course->image_path)
    <img src="{{ Storage::url($course->image_path) }}" ...>
@else
    @php $c = $course->categories->first()?->color ?? '#2A3142'; @endphp
    <div class="h-full w-full flex flex-col justify-between p-4"
         @style(["background: linear-gradient(135deg, {$c}, #0E1320)"])>
        <span class="text-xs uppercase tracking-wide text-white/70">
            {{ $course->teacher?->name }}
        </span>
        <span class="text-2xl font-bold text-white leading-tight">
            {{ $course->title }}
        </span>
    </div>
@endif
```
Бейджи статуса/числа лекций/часов поверх обложки оставить как есть.

**Acceptance:**
- Курс без `image_path` показывает цветную типографскую обложку, а не ॐ.
- Цвет берется из категории; при отсутствии категории — нейтральный темный фон.
- Курс с `image_path` отображается без изменений.

## Задача 3 — кликабельные теги-категории на карточке

Теги категорий на карточке (`course-card.blade.php`) уже рендерятся. Сделать их
кликабельными, чтобы клик добавлял категорию в фильтр (как у Arzamas «Подкаст»-ярлык).

Поскольку карточка — это `<x-...>`-компонент внутри Livewire-сетки, прокинуть событие:
```blade
<button type="button"
        wire:click.stop="toggleCategory({{ $cat->id }})"
        @style([...как сейчас...])>
    {{ $cat->name }}
</button>
```
`wire:click.stop` — чтобы клик по тегу не срабатывал как переход на страницу курса.

**Acceptance:** клик по тегу на карточке выделяет соответствующий чип в строке B и
фильтрует сетку; повторный клик снимает фильтр.

## Не входит в задачу
- Менять схему БД / миграции — все поля (`format`, `categories`, `color`, `image_path`) уже есть.
- Менять серверную логику фильтрации в `CourseCatalog.php` (только при необходимости
  добавить мелкий метод-хелпер для сброса только категорий).
- Загружать реальные иллюстрации к курсам — это контентная задача редактора, отдельно.

## Порядок работ
1. Задача 1 (чипы) — дает основной визуальный эффект «как Arzamas».
2. Задача 2 (фолбэк-обложки) — закрывает разрыв с серыми ॐ.
3. Задача 3 (кликабельные теги) — связывает карточку с фильтром.

## Проверка верстки
В репозитории есть скилл `blade-styling` (визуальная проверка через Playwright MCP) —
использовать его для итеративной отладки раскладки чипов на десктопе и мобиле,
а не править вслепую.

Ветка от `develop`, PR в `develop` → `main` (PR-only, как принято в репозитории).
