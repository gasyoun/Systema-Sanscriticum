## Subject (Предмет)

- **Ссылка на документ:** [`docs/php-8.3-upgrade.md`](https://github.com/gasyoun/Systema-Sanscriticum/blob/main/docs/php-8.3-upgrade.md)
- **Назначение:** пошаговый операционный чек-лист для миграции продакшена samskrte.ru с EOL-PHP 8.1 на 8.3 (под Laravel 10) с планом отката.
- **Аудитория:** DevOps / администратор прода, выполняющий разовое окно апгрейда на сервере Ubuntu; не для студентов и не для разработчиков фич.
- **Формат / контракт:** пронумерованный runbook (шаги 0–8 + блок рисков), команды bash в фенсах, привязанные к фактической конфигурации прода (nginx-сокеты, supervisor/Horizon, набор расширений).

## Known limitations / caveats (Известные ограничения)

- Документ описывает состояние прода на конец июня 2026 (сокеты, supervisor, набор расширений) — при изменении инфраструктуры команды устаревают.
- Несколько открытых вопросов зашиты в тело runbook (реальный каталог приложения, конфигурация default-сайта nginx) и не разрешены на уровне документа.
- Чек-лист не покрывает откат уже применённых миграций БД — только откат трёх указателей PHP (CLI/nginx/supervisor) и composer-файлов.

## Intended use / known misuse (Назначение и антипаттерны)

- **По назначению:** справляться в момент разового окна апгрейда PHP на конкретном сервере samskrte.ru, в указанном порядке шагов.
- **Не по назначению:** использовать как обобщённый гайд по апгрейду PHP для другого проекта/сервера — команды и версии привязаны к фактической конфигурации этого прода; переносить механически нельзя.

## Maintenance & sunset plan (Обслуживание и вывод из эксплуатации)

- Обновлять только если апгрейд ещё не выполнен и меняется целевая версия PHP или конфигурация прода.
- После подтверждённого закрытия окна апгрейда — перевести в статус исторического артефакта (шапка «выполнено», ссылка на дату/коммит окна) и не поддерживать далее.

## Deprecation status (Статус актуальности)

`superseded` — платформенный апгрейд отгружен через H862 (Laravel 10→12, который тянет за собой PHP ≥8.2), поэтому этот PHP 8.1→8.3 runbook как активная задача закрыт; сохраняется как исторический/откатный референс.
