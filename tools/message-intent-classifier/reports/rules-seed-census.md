## 1. SupportAnswerSuggester RULES — порядок приоритетов сохранён

Порядок RULES закодирован как ordered priorities (меньше = раньше):

| Легаси-рука | Приоритет v1 | Категория |
|---|---|---|
| B записи (запис/видеозап/пересмотр…) | 10 | recording_access |
| C узкая (ссылк…расписан) | 20 | schedule |
| D узкая (ссылк…оплат/тариф/цен; H3394: раньше A) | 30 | payment_billing |
| A Zoom (зум/zoom/ссылк/подключ…) | 40 | zoom_link |
| C широкая (расписан/когда…) | 50 | schedule |
| D широкая (сколько стоит/оплат…) | 60 | payment_billing |
| E доступ (нет доступа/кабинет/парол…) | 70 | access_login |
| F материалы (H3394) | 80/85/86 | materials_content / homework_progress / certificate |

Прецедентные кейсы («B раньше A», «оплата раньше zoom») проходят golden-векторами
t-rec-0x, t-pay-05 («сколько будет стоить … где ссылка» → payment_billing),
t-zoom-*. Единственная структурная адаптация: голый «запис» легаси сужен до
«запис[а-я]*( занятия| урока| лекции)?» + negations («записаться|запишусь»,
тех-отказы) — иначе онбординг «хочу записаться» падал в записи уроков;
закреплено negation-парой g-neg-a/g-neg-b ещё в H3525.

## 3. sufler.py В1–В11

Все 11 классов присутствуют в objection.yaml (В2→b2_price, В9→b9_risk_trial,
В3→b3_self_doubt, В6→b6_start_date, В1→b1_time; недостающие в sufler.py
В4/В5/В7/В8/В10/В11 взяты из FAQ_FUNNEL_OBJECTION_MAP — источник указан в
`source:` каждого правила). Маркеры sufler перенесены дословно, кроме трёх
отступлений, задокументированных в шапке objection.yaml ещё при сиде H3525:

- из В2 убраны голые «оплатить/деньг/стоит» («хочу оплатить» = buy_signal,
  а не возражение о цене; «сколько стоит» покрыто);
- из В1 убраны «записи/записаться/запишусь» (в поддержке это записи уроков и
  онбординг, не страх времени);
- «подойде» В9 заменён на «не подойдет/а вдруг», «риск» → «рискованно».

Порядок классов (деньги раньше сомнения в себе, пробное раньше записей) несёт
приоритетами: b8_payment_mechanics p12 < b2_price p15 < b9_risk_trial p20 <
b3_self_doubt p25 < b6_start_date p30 < b1_time p35 < остальные.
