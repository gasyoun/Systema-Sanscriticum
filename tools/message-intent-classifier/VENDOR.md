## Upgrade procedure

```sh
SHA=<new-full-sha>
git clone --depth 1 https://github.com/gasyoun/message-intent-classifier /tmp/mic-new
git -C /tmp/mic-new fetch --depth 1 origin $SHA && git -C /tmp/mic-new checkout FETCH_HEAD
rsync -a --delete --exclude '.git' --exclude 'PINNED_SHA' \
      --exclude 'VENDOR.md' --exclude 'rules/v1/*.json' \
      /tmp/mic-new/ tools/message-intent-classifier/
echo $SHA > tools/message-intent-classifier/PINNED_SHA
python3 tools/gen_mic_rules_json.py
```

CI job `mic-vendor-drift` fails when this tree drifts from the pin or a
generated JSON goes stale.
