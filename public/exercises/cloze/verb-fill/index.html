Выберите нужный глагол

Заполните каждый пропуск подходящей формой глагола. Подсказки дают русский перевод искомого глагола; «Заново» перемешивает варианты. Учебный виджет Systema Sanscriticum.
Источники: глаголы выверены по Уитни, «The Roots, Verb-forms…» (samskrtam.ru/whitney-roots), существительные — по словарю Монье-Вильямса (Cologne CDSL); таблица соответствий — в README семейства.
